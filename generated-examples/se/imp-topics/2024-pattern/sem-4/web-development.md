## Section E — Emergency Plan (1 Night Before)

**Absolute Bare Minimum (code-based):**
1. HTML form with all input types + table
2. CSS box model + 3 types of CSS inclusion
3. JavaScript form validation (email + password)
4. DOM manipulation — getElementById + addEventListener
5. PHP form handling with POST + echo output

**Quick Memory Tricks:**
- **HTML input types:** **"TENBSURLD"** = Text, Email, Number, Button, Submit, URL, Radio, Date, Checkbox, etc.
- **CSS inclusion:** **"EII"** = External (.css file), Internal (<style>), Inline (style="...")
- **PHP superglobals:** **"GRC"** = $_GET, $_REQUEST, $_POST, $_COOKIE, $_SESSION
- **JS DOM methods:** **"GQS"** = getElementById, querySelector, querySelectorAll
- **HTTP methods:** **"GP"** = GET (retrieve), POST (send/modify)

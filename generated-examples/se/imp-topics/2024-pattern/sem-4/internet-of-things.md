## Section C — IMP Questions by Marks

### 2-Mark Questions
1. Define IoT. Give its characteristics.
2. What is the difference between M2M and IoT?
3. What is a transducer?
4. What is MQTT?
5. What is CoAP?
6. What is the difference between BLE and Classic Bluetooth?
7. What is LoRaWAN?
8. Define sensor accuracy and sensitivity.
9. What is 6LoWPAN?
10. What is the difference between IaaS, PaaS, and SaaS?

### 5-Mark Questions
1. Explain the functional blocks of an IoT system.
2. Compare MQTT and CoAP protocols.
3. Compare Arduino, Raspberry Pi, and NodeMCU for IoT applications.
4. Explain the working of MQTT with publish-subscribe model.
5. Explain the architecture of IoT with Cloud.
6. Compare Zigbee, Bluetooth, and LoRaWAN for IoT.
7. Explain IoT applications in Smart Agriculture.
8. Explain sensor specifications — accuracy, precision, sensitivity, range.
9. What is LoRaWAN? Explain its architecture and features.
10. Explain IoT-based health monitoring system.

### 10-Mark Questions
1. Explain the complete IoT architecture with all layers. Discuss each layer's protocols and functions.
2. Compare all IoT communication protocols — Zigbee, BLE, LoRaWAN, Wi-Fi — in a table covering range, power, data rate, and application.
3. Explain MQTT protocol in detail — architecture, working, QoS levels, and comparison with CoAP.
4. Design an IoT-based Smart Home Automation system. Explain sensors, actuators, cloud, and application.
5. Explain IoT with Cloud Computing — discuss AWS IoT and Azure IoT services.
6. Design an IoT-based Environmental Monitoring system. Discuss sensors, data collection, cloud storage, and alerts.
7. Compare and contrast IoT protocols at different layers — Physical/MAC (802.15.4, LoRa), Network (6LoWPAN), Application (MQTT, CoAP).
8. Explain IoT applications in Industrial IoT — predictive maintenance, asset tracking, and monitoring.

## Section E — Preparation Strategy

### Unit Priority
1. **Unit III** (Protocols) — Most technical, highest exam weightage
2. **Unit IV** (Cloud for IoT) — Very practical, good for diagram questions
3. **Unit I** (Introduction) — Foundation, easy marks
4. **Unit V** (Applications) — Application-based, good for case studies
5. **Unit II** (Sensors & Actuators) — Moderate, but important for practical understanding

### Key Strategy
- **Protocols (III):** Memorize the comparison table of Zigbee, BLE, LoRaWAN, MQTT, CoAP
- **Cloud (IV):** Focus on IoT-Cloud architecture diagram and service models
- **Applications (V):** Learn 2-3 smart applications in detail (Smart City, Smart Agriculture)
- **Sensors (II):** Know sensor specs and board comparisons
- **Intro (I):** Quick revision of definitions and functional blocks

## Section F — Emergency Plan (1 Night Before)

**Absolute Bare Minimum:**
1. IoT definition + characteristics + functional blocks (5M)
2. MQTT vs CoAP comparison table (5-10M)
3. IoT-Cloud architecture diagram (5M)
4. Smart City OR Smart Agriculture application (5M)
5. Sensor vs Actuator difference + Arduino vs Raspberry Pi (5M)

**Quick Memory Tricks:**
- **IoT Layers:** **"SGCA"** = Sensing → Gateway → Cloud → Application
- **Protocols:** **"MZLB"** = MQTT, Zigbee, LoRaWAN, BLE
- **MQTT QoS:** **"0-1-2"** = At most once, At least once, Exactly once
- **Cloud Models:** **"ISP"** = IaaS, SaaS, PaaS
- **Smart Applications:** **"SHAPE"** = Smart Home, Health, Agriculture, Parking, Energy

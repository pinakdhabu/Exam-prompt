## Section D — IMP Questions by Marks

### 2-Mark Questions
1. What is a tautology? Give an example.
2. Define reflexive, symmetric, and transitive relations.
3. What is a Hasse Diagram?
4. State the Handshaking Lemma.
5. Define Pigeonhole Principle.
6. What is the difference between a permutation and combination?
7. What is a group? Give an example.
8. What is an Euler path?
9. Define injective and surjective functions.
10. What is a lattice?

### 5-Mark Questions
1. Prove by Mathematical Induction: 1+2+3+...+n = n(n+1)/2.
2. Determine if the relation R = {(1,1),(2,2),(3,3),(1,2)} is reflexive, symmetric, transitive.
3. Draw the Hasse Diagram for the divisibility relation on {1,2,3,4,5,6,10,15,30}.
4. Construct Huffman code for characters with given frequencies.
5. Find the shortest path from vertex A using Dijkstra's algorithm.
6. Apply the Pigeonhole Principle to prove: In any group of 13 people, at least 2 share a birth month.
7. Find the number of ways to arrange 5 books on a shelf if 2 specific books must be together.
8. Apply Inclusion-Exclusion to find the number of integers from 1 to 100 divisible by 2, 3, or 5.
9. Explain types of functions with examples.
10. Find MST using Prim's algorithm for a given weighted graph.

### 10-Mark Questions
1. Construct Huffman tree for given characters and frequencies. Encode and decode a message.
2. Find MST using both Prim's and Kruskal's algorithms for a given graph. Compare the results.
3. Trace Dijkstra's algorithm on a given graph. Find shortest paths from source to all vertices.
4. Prove by induction: 2^n > n+1 for all integers n ≥ 2.
5. Given a relation, find its matrix representation, draw its digraph, and check if it is an equivalence relation.
6. Apply Inclusion-Exclusion principle for 3 sets with a numerical problem.
7. Solve the recurrence relation using generating functions: a_n = a_{n-1} + 2, a_0 = 1.
8. Explain all algebraic structures — Semi Group, Monoid, Group, Ring, Field — with examples and properties.

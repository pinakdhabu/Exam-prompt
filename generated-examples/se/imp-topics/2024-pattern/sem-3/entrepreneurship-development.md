## Section C — IMP Questions (Assignment/Case Study Style)

### 2-Mark Questions

1. Define entrepreneurship.
2. What is the difference between an entrepreneur and an intrapreneur?
3. What is MVP?
4. Define break-even point.
5. What is SWOT analysis?

### 5-Mark Questions

1. Compare sole proprietorship, partnership, and private limited company.
2. Explain the 9 blocks of the Business Model Canvas.
3. Explain SWOT analysis with an example for a food delivery startup.
4. Differentiate between bootstrapping and venture capital funding.
5. Explain the break-even analysis with a numerical problem.
6. What is empathy mapping? How does it help in idea generation?
7. Compare digital marketing channels — SEO, Social Media, Email marketing.
8. Write a 90-second elevator pitch for an ed-tech startup.

### 10-Mark Questions

1. Map the complete Business Model Canvas for Zomato/Uber/OYO. Explain each block.
2. Compare all types of entrepreneurship with examples. Explain the startup ecosystem in India.
3. Explain the complete process — from idea generation to pitching. Use a real case study.
4. Design a marketing plan for a startup covering branding, pricing (break-even), digital marketing,
   and customer acquisition.

## Section E — Emergency Plan (1 Night Before)

**Absolute Bare Minimum:**

1. BMC — draw all 9 blocks with labels (10M guaranteed)
2. SWOT Analysis — practice with 1 startup
3. Break-even formula + 1 numerical
4. Types of entrepreneurship + comparison table
5. Elevator pitch structure — write 1 sample

**Quick Memory Tricks:**

- **BMC blocks:** **"KCVPCKACR"** = Key Partners, Key Activities, Key Resources, Value Proposition,
  Customer Relations, Channels, Customer Segments, Cost Structure, Revenue Streams
- **Business forms:** **"SPPP"** = Sole proprietorship, Partnership, Private Ltd, Public Ltd
- **Funding stages:** **"BANG"** = Bootstrapping, Angel, Next round, Growth/VC

## Section D — IMP Questions by Marks

### 2-Mark Questions

1. State De Morgan's theorem.
2. Define fan-in and fan-out.
3. What is a don't care condition?
4. Difference between SOP and POS.
5. What is a shift register?
6. Difference between PLA and PAL.
7. What is a K-Map?
8. Define propagation delay.
9. What is the difference between TTL and CMOS?
10. What is a Johnson Counter?

### 5-Mark Questions

1. Simplify using K-Map: f(A,B,C,D) = Σm(0,1,5,7,8,10,14,15) + d(2,4)
2. Design a Full Subtractor using logic gates.
3. Implement a Boolean function using 4:1 MUX.
4. Explain JK flip-flop with truth table and excitation table.
5. Convert a JK flip-flop to D flip-flop.
6. Explain SISO and PIPO shift registers with diagrams.
7. Compare Mealy and Moore machines.
8. Explain PLA architecture with a programming example.
9. Design a 3-bit ring counter.
10. Explain the construction of an ASM chart.

### 10-Mark Questions

1. Minimize using K-Map: (provide 4-variable function with don't cares). Realize using basic gates
   and NAND gates.
2. Design a 4-bit binary adder using IC 7483. Add two 4-bit numbers and verify.
3. Design a BCD to Excess-3 code converter.
4. Explain all types of flip-flops (SR, JK, D, T) with truth tables, excitation tables, and
   conversion from one type to another.
5. Design a mod-10 synchronous counter using JK flip-flops.
6. Compare all disk scheduling algorithms with numerical.
7. Design a combinational circuit using PLA for a given truth table.
8. Explain FSM with Mealy and Moore models. Construct ASM chart for a vending machine controller.

## Section E — Preparation Strategy

### Unit Priority

1. **Unit I** (K-Map + Boolean Algebra) — Guaranteed 10M numerical
2. **Unit III** (Sequential Circuits) — Flip-Flop conversions are guaranteed
3. **Unit II** (Combinational Design) — MUX implementation is classic
4. **Unit V** (PLDs) — PLA vs PAL comparison is must-know
5. **Unit IV** (ASM + Logic Families) — Moderate difficulty

### Key Strategy

- **Practice K-Map problems** daily — this is guaranteed marks
- **Master MUX implementation** — the examiner loves this
- **Flip-Flop conversion** — know excitation tables cold
- **PLA vs PAL** — memorize the comparison table

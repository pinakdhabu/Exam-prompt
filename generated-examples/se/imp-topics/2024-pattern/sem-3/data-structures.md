## Section C — IMP Questions by Marks

### 2-Mark Questions (Definitions / Short Notes)

1. Define ADT with example.
2. Differentiate between Big-O and Big-Theta notation.
3. What is a sparse matrix? Give its representation.
4. What is stability in sorting? Give example of stable and unstable sort.
5. Define load factor in hashing.
6. What is a circular queue? Why is it preferred over linear queue?
7. What is a priority queue? Give applications.
8. Define collision in hashing.
9. What is the difference between open hashing and closed hashing?
10. What are the properties of a good hash function?
11. Differentiate between DFS and BFS.
12. What is a BST? State its properties.
13. What is the difference between persistent and ephemeral data structures?
14. Define synchronous and asynchronous loading.

### 5-Mark Questions (Explanations / Comparisons)

1. Explain Big-O, Big-Theta, and Big-Omega notation with examples.
2. Analyze the time complexity of the following code using step count method: (nested loops
   example).
3. Compare Quick Sort and Merge Sort on the basis of time complexity, space complexity, and
   stability.
4. Explain Fibonacci Search algorithm with example.
5. Explain circular queue with diagram. Write algorithms for enqueue and dequeue.
6. Explain the concept of multiple stacks in a single array.
7. Explain the difference between Singly Linked List and Doubly Linked List with diagrams.
8. Explain extendible hashing with a suitable example.
9. Convert the following infix expression to postfix and evaluate: (provide expression).
10. Explain Prim's algorithm for Minimum Spanning Tree with a numerical example.
11. Explain Kruskal's algorithm for MST with a numerical example.
12. Write a short note on Priority Queue and its applications.

### 10-Mark Questions (Detailed / Algorithm + Trace)

1. Explain Binary Search algorithm. Trace it for a given array and search key. Write its time
   complexity.
2. Explain Quick Sort algorithm with a suitable example. Write its time complexity analysis.
3. Explain Merge Sort algorithm with a suitable example. Write its time and space complexity.
4. Explain all operations on a Singly Linked List (create, traverse, search, insert, delete, sort,
   concatenate) with algorithms and diagrams.
5. Explain DFS and BFS traversal algorithms. Trace both on a given graph.
6. Explain BST operations — insert, delete, search — with algorithms and a trace example.
7. Compare open addressing and chaining collision resolution techniques. Solve a numerical problem
   for each.
8. Explain infix to prefix conversion using stack with a complete example.
9. Explain non-recursive (using stack) inorder and preorder traversal of a binary tree.
10. Explain hashing with chaining and linear probing. Compare their performance.

## Section E — Preparation Strategy

### Recommended Unit Priority (Highest weightage first)

1. **Unit V** (Graphs & Trees) — Highest weightage, 3-4 major topics
2. **Unit III** (Stacks, Queues, Linked Lists) — Most question variety
3. **Unit II** (Searching & Sorting) — Algorithm-heavy, high scoring
4. **Unit IV** (Hashing) — Moderate, but very scorable
5. **Unit I** (Introduction) — Lightest, but builds foundation

### Per-Unit Time Allocation (for 1-week plan)

- Unit V: 4-5 hours (DFS/BFS + MST + BST = must do)
- Unit III: 3-4 hours (Stack expressions + Linked List = must do)
- Unit II: 3-4 hours (Quick/Merge Sort + Binary Search = must do)
- Unit IV: 2-3 hours (Hashing + Collision resolution = must do)
- Unit I: 1-2 hours (Notation + Complexity = must do)

## Section F — Emergency Plan (1 Night Before)

**Absolute Bare Minimum (3-5 topics to guarantee passing):**

1. Big-O, Theta, Omega notation with 1 example each
2. Quick Sort or Merge Sort — full algorithm + complexity
3. Infix to Postfix conversion — 1 worked example
4. DFS or BFS — algorithm + trace on small graph
5. Binary Search Tree — insert 5 elements + traversals

**Quick Memory Trick:**

- **Sorting mnemonic:** **"BIBSQM"** = Bubble, Insertion, Binary(search), Selection, Quick, Merge
- **Hashing:** **"CLOP"** = Chaining, Linear probing, Open/Closed hashing, Perfect hash
- **Tree traversals:** **"IPO"** = Inorder, Preorder, Postorder (Left-Root, Root-Left, Left-Right)
- **MST algorithms:** **"PK"** = Prim's, Kruskal's

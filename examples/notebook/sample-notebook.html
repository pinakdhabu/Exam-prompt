Chapter 1 — Normalization

Functional dependencies are the backbone of normalization. A functional dependency X → Y means X uniquely determines Y.

Armstrong's Axioms

  1. Reflexivity: If Y ⊆ X, then X → Y
  2. Augmentation: If X → Y, then XZ → YZ
  3. Transitivity: If X → Y and Y → Z, then X → Z
F+ = { X → Y | F ⊨ X → Y }

1NF, 2NF, 3NF, BCNF

Normal FormConditionEliminates
1NFAtomic values onlyRepeating groups
2NF1NF + no partial dependencyRedundancy (partial)
3NF2NF + no transitive dependencyTransitive redundancy
BCNF3NF + every determinant is a keyAll FD anomalies

Key insight: 3NF is dependency-preserving, but BCNF may lose some FDs. In practice, 3NF is often preferred for transactional systems.

Lossless Decomposition

A decomposition R → {R₁, R₂} is lossless iff:

R₁ ∩ R₂ → R₁ or R₁ ∩ R₂ → R₂

Chapter 2 — Transaction Management

ACID Properties

  • Atomicity: All or nothing
  • Consistency: DB remains valid before & after
  • Isolation: Concurrent transactions don't interfere
  • Durability: Committed changes persist

Schedule Classifications

Recovery Techniques

  • Undo Logging: Write old values before modifying
  • Redo Logging: Write new values after modifying
  • Checkpointing: Periodic sync to reduce recovery time

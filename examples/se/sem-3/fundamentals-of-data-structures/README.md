# Fundamentals of Data Structures — Sample Papers

## Syllabus Overview

FDS covers the design, analysis, and implementation of fundamental data structures including arrays,
linked lists, stacks, queues, along with searching and sorting algorithms.

## Units

1. Introduction to Algorithm and Data Structures — 7 hrs
2. Linear Data Structure Using Sequential Organization — 7 hrs
3. Searching and Sorting — 7 hrs
4. Linked List — 7 hrs
5. Stack — 7 hrs
6. Queue — 7 hrs

## Exam Pattern

- ESE: Units 3-6, 70 marks, 2.5 hrs
- Unit marks: U3=18, U4=17, U5=18, U6=17
- In-Sem: Units 1-2, 30 marks

## Key Topics

- Binary search, quick sort, selection sort
- Singly/doubly linked list operations
- Stack applications (expression evaluation, recursion)
- Circular queue, priority queue, deque
- Time complexity analysis (Big-O notation)

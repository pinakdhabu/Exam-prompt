# Object Oriented Programming — Sample Papers

## Syllabus Overview

OOP introduces the object-oriented paradigm using C++, covering classes, inheritance, polymorphism,
file handling, templates, exception handling, and the Standard Template Library (STL).

## Units

1. Fundamentals of Object Oriented Programming — 7 hrs
2. Inheritance and Pointers — 7 hrs
3. Polymorphism — 7 hrs
4. Files and Streams — 7 hrs
5. Exception Handling and Templates — 7 hrs
6. Standard Template Library (STL) — 7 hrs

## Exam Pattern

- ESE: Units 3-6, 70 marks, 2.5 hrs
- Unit marks: U3=18, U4=17, U5=18, U6=17
- In-Sem: Units 1-2, 30 marks

## Key Topics

- Virtual functions, runtime polymorphism, operator overloading
- File operations, command-line arguments
- Templates (function and class), exception handling
- STL containers (vector, list, map), iterators, algorithms
- Diamond problem, virtual base class

# Discrete Mathematics — Sample Papers

## Syllabus Overview

Discrete Mathematics covers foundational mathematical structures used in computer science — logic,
set theory, combinatorics, graph theory, trees, and algebraic structures.

## Units

1. Set Theory and Logic — 7 hrs
2. Relations and Functions — 7 hrs
3. Counting Principles — 7 hrs
4. Graph Theory — 7 hrs
5. Trees — 7 hrs
6. Algebraic Structures and Coding Theory — 7 hrs

## Exam Pattern

- ESE: Units 3-6, 70 marks, 2.5 hrs
- Unit marks: U3=18, U4=17, U5=18, U6=17
- In-Sem: Units 1-2, 30 marks

## Key Topics

- Permutations and combinations, binomial theorem
- Dijkstra's algorithm, graph isomorphism
- Huffman coding, MST (Kruskal's/Prim's)
- Groups, rings, fields, Lagrange's theorem
- Pigeonhole principle, inclusion-exclusion

# Digital Electronics and Logic Design — Sample Papers

## Syllabus Overview

DE&LD covers digital circuit design from Boolean algebra and minimization techniques through combinational and sequential circuits, programmable logic devices, logic families, and computer architecture.

## Units

1. Minimization Technique — 7 hrs
2. Combinational Logic Design — 7 hrs
3. Sequential Logic Design — 7 hrs
4. Algorithmic State Machines and Programmable Logic Devices — 7 hrs
5. Logic Families — 7 hrs
6. Introduction to Computer Architecture — 7 hrs

## Exam Pattern

- ESE: Units 3-6, 70 marks, 2.5 hrs
- Unit marks: U3=18, U4=17, U5=18, U6=17
- In-Sem: Units 1-2, 30 marks

## Key Topics

- Flip-flop conversions (SR, JK, D, T), excitation tables
- Counters (asynchronous, synchronous, MOD-N using IC 7490)
- Shift registers (SISO, SIPO, PISO, PIPO)
- ASM charts, PLA vs PAL
- TTL and CMOS logic families, characteristics
- Microprocessor bus structure, ALU IC 74181

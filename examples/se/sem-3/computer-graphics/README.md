# Computer Graphics — Sample Papers

## Syllabus Overview

Computer Graphics covers the fundamentals of generating and rendering graphical output — scan
conversion, transformations, projections, color models, shading, curves, fractals, and animation.

## Units

1. Graphics Primitives and Scan Conversion Algorithms — 7 hrs
2. Polygon, Windowing and Clipping — 7 hrs
3. 2D, 3D Transformations and Projections — 7 hrs
4. Light, Colour, Shading and Hidden Surfaces — 7 hrs
5. Curves and Fractals — 7 hrs
6. Introduction to Animation and Gaming — 7 hrs

## Exam Pattern

- ESE: Units 3-6, 70 marks, 2.5 hrs
- Unit marks: U3=18, U4=17, U5=18, U6=17
- In-Sem: Units 1-2, 30 marks

## Key Topics

- 2D/3D transformation matrices, homogeneous coordinates
- Projection types (parallel, perspective, orthographic, isometric)
- Color models (RGB, HSV, CMY), Phong illumination model
- Bezier and B-Spline curves
- Fractals (Koch curve, Hilbert curve)
- Hidden surface removal (z-buffer, Painter's algorithm)

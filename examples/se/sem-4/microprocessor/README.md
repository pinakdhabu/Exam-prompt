# Microprocessor — Sample Papers

## Syllabus Overview

Microprocessor covers the architecture, programming model, memory management, protection mechanisms, multitasking, and interrupt handling of the Intel 80386 processor, along with microcontroller fundamentals.

## Units

1. Introduction to 80386 — 7 hrs
2. Bus Cycles and System Architecture — 7 hrs
3. Memory Management — 8 hrs
4. Protection — 8 hrs
5. Multitasking and Virtual 8086 Mode — 8 hrs
6. Interrupts, Exceptions, and Introduction to Microcontrollers — 7 hrs

## Exam Pattern

- ESE: Units 3-6, 70 marks, 2.5 hrs
- Unit marks: U3=18, U4=17, U5=18, U6=17

## Key Topics

- 80386 addressing modes, instruction set
- GDT/LDT/IDT, segment and page translation
- Protection rings, DPL/CPL/RPL, call gates
- Task State Segment (TSS), task switching
- Virtual 8086 mode, entering/leaving
- Interrupt handling in protected mode, exceptions
- 8051 microcontroller features

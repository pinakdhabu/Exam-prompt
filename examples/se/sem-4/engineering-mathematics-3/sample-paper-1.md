Unit III — Statistics (17 Marks)

Q1) Write the correct option for the following multiple choice questions.

    a) If the two regression coefficients are −8/15 and −5/6, then the correlation coefficient is:
        i) −2/3    ii) 2/3    iii) −1/2    iv) 1/2 [2]

    b) A and B are independent events such that P(A) = 1/2, P(B) = 1/3, then P(A ∪ B) is:
        i) 3/5    ii) 2/3    iii) 1/6    iv) 1/3 [2]

    c) Using the Gauss elimination method, the solution of the system of equations x + 2y + z = 4, −3y + 2z = −3, −7y − 2z = −6 is:
        i) x = −43/16, y = −9/8, z = 15/16
        ii) x = 47/20, y = 9/10, z = −3/20
        iii) x = 4/3, y = 3/8, z = −5/6
        iv) x = 16/43, y = 8/9, z = −5 [2]

    d) If a curve passes through (0,0), (2,4), (4,8) and is given by y = y₀ + u Δy₀, then y at x = 1 is (Note: x = x₀ + uh):
        i) 1    ii) 0    iii) −1    iv) 2 [2]

    e) The range of the correlation coefficient r for bivariate data is:
        i) 0 < r < ∞    ii) −∞ < r < ∞    iii) −1 ≤ r ≤ 1    iv) 0 ≤ r ≤ 1 [1]

    f) If x₀ and x₁ are two initial approximations to the root of f(x) = 0, by the secant method the next approximation x₂ is given by:
        i) x₂ = x₁ − (x₁ − x₀)f₁ / (f₁ − f₀)
        ii) x₂ = (x₀ + x₁)/2
        iii) x₂ = x₁ − f(x₁) / f'(x₁)
        iv) x₂ = x₁ + (x₁ − x₀)f₁ / (f₁ − f₀) [1]

# Software Engineering — Sample Papers

## Syllabus Overview

Software Engineering covers software process models, requirements engineering, estimation and
scheduling, design engineering, risk management, configuration management, and software testing.

## Units

1. Introduction to Software Engineering and Process Models — 6 hrs
2. Software Requirements Engineering and Analysis — 7 hrs
3. Estimation and Scheduling — 7 hrs
4. Design Engineering — 7 hrs
5. Risks and Configuration Management — 7 hrs
6. Software Testing — 7 hrs

## Exam Pattern

- ESE: Units 3-6, 70 marks, 2.5 hrs
- Unit marks: U3=18, U4=17, U5=18, U6=17

## Key Topics

- COCOMO II, LOC/FP estimation, PERT scheduling
- Design patterns, architectural styles (data-flow, layered)
- W5HH principle, project management life cycle
- Risk management, RMMM plan
- SCM elements, repository, CASE tools
- Testing strategies (unit, integration, system, acceptance)

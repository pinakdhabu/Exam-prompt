# Principles of Programming Languages — Sample Papers

## Syllabus Overview

PPL covers the syntax, semantics, and paradigms of programming languages — including object-oriented
(Java), functional (LISP), and logic programming — along with concurrency and exception handling.

## Units

1. Syntax and Semantics — 7 hrs
2. Data Types and Basic Statements — 7 hrs
3. Object-Oriented Programming — 7 hrs
4. Functional Programming — 7 hrs
5. Logic Programming — 7 hrs
6. Concurrency and Exception Handling — 7 hrs

## Exam Pattern

- ESE: Units 3-6, 70 marks, 2.5 hrs
- Unit marks: U3=18, U4=17, U5=18, U6=17

## Key Topics

- Java OOP features (inheritance, polymorphism, encapsulation)
- Packages, exception handling, threads
- LISP functions (CAR, CDR, CONS, APPEND), recursion
- Equality and number predicates in LISP
- Constructor types, final/finally/finalize
- Vue.js, React JS, Angular JS basics

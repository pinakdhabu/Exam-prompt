# Data Structures and Algorithms — Sample Papers

## Syllabus Overview

DSA builds on FDS fundamentals to cover advanced data structures — hashing, trees, graphs, search
trees (AVL, Red-Black), indexing (B-Tree, B+Tree), and file organization techniques.

## Units

1. Hashing — 7 hrs
2. Trees — 8 hrs
3. Graphs — 7 hrs
4. Search Trees — 8 hrs
5. Indexing and Multiway Trees — 7 hrs
6. File Organization — 7 hrs

## Exam Pattern

- ESE: Units 3-6, 70 marks, 2.5 hrs
- Unit marks: U3=18, U4=17, U5=18, U6=17

## Key Topics

- Graph traversals (DFS, BFS), MST (Prim's, Kruskal's)
- Topological sorting, Dijkstra's algorithm
- AVL tree rotations, Red-Black tree properties
- B-Tree and B+Tree insertion/deletion
- Hashing techniques and collision resolution
- File organizations (sequential, indexed sequential, direct)

# Engineering Graphics — Sample Papers

## Syllabus Overview
Projection of points/lines/planes, engineering curves, development of surfaces, orthographic/isometric projections.

## Units
1. Projection of Point and Line — Quadrants, line inclined to both planes (7 Hrs)
2. Projection of Plane — Plane inclined to both reference planes (7 Hrs)
3. Engineering Curves and Development — Conics, cycloid, involute, helix (7 Hrs)
4. Orthographic Projection — First/third angle, hidden features (7 Hrs)
5. Isometric Projection — Isometric scale, isometric views from orthographic (7 Hrs)
6. (CAD and Practice)

## Exam Pattern
- ESE: Units 3–6, 50 marks, 2.5 hrs | ISE: Units 1–2, 30 marks, 1 hr
- Drawing-based: each question is a full-size drawing problem

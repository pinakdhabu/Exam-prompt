# Engineering Mathematics-II — Sample Papers

## Syllabus Overview

Advanced calculus: differential equations, vector calculus, Laplace transforms, and multiple
integrals.

## Units

1. **First Order ODE** — Exact, linear, Bernoulli, Clairaut's equations (8 Hrs)
2. **Higher Order Linear ODE** — Complementary function, particular integral, method of variation of
   parameters (8 Hrs)
3. **Vector Calculus** — Gradient, divergence, curl, line/surface integrals (8 Hrs)
4. **Laplace Transform** — Definition, properties, inverse LT, convolution (8 Hrs)
5. **Fourier Transform** — Fourier sine/cosine transforms, properties (8 Hrs)
6. **Multiple Integrals** — Double integrals, change of order, triple integrals, applications (8
   Hrs)

## Exam Pattern

- ESE: Units 3–6, 70 marks, 2.5 hrs | ISE: Units 1–2, 30 marks, 1 hr

## Key Topics

- **Unit 3:** Gauss/Stokes/Green's theorems, verification
- **Unit 4:** LT of standard functions, inverse LT by partial fractions, solving ODEs
- **Unit 5:** Fourier sine/cosine transforms, Parseval's identity
- **Unit 6:** Double integrals over regions, change to polar, area/volume applications

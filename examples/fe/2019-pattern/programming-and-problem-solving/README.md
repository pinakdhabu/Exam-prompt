# Programming and Problem Solving — Sample Papers

## Syllabus Overview

Problem-solving using Python: algorithms, control structures, functions, OOP, file handling.

## Units

1. Problem Solving & Python Basics — Algorithms, flowcharts, data types, operators (7 Hrs)
2. Decision Control Statements — if-else, loops, lists, tuples, dictionaries (8 Hrs)
3. Functions and Modules — Function definition, scope, lambda, modules, packages (8 Hrs)
4. Strings — Formatting, methods, iteration, string operations (7 Hrs)
5. Object Oriented Programming — Classes, objects, inheritance, encapsulation (7 Hrs)
6. File Handling — File operations, read/write, directory methods, exceptions (7 Hrs)

## Exam Pattern

- ESE: Units 3–6, 70 marks, 2.5 hrs | ISE: Units 1–2, 30 marks, 1 hr
- Q1 compulsory + 3 OR pairs (Q2/Q3, Q4/Q5, Q6/Q7, Q7/Q8)

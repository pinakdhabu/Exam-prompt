# Engineering Mathematics-I (2024 Pattern) — Sample Papers

## Syllabus Overview

NEP 2020 compliant: Single variable calculus, multivariable calculus, linear algebra. 5 units
covering calculus through matrix diagonalization.

## Units

1. Single Variable Calculus — Rolle's, MVT, Taylor series, Fourier series, harmonic analysis (8 Hrs)
2. Multivariable Calculus — Partial derivatives, Euler's theorem, total derivative (8 Hrs)
3. Applications of Partial Differentiation — Jacobian, errors, maxima/minima, Lagrange (8 Hrs)
4. Linear Algebra — Rank, system of equations, linear dependence, transformations (8 Hrs)
5. Eigen Values and Diagonalization — Cayley-Hamilton, quadratic forms, canonical reduction (8 Hrs)

## Exam Pattern

- ESE: All 5 units, 70 marks, 2.5 hrs | CCE: 30 marks
- Q1 compulsory + 5 OR pairs (Q2/Q3 through Q10/Q11)

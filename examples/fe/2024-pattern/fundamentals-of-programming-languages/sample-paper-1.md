&emsp; iv) 8 bytes

## Unit I — Introduction to Program Planning & C Programming (14 Marks)

**Q2)** Attempt the following: [12]

a) Draw a **flowchart** and write an **algorithm** to find the factorial of a given number \(n\).
[6]

b) Explain the following **C tokens** with examples: keywords, identifiers, constants, operators.
[6]

**OR**

**Q3)** Attempt the following: [12]

a) Explain the **compilation process** of a C program (preprocessing, compilation, assembly,
linking). [6]

b) Explain **data types** in C with their size and range (int, char, float, double). [6]

## Unit II — Operators and Expressions (14 Marks)

**Q4)** Attempt the following: [12]

a) Write a C program to **swap two numbers** without using a third variable. [6]

b) Explain the **operator precedence** and **associativity** in C with an example. [6]

**OR**

**Q5)** Attempt the following: [12]

a) Explain **bitwise operators** in C with examples (AND, OR, XOR, NOT, left shift, right shift).
[6]

b) Evaluate the expression: \(5 + 3 \* 2 \ \% \ 4 - 1\) showing precedence order. [6]

## Unit III — Control Flow (14 Marks)

**Q6)** Attempt the following: [12]

a) Write a C program to check whether a year is **leap year** or not using `if-else`. [6]

b) Explain the `switch` statement with syntax and an example (menu-driven calculator). [6]

**OR**

**Q7)** Attempt the following: [12]

a) Write a C program to **generate Fibonacci series** up to \(n\) terms using `for` loop. [6]

b) Differentiate between `while` and `do-while` loops with examples. [6]

## Unit IV — Arrays (14 Marks)

**Q8)** Attempt the following: [12]

b) Explain **string handling functions**: `strlen`, `strcpy`, `strcmp`, `strcat` with examples. [6]

**OR**

**Q9)** Attempt the following: [12]

a) Write a C program to perform **linear search** on an array of \(n\) elements. [6]

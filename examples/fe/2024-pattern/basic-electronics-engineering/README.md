# basic-electronics-engineering (2024 Pattern) — Sample Papers

**Course Code:** 104010 | **Credits:** 03 | **Semester:** I/II | **FE (2024 Pattern)**

## Syllabus Overview

| Unit | Title                                 | Hours |
| ---- | ------------------------------------- | ----- |
| I    | Semiconductor Diodes and Applications | 08    |
| II   | Bipolar Junction Transistor and FET   | 08    |
| III  | Operational Amplifiers                | 08    |
| IV   | Digital Electronics Fundamentals      | 08    |
| V    | Electronic Communication Systems      | 08    |

## Key Topics

- PN junction diode, Zener diode, rectifiers (half/full wave), filters
- BJT: biasing, configurations (CB, CE, CC), amplifier circuits
- JFET and MOSFET: characteristics, biasing, applications
- Op-amp: ideal characteristics, inverting/non-inverting, applications (adder, subtractor,
  integrator, differentiator)
- Number systems, logic gates, Boolean algebra, combinational logic circuits
- Flip-flops, counters, registers
- Modulation (AM, FM), demodulation, communication systems basics

## Exam Pattern

- ESE: All 5 units, 70 marks, 2.5 hrs | CCE: 30 marks
- 5 OR pairs (10 questions total)

# Programming and Problem Solving — Sample Paper 1

**University:** SPPU (Savitribai Phule Pune University) **Pattern:** 2024 Pattern (NEP) **Program:**
B.E./B.Tech (First Year) **Semester:** I/II **Total Marks:** 70 **Time:** 2½ Hours

---

## Instructions

1. Answer Q.1 or Q.2, Q.3 or Q.4, Q.5 or Q.6, Q.7 or Q.8, Q.9 or Q.10.
2. Neat diagrams must be drawn wherever necessary.
3. Figures to the right indicate full marks.
4. Assume suitable data, if necessary.

**Q1) a)** Define Algorithm and Flowchart. Explain the characteristics of a good algorithm. [6] CO:
CO1 | Bloom's: L1 (Remember)

**Q1) b)** Explain different data types in C programming with syntax and examples. [8] CO: CO2 |
Bloom's: L2 (Understand)

**OR**

**Q2) a)** What is a flowchart? Draw a flowchart to find the largest of three numbers. [6] CO: CO1 |
Bloom's: L2 (Understand)

**Q2) b)** Explain various operators in C with examples (Arithmetic, Relational, Logical, Bitwise).
[8] CO: CO2 | Bloom's: L2 (Understand)

---

**Q3) a)** Explain the concept of Arrays in C. Write a program to reverse an array of n integers.
[8] CO: CO3 | Bloom's: L3 (Apply)

**Q3) b)** Explain call by value and call by reference with suitable examples. [6] CO: CO3 |
Bloom's: L2 (Understand)

**OR**

**Q4) a)** Write a C program using functions to calculate factorial of a number using recursion. [8]
CO: CO3 | Bloom's: L3 (Apply)

**Q4) b)** Explain pointer arithmetic with examples. [6] CO: CO3 | Bloom's: L2 (Understand)

**Q5) a)** What is Structure? Write a program to create a structure `Student` with fields roll_no,
name, marks and display the student details. [8] CO: CO4 | Bloom's: L3 (Apply)

**Q5) b)** Differentiate between Structure and Union with suitable examples. [6] CO: CO4 | Bloom's:
L4 (Analyze)

**OR**

**Q6) a)** What is Dynamic Memory Allocation? Explain malloc(), calloc(), realloc(), and free() with
examples. [8] CO: CO4 | Bloom's: L2 (Understand)

**Q6) b)** Explain file handling functions in C: fopen(), fclose(), fread(), fwrite() with syntax
and examples. [6] CO: CO4 | Bloom's: L3 (Apply)

---

**Q7) a)** What is a String? Write a program to perform string concatenation without using built-in
function. [6] CO: CO5 | Bloom's: L3 (Apply)

**Q7) b)** Write a program to sort an array of n integers using Bubble Sort. [8] CO: CO5 | Bloom's:
L3 (Apply)

**OR**

**Q8) a)** Write a program to search an element in an array using Linear Search and Binary Search.
Compare their complexities. [8] CO: CO5 | Bloom's: L4 (Analyze)

**Q8) b)** Explain the concept of 2D arrays with matrix multiplication example. [6] CO: CO5 |
Bloom's: L3 (Apply)

**Q9) a)** Explain the need for Problem Solving. List and explain the steps involved in problem

**Q9) b)** Write a program to check if a given string is palindrome or not. [8] CO: CO6 | Bloom's:

**OR**

**Q10) a)** Explain different storage classes in C (auto, register, static, extern) with examples.

# High Performance Computing — Sample Papers

## Syllabus

### Unit I: Introduction to Parallel Computing

Motivating Parallelism, Modern Processor Architecture, Parallel Programming Platforms, Implicit
Parallelism, Dichotomy of Parallel Platforms, Physical Organization, Communication Costs, Levels of
Parallelism, Models: SIMD, MIMD, SIMT, SPMD, Data Flow, Architectures: Superscalar, Multi-core,
Multi-threaded

### Unit II: Parallel Algorithm Design

Principles of Parallel Algorithm Design, Decomposition Techniques, Characteristics of Tasks and
Interactions, Mapping Techniques for Load Balancing, Interaction Overheads, Parallel Algorithm
Models: Data, Task, Work Pool, Master Slave, Complexities, Anomalies in Parallel Algorithms

### Unit III: Parallel Communication

Basic Communication: One-to-All Broadcast, All-to-One Reduction, All-to-All Broadcast and Reduction,
All-Reduce and Prefix-Sum, Collective Communication using MPI: Scatter, Gather, Broadcast, Blocking
and Non-blocking MPI, Circular Shift

### Unit IV: Analytical Modeling of Parallel Programs

Sources of Overhead, Performance Measures: Amdahl's and Gustafson's Laws, Speedup and Efficiency,
Cost and Utilization, Granularity, Scalability, Minimum Execution Time and Cost, Asymptotic
Analysis, Matrix Computation: Matrix-Vector, Matrix-Matrix Multiplication

### Unit V: CUDA Architecture

Introduction to GPU, GPU Architecture, Introduction to CUDA, CUDA Programming Model, Writing and
Launching CUDA Kernels, Handling Errors, CUDA Memory Model, Communication and Synchronization

### Unit VI: HPC Applications

Scope of Parallel Computing, Parallel Search: DFS, BFS, Parallel Sorting: Bubble and Merge,
Distributed Computing: Document Classification, Frameworks: Kubernetes, GPU Applications, AI/ML on
GPUs

## Exam Pattern

- **ESE**: Units 3-6, 70 marks, 2.5 hours
- **ISE**: Units 1-2, 30 marks, 1 hour

## Key Topics

- Parallel communication operations (Broadcast, Reduce, Scatter, Gather)
- MPI programming concepts
- Performance analysis (Amdahl's Law, Gustafson's Law, Speedup, Efficiency)
- Matrix operations: Vector and Matrix Multiplication
- CUDA architecture and programming
- Parallel sorting and search algorithms
- Distributed algorithms (BFS, DFS)

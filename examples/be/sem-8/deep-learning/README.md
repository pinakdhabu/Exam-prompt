# Deep Learning — Sample Papers

## Syllabus

### Unit I: Foundations of Deep Learning

ML vs DL, Supervised/Unsupervised Learning, Bias-variance tradeoff, Hyperparameters,
Under/Overfitting, Regularization, History, Advantages/Challenges, Learning representations,
Architectural principles, Applications, Tools: TensorFlow, Keras, PyTorch

### Unit II: Deep Neural Networks (DNNs)

Biological Neuron, Perceptron, Multilayer Feed-Forward Networks, Training: Backpropagation, Forward
propagation, Activation Functions: Linear, Sigmoid, Tanh, Hard Tanh, Softmax, ReLU, Loss Functions,
Hyperparameters, Deep Feedforward Networks, Gradient-based learning, Vanishing/Exploding gradients

### Unit III: Convolution Neural Network (CNN)

Overview and Architecture, Padding, Strides, ReLU layer, Pooling, Fully Connected Layers, Local
Response Normalization, Training CNNs, Case Studies: AlexNet, VGG

### Unit IV: Recurrent Neural Network (RNN)

Unfolding Computational Graphs, Bidirectional RNNs, Encoder-Decoder Seq2Seq Architectures, Deep
Recurrent Networks, Recursive Neural Networks, Long-Term Dependencies, LSTM, Gated RNNs,
Optimization, Practical Methodology

### Unit V: Deep Generative Models

Introduction to Generative Models, Boltzmann Machine, Deep Belief Networks, GAN:
Discriminator/Generator, Types of GAN, Applications

### Unit VI: Reinforcement Learning

Introduction to RL, Markov Decision Process, Dynamic Programming, Q Learning, Deep Q-Networks, Deep
Q Recurrent Networks, RL for Tic-Tac-Toe

## Exam Pattern

- **ESE**: Units 3-6, 70 marks, 2.5 hours
- **ISE**: Units 1-2, 30 marks, 1 hour

## Key Topics

- CNN architecture and components (convolution, pooling, ReLU, FC layers)
- RNN, LSTM, GRU architectures
- Vanishing/exploding gradient problem
- Generative models (GAN, Boltzmann Machine, DBN)
- Reinforcement Learning (MDP, Q-Learning, Deep Q-Networks)
- Activation functions and their properties
- Backpropagation algorithm

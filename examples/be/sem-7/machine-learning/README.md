# Machine Learning — Sample Papers

## Syllabus

### Unit I: Introduction to Machine Learning
Introduction to ML, Comparison of ML with traditional programming, ML vs AI vs Data Science, Types of learning: Supervised, Unsupervised, Semi-supervised, Reinforcement learning, Models of ML: Geometric, Probabilistic, Logical, Grouping, Parametric and non-parametric models, Important Elements — Data formats, Learnability, Statistical learning approaches

### Unit II: Feature Engineering
Concept of Feature, Preprocessing: Normalization, Scaling, Standardization, Managing missing values, Dimensionality Reduction: PCA, Feature Extraction: Kernel PCA, Local Binary Pattern, Feature Selection: SFS, SBS, Statistical feature engineering, Multidimensional Scaling, Matrix Factorization

### Unit III: Supervised Learning: Regression
Bias, Variance, Generalization, Underfitting, Overfitting, Linear regression, Lasso regression, Ridge regression, Gradient descent, Evaluation Metrics: MAE, RMSE, R²

### Unit IV: Supervised Learning: Classification
KNN, SVM, Ensemble Learning: Bagging, Boosting, Random Forest, AdaBoost, Binary vs Multiclass Classification, Balanced and Imbalanced Data, One-vs-One, One-vs-All, Evaluation Metrics: Accuracy, Precision, Recall, F-score, Cross-validation, Micro/Macro Average

### Unit V: Unsupervised Learning
K-Means, K-medoids Clustering, Hierarchical Clustering, Density-based Clustering, Spectral Clustering, Outlier analysis, Evaluation: Elbow method, Extrinsic and Intrinsic methods

### Unit VI: Introduction to Neural Networks
ANN: Single Layer, Multilayer Perceptron, Back Propagation Learning, Functional Link ANN, Radial Basis Function Network, Activation functions, RNN and CNN introduction

## Exam Pattern
- **ESE**: Units 3-6, 70 marks, 2.5 hours
- **ISE**: Units 1-2, 30 marks, 1 hour

## Key Topics
- Regression models (Linear, Lasso, Ridge) with gradient descent
- Evaluation metrics and bias-variance tradeoff
- Classification algorithms (KNN, SVM) and ensemble methods
- Multiclass classification strategies (OvO, OvA)
- Clustering algorithms (K-Means, Hierarchical, DBSCAN)
- Neural Networks (MLP, Backpropagation, Activation functions)
- CNN and RNN architectures

- **ESE:** Units 3–6, 70 marks, 2.5 hrs
- **Unit Marks:** U3 = 18, U4 = 17, U5 = 18, U6 = 17
- **Question Pattern:** 4 OR-pairs (Q1/Q2, Q3/Q4, Q5/Q6, Q7/Q8)
- **Mid-Sem:** Units 1–2, 30 marks

## Key Topics

- Functional dependencies and normalization (2NF, 3NF, BCNF)
- Codd's rules and relational integrity
- Transaction states, ACID properties, serializability
- Concurrency control: lock-based and timestamp-based protocols
- Deadlock handling and log-based recovery
- NoSQL data models: document, key-value, graph, wide-column
- MongoDB: CRUD, aggregation, MapReduce, indexing
- CAP theorem, BASE vs ACID
- Semi-structured data: JSON, XML
- Object-relational databases and spatial data

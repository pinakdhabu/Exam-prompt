# Systems Programming and Operating System — Sample Papers

**Course Code:** 310243 | **Credits:** 03 | **Teaching Scheme:** 03 Hrs/Week

## Syllabus

| Unit | Title | Hours | CO |
|------|-------|-------|----|
| I | Introduction to Systems Programming | 08 | CO1, CO2, CO3 |
| II | Macro Processor and Compilers | 06 | CO1, CO2, CO3 |
| III | Linkers and Loaders | 07 | CO1, CO2, CO3 |
| IV | Operating System and Process Scheduling | 07 | CO4 |
| V | Synchronization and Concurrency Control | 07 | CO5 |
| VI | Memory Management | 07 | CO6 |

## Exam Pattern

- **ESE:** Units 3–6, 70 marks, 2.5 hrs
- **Unit Marks:** U3 = 18, U4 = 17, U5 = 18, U6 = 17
- **Question Pattern:** 4 OR-pairs (Q1/Q2, Q3/Q4, Q5/Q6, Q7/Q8)
- **Mid-Sem:** Units 1–2, 30 marks

## Key Topics

- Linkers vs Loaders, static/dynamic linking, absolute loader, direct linking loader
- Overlay structures, self-relocating programs
- Compiler vs Interpreter, phases of compiler, YACC
- Process states, PCB, scheduling algorithms (FCFS, SJF, RR, Priority)
- Thread lifecycle, multithreading models
- Semaphores, mutex, classical synchronization problems
- Deadlock: prevention, avoidance, detection, recovery
- Memory partitioning, paging, segmentation, virtual memory
- Page replacement algorithms (FIFO, LRU, Optimal), thrashing

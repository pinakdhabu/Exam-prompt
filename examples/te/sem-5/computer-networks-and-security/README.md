# Computer Networks and Security — Sample Papers

**Course Code:** 310244 | **Credits:** 03 | **Teaching Scheme:** 03 Hrs/Week

## Syllabus

| Unit | Title | Hours | CO |
|------|-------|-------|----|
| I | Introduction to Computer Networks | 06 | CO1 |
| II | Data Link Layer | 08 | CO2 |
| III | Network Layer | 08 | CO3 |
| IV | Transport Layer | 07 | CO4 |
| V | Application Layer | 06 | CO5 |
| VI | Security | 07 | CO6 |

## Exam Pattern

- **ESE:** Units 3–6, 70 marks, 2.5 hrs
- **Unit Marks:** U3 = 18, U4 = 17, U5 = 18, U6 = 17
- **Question Pattern:** 4 OR-pairs (Q1/Q2, Q3/Q4, Q5/Q6, Q7/Q8)
- **Mid-Sem:** Units 1–2, 30 marks

## Key Topics

- IPv4/IPv6 addressing, subnetting, CIDR, NAT
- Routing algorithms: Distance Vector, Link State, Path Vector
- Routing protocols: RIP, OSPF, BGP
- TCP and UDP header formats, socket programming
- Congestion control, QoS, SCTP
- HTTP, DNS, SMTP, POP3, FTP, DHCP
- Symmetric/Asymmetric cryptography, SSL/IPSec
- Firewalls, IDS, X.800 security architecture

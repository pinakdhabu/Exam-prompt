# Internet of Things and Embedded Systems — Sample Paper

**Course Code:** 310245(A) | **Credits:** 03 | **Semester:** V | **Elective I**

## Syllabus Overview

| Unit | Title                            | Hours |
| ---- | -------------------------------- | ----- |
| I    | Introduction to Embedded Systems | 07    |
| II   | Internet of Things: Concepts     | 07    |
| III  | IoT Design Methodology           | 07    |
| IV   | IoT Protocols                    | 07    |
| V    | Cloud Platforms for IoT          | 07    |
| VI   | Security in IoT                  | 07    |

## Key Topics

- Embedded processors, microcontrollers, SoC, RTOS
- IoT architecture: physical/logical design, IoT levels
- Sensors, actuators, communication models
- MQTT, CoAP, 6LoWPAN, Zigbee, LoRa
- Cloud platforms: AWS IoT, Azure IoT, ThingSpeak
- RESTful APIs, Django for IoT
- IoT security: threats, lightweight cryptography, access control

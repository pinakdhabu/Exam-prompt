### Unit III — IoT Design Methodology

**Q1)** **a)** Explain the IoT design methodology in detail. List and describe the steps involved in
designing an IoT system with a suitable example of a smart home automation system. [9]

**b)** Compare IoT communication models: Request-Response, Publisher-Subscriber, Push-Pull, and
Exclusive Pair. Give one use case for each model. [9]

**OR**

**Q2)** **a)** Explain the four pillars of IoT: M2M, SCADA, WSN, and RFID. Compare their roles in
building IoT systems. [9]

**b)** What are sensor networks? Explain the architecture and applications of Wireless Sensor
Networks (WSN) in IoT. [9]

---

### Unit IV — IoT Protocols

**Q3)** **a)** Explain MQTT protocol in detail. Describe MQTT architecture, message types, QoS
levels, and security features. Compare MQTT with MQTT-SN. [9]

**b)** What is 6LoWPAN? Explain its architecture, header compression techniques, and role in IoT
networking. [8]

**OR**

**Q4)** **a)** Compare Zigbee and LoRa protocols on the basis of: frequency band, data rate, range,
power consumption, and application areas. [9]

**b)** Explain the Modbus protocol. Describe Modbus RTU and Modbus TCP with frame formats and
applications. [8]

---

### Unit V — Cloud Platforms for IoT

**Q5)** **a)** Explain the role of Software Defined Networking (SDN) in IoT. Describe the SDN
architecture with a neat diagram. [9]

**b)** Compare AWS IoT, Microsoft Azure IoT, and ThingSpeak cloud platforms for IoT applications.
Discuss their features, pricing models, and ideal use cases. [9]

**OR**

**Q6)** **a)** What is RESTful Web Service? Explain REST API design principles for IoT. How does
REST differ from SOAP and gRPC? [9]

**b)** Explain the Django web application framework for IoT. Describe the Django architecture (MVT
pattern) with a block diagram. [9]

---

### Unit VI — Security in IoT

**Q7)** **a)** Analyze the major security vulnerabilities in IoT systems. Explain the security
requirements and challenges for designing secure IoT applications. [9]

**b)** What is lightweight cryptography? Explain the need for lightweight cryptographic algorithms
in IoT. Compare at least three lightweight ciphers. [8]

**OR**

**Q8)** **a)** Describe the threat modeling process for IoT systems. Explain key elements of IoT
security: identity establishment, access control, and data message security. [9]

**b)** Write short notes on any two: i) Security model for IoT ii) Blockchain for IoT security iii)
Intrusion detection in IoT networks [8]

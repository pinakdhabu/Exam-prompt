# Information Security — Sample Paper

**Course Code:** 310254(A) | **Credits:** 03 | **Semester:** VI | **Elective II**

## Syllabus Overview

| Unit | Title                                | Hours |
| ---- | ------------------------------------ | ----- |
| I    | Introduction to Information Security | 07    |
| II   | Cryptography and Encryption          | 07    |
| III  | Network Security                     | 07    |

## Key Topics

- CIA triad, security policies, risk management
- Symmetric/asymmetric encryption, hash functions, digital signatures
- IPSec, SSL/TLS, VPN, IDS/IPS
- Firewalls, access control, authentication (Biometric, OAuth, Kerberos)
- Secure coding, OWASP Top 10, SQL injection, XSS
- Cyber laws, IT Act 2000, digital forensics

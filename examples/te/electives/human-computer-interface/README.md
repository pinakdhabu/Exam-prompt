# Human Computer Interface — Sample Paper

**Course Code:** 310245(B) | **Credits:** 03 | **Semester:** V | **Elective I**

## Syllabus Overview

| Unit | Title                                          | Hours |
| ---- | ---------------------------------------------- | ----- |
| I    | Introduction and Foundation of HCI             | 07    |
| II   | Human Perspective in Interaction Design        | 07    |
| III  | Interaction Styles and HCI in Software Process | 07    |
| IV   | Usability Evaluation and Universal Design      | 07    |
| V    | HCI Paradigms                                  | 07    |
| VI   | HCI for Mobile and Handheld Devices            | 07    |

## Key Topics

- Human memory, cognition, Miller's Law, ergonomics
- Eight golden rules of interface design
- Interaction styles: command line, menu, form, direct manipulation
- GUI vs Web UI design
- Usability evaluation: GOMS model, heuristic evaluation, cognitive walkthrough
- DECIDE framework, universal design principles
- Mobile UI: multi-touch gestures, navigation, accessibility

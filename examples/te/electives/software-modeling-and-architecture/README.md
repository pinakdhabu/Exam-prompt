# Software Modeling and Architecture — Sample Paper

**Course Code:** 310254(D) | **Credits:** 03 | **Semester:** VI | **Elective II**

## Syllabus Overview

| Unit | Title                                             | Hours |
| ---- | ------------------------------------------------- | ----- |
| I    | Introduction to Software Architecture             | 07    |
| II   | Architectural Styles and Patterns                 | 07    |
| III  | Object-Oriented Modeling                          | 07    |
| IV   | Design Patterns                                   | 07    |
| V    | Component-Based and Service-Oriented Architecture | 07    |
| VI   | Architecture Evaluation and Documentation         | 07    |

## Key Topics

- Software architecture definitions, architectural views (4+1 view model)
- Layered, pipe-and-filter, client-server, peer-to-peer styles
- UML diagrams: class, sequence, deployment, component
- Design patterns: Creational (Singleton, Factory), Structural (Adapter, Proxy), Behavioral
  (Observer, Strategy)
- SOA, REST, microservices, web services
- ATAM, SAAM, architectural documentation (IEEE 1471)

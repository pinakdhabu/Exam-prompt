## Key Topics

- NIST definition, cloud characteristics, service models (IaaS, PaaS, SaaS)
- Deployment models (public, private, hybrid, community)
- Virtualization: hypervisors, para-virtualization, hardware-assisted
- MapReduce, Hadoop, Google File System
- AWS, Azure, Google Cloud overview
- Cloud security: DLP, CASB, encryption
- Fog and edge computing

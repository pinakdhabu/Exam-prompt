### Unit III — Virtualization

**Q1)** **a)** Explain the concept of virtualization in cloud computing. Describe the types of virtualization: hardware, software, memory, storage, network, and data virtualization with examples for each. [9]

**b)** Compare Type 1 (bare-metal) and Type 2 (hosted) hypervisors. Explain how CPU virtualization works using Full Virtualization, Paravirtualization, and Hardware-Assisted Virtualization. [9]

**OR**

**Q2)** **a)** What is the difference between Grid Computing and Cloud Computing? Explain virtualization architecture with a neat diagram showing the roles of the hypervisor, guest OS, and host OS. [9]

**b)** Explain network virtualization and storage virtualization in detail. Discuss how Software-Defined Networking (SDN) and Software-Defined Storage (SDS) enable cloud infrastructure. [9]

### Unit IV — Cloud Platforms and Applications

**Q3)** **a)** Explain Amazon Web Services (AWS) architecture. Describe core services: EC2 (compute), S3 (storage), and Lambda (serverless) with use cases for each. [9]

**b)** Compare AWS, Microsoft Azure, and Google Cloud Platform (GCP) on the basis of: computing services, storage options, pricing models, and geographical coverage. [8]

**OR**

**Q4)** **a)** Explain Microsoft Azure architecture. Describe Azure Virtual Machines, Azure App Services, and Azure Functions. How does Azure Active Directory manage identity? [9]

**b)** Discuss industry-specific cloud applications in healthcare, business, and education sectors with real-world examples. [8]

### Unit V — Cloud Security

**Q5)** **a)** Explain the risk management process in cloud computing. Discuss data security mechanisms: encryption at rest, encryption in transit, and key management in cloud environments. [9]

**b)** What is Identity and Access Management (IAM) in cloud? Explain IAM components: users, groups, roles, policies, and permissions with AWS IAM examples. [9]

**OR**

**Q6)** **a)** Analyze the major security challenges in cloud computing. Explain Cloud Security Alliance (CSA) guidance and the Shared Responsibility Model. [9]

**b)** What is compliance and governance in cloud? Discuss compliance standards: GDPR, HIPAA, SOC 2, and ISO 27001. How does cloud audit logging help meet compliance? [9]

### Unit VI — Advanced Cloud Techniques

**Q7)** **a)** Explain Docker container architecture. Describe Docker components: images, containers, Dockerfile, Docker Hub, and Docker Compose. Compare containers with virtual machines. [9]

**b)** What is Kubernetes? Explain Kubernetes architecture: master node, worker nodes, pods, services, deployments, and ingress. How does Kubernetes enable container orchestration? [8]

**OR**

**Q8)** **a)** Explain the convergence of IoT and Cloud Computing. What is Edge Computing? Compare cloud, fog, and edge computing with reference to latency, bandwidth, and processing power. [9]

**b)** Write short notes on any two: i) DevOps in cloud ii) Mobile cloud computing iii) Multimedia cloud computing [8]

## Examiner Commentary

This paper covers virtualization techniques, major cloud platforms (AWS, Azure, GCP), cloud security models, and advanced topics (Docker, Kubernetes, edge computing). The comparative questions (hypervisor types, cloud platforms, container vs VM) test analytical skills, while platform-specific questions test applied cloud knowledge.

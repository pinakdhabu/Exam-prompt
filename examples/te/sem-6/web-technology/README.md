# Web Technology — Sample Papers

**Course Code:** 310252 | **Credits:** 03 | **Teaching Scheme:** 04 Hrs/Week

## Syllabus

| Unit | Title                                        | Hours | CO  |
| ---- | -------------------------------------------- | ----- | --- |
| I    | Web Essentials and HTML                      | 07    | CO1 |
| II   | Client Side Technologies: JavaScript and DOM | 07    | CO2 |
| III  | Java Servlets and XML                        | 07    | CO3 |
| IV   | JSP and Web Services                         | 07    | CO4 |
| V    | PHP and .NET                                 | 07    | CO5 |
| VI   | Ruby and Rails                               | 07    | CO6 |

## Exam Pattern

- **ESE:** Units 3–6, 70 marks, 2.5 hrs
- **Unit Marks:** U3 = 18, U4 = 17, U5 = 18, U6 = 17
- **Question Pattern:** 4 OR-pairs (Q1/Q2, Q3/Q4, Q5/Q6, Q7/Q8)
- **Mid-Sem:** Units 1–2, 30 marks

## Key Topics

- Servlet: lifecycle, doGet vs doPost, session management, cookies
- XML: DTD, Schema, parsing
- JSP: lifecycle, MVC paradigm, Struts framework
- Web services: SOAP, WSDL, REST
- PHP: arrays, MySQL connectivity, session tracking
- WAP, WML, .NET framework, Node.js
- Ruby: control statements, arrays, Rails framework

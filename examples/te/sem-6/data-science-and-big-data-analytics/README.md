# Data Science and Big Data Analytics — Sample Papers

**Course Code:** 310251 | **Credits:** 03 | **Teaching Scheme:** 04 Hrs/Week

| Unit | Title | Hours | CO |
|------|-------|-------|----|
| I | Introduction to Data Science and Big Data | 07 | CO1 |
| II | Statistical Inference | 07 | CO2 |

## Exam Pattern

- **ESE:** Units 3–6, 70 marks, 2.5 hrs
- **Unit Marks:** U3 = 18, U4 = 17, U5 = 18, U6 = 17
- **Question Pattern:** 4 OR-pairs (Q1/Q2, Q3/Q4, Q5/Q6, Q7/Q8)
- **Mid-Sem:** Units 1–2, 30 marks
- **Scientific Calculator permitted**

## Key Topics

- Data analytics lifecycle phases, stakeholders, sandbox, ETLT
- Linear and logistic regression, Naive Bayes, Decision Trees
- Apriori algorithm, association rule mining
- K-means clustering, hierarchical clustering
- Text preprocessing, Bag of Words, TF-IDF
- Model evaluation: holdout, cross-validation, confusion matrix, AUC-ROC
- Hadoop ecosystem: HDFS, MapReduce, Pig, Hive
- Data visualization: histogram, box plot, density plot

# SPPU Question Paper Header Formatting

## Purpose

This document defines the STRICT PAGE TEMPLATE for SPPU examination paper headers.
Every solved paper / question paper PDF must use this exact header layout.
The header is auto-generated by `src/transforms/header.js` from metadata present in the markdown source.

## Layout Specification

### DOCUMENT TYPE

* Savitribai Phule Pune University (SPPU) Question Paper
* Professional examination-paper formatting
* Header must visually resemble an official SPPU paper

### LAYOUT REQUIREMENTS

#### TOP SECTION

**Row 1 — Total Questions + SEAT No. box (12 pt Times Bold)**

```
Total No. of Questions : 8]                    SEAT No. : [___]
```

- `Total No. of Questions : 8]` aligned left
- `SEAT No. :` aligned right, with inline bordered box beside it
- Box: 2px solid black border, ~130 x 22 px, inline-block beside label
- Font: 12 pt Times Bold

**Row 2 — Paper code (16 pt Times Bold)**

```
PE-2519
```

- Paper code right-aligned
- Font: 16 pt Times Bold

**Row 3 — Paper identifier (17 pt Times Bold, centered)**

```
[6583]-45
```

- Font: 17 pt Times Bold
- Center-aligned on page

#### MAIN TITLE BLOCK

Department line (17 pt Times Bold, centered):
```
T.E. (Computer Engg./Computer Science)
```

Subject line (16 pt Times Bold, centered):
```
SYSTEM PROGRAMMING & OPERATING SYSTEM
```

Pattern info line (16 pt Times Bold, centered):
```
(2019 Pattern) (Semester - V) (310243)
```

#### TIME / MARKS ROW (13 pt Times Regular)

```
Time : 2½ Hours]                             [Max. Marks : 70
```

- Time left aligned (13 pt Times Regular)
- Marks right aligned (13 pt Times Regular)
- On same line (never separate)

#### INSTRUCTIONS SECTION (13 pt)

```
Instructions to the candidates :
```
- Font: 13 pt, bold + italic in solved papers (Times Regular in original QP)

```
1) Answer Q. 1 or Q. 2, Q. 3 or Q. 4, Q. 5 or Q. 6, Q. 7 or Q. 8.
2) Neat diagrams must be drawn wherever necessary.
3) Figures to the right indicate full marks.
4) Assume suitable data, if necessary.
```
- Font: 13 pt, italic only in solved papers
- Numbered with `)` closing parenthesis

### VISUAL REQUIREMENTS

* Preserve whitespace
* Preserve alignment
* Preserve centered elements
* Preserve right-aligned elements
* Preserve seat-number box (inline, same line as label)
* Use horizontal spacing intentionally
* Use page-header hierarchy (font sizes decrease: 17pt → 16pt → 13pt → 12pt)
* Do not collapse lines
* Do not convert header into paragraphs
* Do not stack unrelated fields vertically

### CRITICAL RULE

The header must be rendered using a fixed layout grid/table structure.
Never generate the header as flowing text.
Treat it as a professionally typeset examination paper header.
Only after the complete header is rendered should the question paper content begin.

## Metadata Extraction

The header transform (`src/transforms/header.js`) extracts metadata from the
markdown source header block (between `---` delimiters).

### Supported patterns

| Field | Pattern | Example |
|-------|---------|---------|
| Total Questions | `Total No. of Questions : X` | `Total No. of Questions : 8` |
| Paper code | `^[A-Z]+-\d+$` | `PE-2519` or `P-7539` |
| Paper identifier | `^\[.+\]-\S+$` | `[6583]-45` or `[5650]-SPOS` |
| Department | `^(SE\|TE\|BE\|FE).*$` | `T.E. (Computer Engg./Computer Science)` |
| Subject | All-caps line | `SYSTEM PROGRAMMING &amp; OPERATING SYSTEM` |
| Pattern info | `(YYYY Pattern) (Semester - X) (XXXXXX)` | `(2019 Pattern) (Semester - V) (310243)` |
| Time | `Time : VALUE` | `Time : 2½ Hours` |
| Max Marks | `Max. Marks : X` | `Max. Marks : 70` |
| Instructions block | After closing `---` | Numbered items 1-4 |

### Fallback defaults

If a field cannot be detected from the markdown, sensible defaults are used.

## How to Verify / Debug Header Output

If you are unsure about exact positioning, font sizes, margins, spacing, or any
visual property of the generated header:

1. **Ask for the reference question paper PDF** — the actual SPPU question paper
   PDF for the same subject/pattern (e.g., `Nov_Dec_2025.pdf`).

2. **Run the extraction script** to measure its exact properties:
   ```bash
   python3 << 'EOF'
   import re
   from pypdf import PdfReader
   r = PdfReader('/path/to/reference.pdf')
   page = r.pages[0]
   cs = page.get_contents()
   raw = cs.get_data()
   text = raw.decode('latin-1')
   lines = text.split('\n')
   for i, l in enumerate(lines):
       s = l.strip()
       if s and ('Tf' in s or 'Tm' in s or 'Td' in s or 'TJ' in s or 'Tj' in s):
           print(f'{i}: {s[:130]}')
   EOF
   ```
   This extracts font selections (`Tf`), font sizes + positions (`Tm`), and
   text content (`TJ`/`Tj`) from the reference PDF's content stream.

3. **Cross-check these extracted values** against the Font Specifications table
   in this document. Update the table if the reference differs.

4. **Regenerate the PDF** and verify visually that the output matches the
   reference.

## Implementation Notes

- Uses HTML `<table>` elements with inline styles for layout precision
- Overrides default table borders via inline `border:none` on `<td>`
- Uses HTML entities `&#91;` / `&#93;` for brackets to avoid
  colliding with the `.marks` CSS auto-replacement in `renderer.js`
- The seat number box is an inline `<span>` with CSS border, beside the label
- Instructions: header = bold+italic, items = italic only
- Footer: `[paper-id]` left, page number center, `[paper-id]` right (9pt)
- P.T.O. right-aligned italic below header on first page only

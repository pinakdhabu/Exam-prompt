# SPPU Question Paper Header Formatting

## Purpose

This document defines the STRICT PAGE TEMPLATE for SPPU examination paper headers. Every solved
paper / question paper PDF must use this exact header layout. The header is auto-generated by
`src/transforms/header.js` from metadata present in the markdown source.

## Source References

### Primary: Official SPPU QP Format Templates (blank forms)

The authoritative source is the SPPU SODL Question Papers Formats library at:
`http://collegecirculars.unipune.ac.in/sites/examdocs/SODL%20Question%20Papers%20Formats/`

Download all 18 blank QP format templates from that URL (BA/BCom/MA/MCom, FY/SY/TY,
Annual/Semester). They share identical layout and are the ground truth for header formatting. If you
need to check exact positioning, ask the user to provide the relevant QP format PDF or an actual
question paper PDF.

### Secondary: Actual SPPU Question Papers (for footer/page-number reference)

Ask the user for an actual SPPU question paper PDF (e.g., `Nov_Dec_2025.pdf`) for the same
subject/pattern. This is needed for footer, page number, and P.T.O. positioning which the blank
templates lack.

## Font Specifications (measured from official SPPU templates & actual QPs)

All measurements in PDF points (1 pt = 1/72 inch). Positions use bottom-left origin (y=0 at page
bottom). Page height = 842 pt.

**IMPORTANT:** The body font family is `'TNR', 'Times New Roman', serif`. Do NOT add 'Cambria' or
other fallback fonts — the answer paper must render entirely in Times New Roman (except code blocks,
which use CaskaydiaCove Nerd Font Mono for monospace preservation).

## Layout Specification

### DOCUMENT TYPE

- Savitribai Phule Pune University (SPPU) Question Paper
- Professional examination-paper formatting
- Header must visually resemble an official SPPU paper

### LAYOUT REQUIREMENTS

#### TOP SECTION

**Row 1 — Total Questions + SEAT No. box (12 pt Times Bold)**

```
Total No. of Questions : 8]                    SEAT No. : [___]
```

- `Total No. of Questions : 8]` aligned left
- `SEAT No. :` aligned right, with inline bordered box beside it
- Box: 2px solid black border, ~130 x 22 px, inline-block beside label
- Font: 12 pt Times Bold

**Row 2 — Paper code (16 pt Times Bold)**

```
PE-2519
```

- Paper code right-aligned
- Font: 16 pt Times Bold

**Row 3 — Paper identifier (17 pt Times Bold, centered)**

```
[6583]-45
```

- Font: 17 pt Times Bold
- Center-aligned on page

#### MAIN TITLE BLOCK

Department line (17 pt Times Bold, centered):

```
T.E. (Computer Engg./Computer Science)
```

Subject line (16 pt Times Bold, centered):

```
SYSTEM PROGRAMMING & OPERATING SYSTEM
```

Pattern info line (16 pt Times Bold, centered):

```
(2019 Pattern) (Semester - V) (310243)
```

#### TIME / MARKS ROW (13 pt Times Regular)

```
Time : 2½ Hours]                             [Max. Marks : 70
```

- Time left aligned (13 pt Times Regular)
- Marks right aligned (13 pt Times Regular)
- On same line (never separate)

#### INSTRUCTIONS SECTION (13 pt)

```
Instructions to the candidates :
```

- Font: 13 pt, bold + italic in solved papers (Times Regular in original QP)

```
1) Answer Q. 1 or Q. 2, Q. 3 or Q. 4, Q. 5 or Q. 6, Q. 7 or Q. 8.
2) Neat diagrams must be drawn wherever necessary.
3) Figures to the right indicate full marks.
4) Assume suitable data, if necessary.
```

- Font: 13 pt, italic only in solved papers
- Numbered with `)` closing parenthesis

### VISUAL REQUIREMENTS

- Preserve whitespace
- Preserve alignment
- Preserve centered elements
- Preserve right-aligned elements
- Preserve seat-number box (inline, same line as label)
- Use horizontal spacing intentionally
- Use page-header hierarchy (font sizes: 16pt title → 13pt time/marks → 12pt body)
- Do not collapse lines
- Do not convert header into paragraphs
- Do not stack unrelated fields vertically

### CRITICAL RULE

The header must be rendered using a fixed layout grid/table structure. Never generate the header as
flowing text. Treat it as a professionally typeset examination paper header. Only after the complete
header is rendered should the question paper content begin.

### FOOTER RULE (answer/solved papers)

Unlike the official blank QP templates (which have no footer), solved/answer papers MUST include a
running footer on every page for identification:

```
Left: [paper-identifier]        Center: page-number
```

- Paper identifier: Times Bold, 17pt (left)
- Page number: Times Regular, 12pt (center)
- Footer is rendered via Puppeteer's `displayHeaderFooter` with `footerTemplate`
- The footer template is in `pdf.js`

### P.T.O. RULE (answer/solved papers)

`P.T.O.` (Please Turn Over) is placed in the HTML body RIGHT AFTER the header `<hr>` separator, as a
right-aligned italic element. This means it appears ONLY on page 1 of the document. It is NOT part
of the footer template, which avoids the illogical case of "P.T.O." on the last page.

## Metadata Extraction

The header transform (`src/transforms/header.js`) extracts metadata from the markdown source header
block (between `---` delimiters).

### Supported patterns

| Field              | Pattern                                  | Example                                     |
| ------------------ | ---------------------------------------- | ------------------------------------------- |
| Total Questions    | `Total No. of Questions : X`             | `Total No. of Questions : 8`                |
| Paper code         | `^[A-Z]+-\d+$`                           | `PE-2519` or `P-7539`                       |
| Paper identifier   | `^\[.+\]-\S+$`                           | `[6583]-45` or `[5650]-SPOS`                |
| Department         | `^(SE\|TE\|BE\|FE).*$`                   | `T.E. (Computer Engg./Computer Science)`    |
| Subject            | All-caps line                            | `SYSTEM PROGRAMMING &amp; OPERATING SYSTEM` |
| Pattern info       | `(YYYY Pattern) (Semester - X) (XXXXXX)` | `(2019 Pattern) (Semester - V) (310243)`    |
| Time               | `Time : VALUE`                           | `Time : 2½ Hours`                           |
| Max Marks          | `Max. Marks : X`                         | `Max. Marks : 70`                           |
| Instructions block | After closing `---`                      | Numbered items 1-4                          |

### Fallback defaults

If a field cannot be detected from the markdown, sensible defaults are used.

## How to Verify / Debug Header Output

If you are unsure about exact positioning, font sizes, margins, spacing, or any visual property of
the generated header:

### Step 1 — Ask the user for reference PDFs

Ask the user to provide:

- One or more official SPPU QP format templates (from the SODL library at
  `http://collegecirculars.unipune.ac.in/sites/examdocs/SODL%20Question%20Papers%20Formats/`)
- The actual question paper PDF for the same subject/pattern (e.g., `Nov_Dec_2025.pdf`)

These serve as the ground truth for header layout and footer positioning.

### Step 2 — Run the extraction script

```bash
python3 << 'EOF'
import re
from pypdf import PdfReader
r = PdfReader('/path/to/reference.pdf')
page = r.pages[0]
cs = page.get_contents()
raw = cs.get_data()
text = raw.decode('latin-1')
lines = text.split('\n')
for i, l in enumerate(lines):
    s = l.strip()
    if s and ('Tf' in s or 'Tm' in s or 'Td' in s or 'TJ' in s or 'Tj' in s):
        print(f'{i}: {s[:130]}')
EOF
```

This extracts font selections (`Tf`), font sizes + positions (`Tm`), and text content (`TJ`/`Tj`)
from the reference PDF's content stream.

### Step 3 — Decode font references

Official templates use generic font names (F1, F2, F3, F4, F5). Map them:

| Font Ref | Weight/Style        | Maps To                                          |
| -------- | ------------------- | ------------------------------------------------ |
| F1       | Regular             | Times Regular                                    |
| F2       | Bold                | Times Bold                                       |
| F3       | Regular             | Times Regular (used for Time/Marks/Instructions) |
| F4       | Regular (underline) | Times Regular (underline fill)                   |
| F5       | Symbol              | Zapf Dingbats / Symbol                           |

Actual QPs use Distiller-generated names: | Font Ref | Weight/Style | |----------|-------------| |
TT0 | Times Bold | | TT1 | Times Regular | | TT2 | Times BoldItalic | | TT3 | Times Italic |

### Step 4 — Cross-check against Font Specifications table

Update the table in this document if the reference differs from what's listed.

### Step 5 — Regenerate and verify visually

Regenerate the PDF and check that the output matches both the official template (layout/structure)
and the actual QP (footer/P.T.O./page numbers).

## Implementation Notes

- Uses HTML `<table>` elements with inline styles for layout precision
- Overrides default table borders via inline `border:none` on `<td>`
- Uses HTML entities `&#91;` / `&#93;` for brackets to avoid colliding with the `.marks` CSS
  auto-replacement in `renderer.js`
- The seat number box is an inline `<span>` with CSS border, beside the label
- Instructions: header = bold+italic, items = italic only (solved paper format)
- **Footer** (rendered via Puppeteer `displayHeaderFooter` in `pdf.js`):
  - `[paper-identifier]` left: 17pt Times Bold
  - Page number center: 12pt Times Regular
  - Appears on every page
- **P.T.O.** is in the HTML body (right after header `<hr>`) — page 1 only
- The footer paper identifier is extracted via `<!-- PAPER_ID:[...] -->` HTML comment after bracket
  entity escaping in the header transformation
- Official blank QP templates have NO footer — answer/solved papers add one for page identification

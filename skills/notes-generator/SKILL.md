# Universal Academic Notes Generator

## Overview

Generates 100% syllabus-locked, exam-ready notes for any subject at any university. Produces
structured notes with definitions, mechanism points, diagrams, tables, and examples. Calibrated for
examiner checking behavior across global academic standards.

## How This Skill Works with Any University

1. **User provides**: University name, department/discipline, subject code/name, syllabus topics or
   PDF, exam pattern details
2. **System maps**: The subject to the Universal Subject Framework (see below)
3. **System selects**: Optimal note format(s) based on Notes Type Selection matrix
4. **System generates**: Syllabus-locked notes in chosen format(s)
5. **System calibrates**: Depth, terminology, and structure to match the specific university's exam
   pattern

**Example**: _"Generate notes for [University of Cambridge] [Computer Science] [Algorithms] [Unit 3:
Sorting]"_

## 1. Notes Type Selection

Choose the right note format based on these dimensions:

### Dimension A — Subject Type

| Subject Type      | Characteristics                                       | Recommended Formats                                |
| ----------------- | ----------------------------------------------------- | -------------------------------------------------- |
| **Theory-heavy**  | Law, History, Philosophy, Literature, Management      | Outline, Cornell, Q&A, Summary, Detail/Explanatory |
| **Numerical**     | Mathematics, Physics, Engineering, Finance, Economics | Formula Sheets, Worked Examples, Flowchart-based   |
| **Mixed**         | Computer Science, Chemistry, Biology, Accounting      | Table-based, Mind Map, Flowchart, Cornell          |
| **Conceptual**    | Psychology, Sociology, Political Science, Education   | Mind Map, Cornell, Q&A, Cross-subject Integration  |
| **Lab/Practical** | Lab Sciences, Engineering Labs, Clinical Skills       | Diagram-centric, Flowchart, Rapid Revision         |
| **Language**      | English, French, German, Sanskrit, Linguistics        | Outline, Cornell, Table-based (grammar), Q&A       |

### Dimension B — Exam Type

| Exam Type         | Strategy                           | Recommended Formats                               |
| ----------------- | ---------------------------------- | ------------------------------------------------- |
| **Closed Book**   | Memory-heavy, need recall triggers | Rapid Revision, Mind Map, Cornell, Q&A            |
| **Open Book**     | Reference-heavy, need indexing     | Detailed/Explanatory, Table-based, Formula Sheets |
| **Online/Remote** | Searchable but timed               | Summary, Rapid Revision, Flowchart                |
| **MCQ-based**     | Fact recognition                   | Q&A, Rapid Revision, Table-based                  |
| **Essay-based**   | Argument structure                 | Outline, Cornell, Detailed/Explanatory            |
| **Problem-based** | Method application                 | Flowchart, Formula Sheets, Worked Examples        |
| **Viva/Oral**     | Quick recall                       | Mind Map, Rapid Revision, Q&A                     |

### Dimension C — Time Available

| Timeframe                     | Approach                      | Recommended Formats                                                   |
| ----------------------------- | ----------------------------- | --------------------------------------------------------------------- |
| **< 1 day (Cram)**            | High-density, memory triggers | Rapid Revision, Formula Sheets, Mind Map                              |
| **1-3 days (Quick)**          | Prioritized coverage          | Summary, Q&A, Flowchart, Cornell                                      |
| **1-2 weeks (Moderate)**      | Balanced depth                | Cornell, Table-based, Outline, Diagram-centric                        |
| **> 2 weeks (Comprehensive)** | Deep understanding            | Detailed/Explanatory, Cross-subject Integration, All formats combined |

### Dimension D — Purpose

| Purpose                  | Focus                   | Recommended Formats                             |
| ------------------------ | ----------------------- | ----------------------------------------------- |
| **Last-minute revision** | High-yield, memorizable | Rapid Revision, Formula Sheets, Q&A             |
| **First-time learning**  | Build understanding     | Detailed/Explanatory, Outline, Mind Map         |
| **Exam preparation**     | Exam-aligned practice   | Cornell, Q&A, Flowchart, Table-based            |
| **Assignment reference** | Comprehensive coverage  | Detailed/Explanatory, Cross-subject Integration |
| **Teaching others**      | Clear explanation       | Mind Map, Flowchart, Diagram-centric            |

### Dimension E — Learning Style

| Learning Style         | Best Formats                                      |
| ---------------------- | ------------------------------------------------- |
| **Visual**             | Mind Map, Diagram-centric, Flowchart, Table-based |
| **Verbal/Linguistic**  | Outline, Cornell, Detailed/Explanatory            |
| **Logical/Analytical** | Flowchart, Formula Sheets, Table-based comparison |
| **Read/Write**         | Cornell, Outline, Summary, Q&A                    |
| **Kinesthetic**        | Worked Examples, Diagram-centric (draw/re-draw)   |

## 3. All Note Types / Formats

### 3.1 Outline Notes

**Best for**: Linear thinkers, first pass, theory-heavy subjects

Structure:

```
[UNIT N: TITLE]
  1. [TOPIC A]
      1.1 [Subtopic]
          - Key point
          - Key point
          - Example
      1.2 [Subtopic]
          - Key point
          - Key point
  2. [TOPIC B]
      2.1 [Subtopic]
          ...
```

### 3.2 Cornell Notes

**Best for**: Active recall, exam revision, closed-book prep

Structure:

```
┌────────────────────────────────┬──────────────────────────────────┐
│   CUE COLUMN                    │   NOTES COLUMN                   │
│   (Questions/Keywords)          │   (Main content)                 │
├────────────────────────────────┼──────────────────────────────────┤
│ What is [concept]?             │ Definition and explanation       │
│ Key characteristics?           │ Bullet points                    │
│ How does it differ from X?     │ Comparison                       │
│ Application?                   │ Example                          │
│ Exam tip?                      │ How to answer                    │
├────────────────────────────────┴──────────────────────────────────┤
│   SUMMARY (3-4 sentences covering the entire page)                │
└──────────────────────────────────────────────────────────────────┘
```

### 3.3 Mind Map / Concept Map Notes

**Best for**: Visual learners, seeing connections, brainstorming

Structure (textual representation):

```
                        ┌─────────────────────┐
                        │  CENTRAL CONCEPT     │
                        │  (Topic Title)       │
                        └──────────┬──────────┘
                                   │
             ┌─────────────────────┼─────────────────────┐
             │                     │                     │
    ┌────────┴────────┐  ┌────────┴────────┐  ┌────────┴────────┐
    │   BRANCH 1      │  │   BRANCH 2      │  │   BRANCH 3      │
    │ (Subtopic)      │  │ (Subtopic)      │  │ (Subtopic)      │
    └────────┬────────┘  └────────┬────────┘  └────────┬────────┘
             │                    │                     │
    ┌────────┴────────┐  ┌────────┴────────┐  ┌────────┴────────┐
    │ Leaf 1 │ Leaf 2 │  │ Leaf 1 │ Leaf 2 │  │ Leaf 1 │ Leaf 2 │
    └─────────────────┘  └─────────────────┘  └─────────────────┘
```

### 3.4 Flowchart-Based Notes

**Best for**: Processes, algorithms, workflows, step-by-step procedures

Structure:

```
┌──────────────┐
│   START      │
│ (Condition)  │
└──────┬───────┘
       │
       ▼
┌──────────────┐     YES     ┌──────────────┐
│   DECISION?  │────────────│   ACTION A   │
│              │             └──────┬───────┘
└──────┬───────┘                    │
       │ NO                         │
       ▼                            ▼
┌──────────────┐             ┌──────────────┐
│   ACTION B   │             │   ACTION C   │
└──────┬───────┘             └──────┬───────┘
       │                            │
       └──────────────┬─────────────┘
                      ▼
              ┌──────────────┐
              │    END       │
              │  (Result)    │
              └──────────────┘
```

Accompanied by textual explanation of each step.

### 3.5 Table-Based Comparison Notes

**Best for**: Comparing theories, methods, algorithms, classifications

Structure:

```
┌──────────────────┬──────────────┬──────────────┬──────────────┐
│   DIMENSION      │  OPTION A    │  OPTION B    │  OPTION C    │
├──────────────────┼──────────────┼──────────────┼──────────────┤
│ Definition       │ Text         │ Text         │ Text         │
│ Year/Origin      │ Date/Source  │ Date/Source  │ Date/Source  │
│ Key Principle    │ Description  │ Description  │ Description  │
│ Advantages       │ List         │ List         │ List         │
│ Disadvantages    │ List         │ List         │ List         │
│ Applications     │ Examples     │ Examples     │ Examples     │
│ Exam Frequency   │ High/Med/Low │ High/Med/Low │ High/Med/Low │
└──────────────────┴──────────────┴──────────────┴──────────────┘
```

**Best for**: Active recall, self-testing, exam preparation

Structure:

```

```

## 4. CO-Blood Framework for Any Subject

The **CO-Blood** framework maps Course Outcomes to Bloom's Taxonomy levels, calibrated to any
university's assessment system.

### 4.1 The CO-Blood Matrix

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ COURSE OUTCOME │ BLOOM'S LEVEL │ KEYWORDS                │ EXAM FORMAT      │
├────────────────┼───────────────┼─────────────────────────┼──────────────────┤
│ CO1: Remember  │ L1 — Remember │ Define, List, State,    │ MCQ, Fill-in,    │
│                │               │ Identify, Recall, Label │ Short answer (2M)│
├────────────────┼───────────────┼─────────────────────────┼──────────────────┤
│ CO2: Understand│ L2 — Understand│ Explain, Describe,     │ Short note,      │
│                │               │ Interpret, Illustrate   │ Explain (4M)     │
├────────────────┼───────────────┼─────────────────────────┼──────────────────┤
│ CO3: Apply     │ L3 — Apply    │ Apply, Solve, Use,     │ Numerical,       │
│                │               │ Demonstrate, Implement  │ Problem solving(6M)│
├────────────────┼───────────────┼─────────────────────────┼──────────────────┤
│ CO4: Analyze   │ L4 — Analyze  │ Analyze, Compare,       │ Compare/contrast, │
│                │               │ Differentiate, Examine  │ Case study (8M)  │
├────────────────┼───────────────┼─────────────────────────┼──────────────────┤
│ CO5: Evaluate  │ L5 — Evaluate │ Evaluate, Justify,      │ Justify, Criticize│
│                │               │ Criticize, Assess       │ Design problem   │
├────────────────┼───────────────┼─────────────────────────┼──────────────────┤
│ CO6: Create    │ L6 — Create   │ Design, Develop,        │ Project, Design, │
│                │               │ Construct, Propose      │ Open-ended (10M+)│
└────────────────┴───────────────┴─────────────────────────┴──────────────────┘
```

### 4.2 Applying CO-Blood to Notes

For each topic in the notes, annotate:

```
[TOPIC NAME] — CO2 (Understand) — L2

Content adjusts depth based on Bloom's level:
- L1: Definitions, lists, labels only
- L2: + Explanations, descriptions, examples
- L3: + Problem-solving methods, applications
- L4: + Comparisons, analyses, differentiations
- L5: + Evaluations, justifications, assessments
- L6: + Design methods, creative solutions
```

### 4.3 University-Specific CO-Blood Mapping

Different universities use different outcome frameworks:

- **ABET (USA)**: a-k outcomes → map to Bloom's
- **AACSB (Business)**: Standard 9 → map to Bloom's
- **QAA (UK)**: Subject benchmark statements → map to Bloom's
- **TEQSA (Australia)**: AQF levels → map to Bloom's
- **NAAC / NBA (India)**: CO-PO mapping → Bloom's
- **CTI (France)**: Compétences → Bloom's
- **ANECA (Spain)**: Competencias → Bloom's
- **DAkkA (Germany)**: Qualifikationsziele → Bloom's
- **JABEE (Japan)**: Learning outcomes → Bloom's

## 5. Exam-Specific Note Versions

### 5.1 Closed Book (Memory-Based)

- Focus on Cornell and Mind Map formats
- Include mnemonics, memory triggers, acronyms
- Use Rapid Revision as the final layer
- Prioritize definitions and key points

### 5.2 Open Book (Reference-Based)

- Focus on Detailed/Explanatory and Table-based formats
- Build a personal index / table of contents
- Cross-reference formulas with problem types
- Include worked examples with step-by-step reasoning

### 5.3 Online / Remote Exam

- Focus on Summary and Rapid Revision (quick lookup)
- Organize by searchable headings
- Include digital bookmarks / anchor links
- Prepare answer templates for common question types

### 5.4 MCQ Exam

- Focus on Q&A format with single correct answer
- Include common distractors and how to avoid them
- Use Table-based comparison for similar concepts
- Rapid Revision for factual recall

### 5.5 Essay Exam

- Focus on Outline and Detailed/Explanatory
- Include thesis statements for each topic
- Structure arguments with evidence points
- Include counterarguments

### 5.6 Problem-Solving Exam

- Focus on Flowchart, Formula Sheets, Worked Examples
- Include algorithm/method templates
- Show common mistake patterns
- Include unit checking strategies

### 5.7 Viva / Oral Exam

- Focus on Mind Map and Q&A (spoken format)
- Include one-line definitions (for quick verbal recall)
- Prepare "explain like I'm 5" versions
- Include follow-up question predictions

## 12. Learning Acceleration Engine — Supercharged Retention

This section integrates **25+ evidence-based learning science methods** directly into the notes
output. These methods accelerate learning speed and extend retention duration by engaging multiple
encoding pathways simultaneously.

### 12A — Core Memory & Retention Techniques

| Technique                              | How It Works                                                               | Integration in Notes                                                                                                                              |
| -------------------------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Active Recall / Retrieval Practice** | Brain strengthens memory by actively retrieving info rather than rereading | Notes include Q&A pairs, blank-fill prompts, and self-test sections. Cover the right column and try to recall.                                    |
| **Spaced Repetition (Leitner System)** | Information reviewed at increasing intervals (1d, 3d, 7d, 14d, 30d)        | Notes output with review schedule: Day 1 (first study), Day 2 (recall test), Day 4 (active recall), Day 8 (weak points), Day 16 (exam simulation) |
| **Feynman Technique**                  | Explain concept in simple language as if teaching a child                  | Notes include "Explain in 1 sentence" prompts. If you can't do it simply, you haven't understood it.                                              |
| **Method of Loci (Memory Palace)**     | Attach information to spatial locations in a familiar environment          | Notes include vivid location-based mnemonics. Walk through your house mentally, placing each concept in a specific room.                          |
| **Chunking**                           | Group individual pieces into meaningful 3-5 item chunks                    | Points are grouped into 3-5 chunks with clear chunk labels. Human working memory maxes at ~7 items.                                               |
| **Mnemonic Devices**                   | Acronyms, acrostics, rhymes, songs to encode information                   | Each major topic has a ready-to-use mnemonic device embedded. Example: VIBGYOR for light spectrum.                                                |
| **Narrative Encoding / Storytelling**  | Information wrapped in a story structure (beginning, conflict, resolution) | Topics framed as mini-stories: problem → solution → outcome. Stories are remembered 22x more than facts.                                          |
| **Dual Coding**                        | Combine visual + verbal information for dual encoding pathways             | Every note MUST have a visual element (diagram, flowchart, table, timeline). Visual + text = 2 memory pathways.                                   |

### 12B — Study Frameworks

| Framework              | Method                                                            | Best For                                                   |
| ---------------------- | ----------------------------------------------------------------- | ---------------------------------------------------------- |
| **Pomodoro Technique** | 25min focused study + 5min break. 4 cycles → 15-30min long break. | Sustained concentration over hours. Prevents burnout.      |
| **SQ3R / PQ4R**        | Preview → Question → Read → Reflect → Recite → Review             | Textbook/chapter reading. Forces active processing.        |
| **Cornell Method**     | Split page: cues (left), notes (right), summary (bottom)          | Lecture notes, chapter summaries. Best for revision.       |
| **Mind Mapping**       | Central concept → radiating branches (hierarchical associations)  | Brainstorming, connecting related topics, overview.        |
| **Retrieval Grid**     | Mix questions from current + past topics in a grid format         | Interleaving + spaced repetition. Fights forgetting curve. |
| **Blurting**           | Write everything you know about a topic without looking at notes  | Identifies knowledge gaps. Used before and after studying. |

### 12C — Learning Science Principles in Action

| Principle                   | What It Means                                                                                | Implementation                                                                                           |
| --------------------------- | -------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| **Testing Effect**          | Taking a test on material produces better retention than restudying the same material        | Notes end with 3 self-test questions. Answer before looking at the answer key.                           |
| **Generation Effect**       | Generating answers yourself leads to better memory than reading them                         | Notes include fill-in-the-blank and "complete the explanation" prompts.                                  |
| **Desirable Difficulties**  | Making learning harder (within reason) improves long-term retention                          | Study the harder version first. Notes sometimes deliberately omit an obvious step for you to figure out. |
| **Interleaving**            | Mixing different topics within a single study session                                        | Notes include cross-topic connections: "How does this concept relate to [previous topic]?"               |
| **Varied Practice**         | Practicing the same skill under different conditions                                         | Each concept has multiple practice contexts (theory, numerical, diagram, comparison).                    |
| **Contextual Interference** | Mixing similar concepts causes short-term confusion but long-term mastery                    | Notes group similar but distinct concepts (e.g., TCP vs UDP, SDLC vs Agile) for deliberate contrast.     |
| **Self-Explanation Effect** | Explaining why a fact is true leads to deeper understanding than just noting the fact        | Each numbered point includes a "Why this matters" sub-line when the concept is non-obvious.              |
| **Encoding Specificity**    | Memory is strongest when study context matches recall context                                | Notes match exam format: if exam is written, study by writing. If oral, study by speaking aloud.         |
| **Depth of Processing**     | Deeper processing (meaning, connections) beats shallow processing (repetition, highlighting) | No passive highlighting. Every line requires active processing: summarize, connect, apply.               |
| **Elaboration**             | Adding more detail and connections to new information                                        | Notes include "Connect to: [related real-world example]" prompts.                                        |

### 12D — Supercharged Learning Workflow

For each unit of study, follow this cyclical workflow:

```
CYCLE 1 — SURVEY (30 min)
  - Preview all headings, diagrams, summaries
  - Write 3 questions you expect the material to answer
  - Set your intention: "By the end, I will be able to..."

CYCLE 2 — DEEP READ + NOTES (60-90 min)
  - Read section by section
  - Generate Cornell/Mind Map/Flowchart notes (auto-selected format)
  - After each section: pause and recall without looking

CYCLE 3 — ACTIVE RECALL (30 min)
  - Close all notes
  - Write everything you remember (Blurting technique)
  - Compare with notes → mark gaps in RED
  - Study only the gaps

CYCLE 4 — ELABORATION (30 min)
  - For each major concept: teach it aloud (Feynman Technique)
  - Connect concept to: real-world example, analogies, previous knowledge
  - Create one mnemonic device per difficult concept

CYCLE 5 — TESTING (30 min)
  - Answer the self-test questions at the end of these notes
  - Attempt past exam questions on this topic
  - Score yourself. For wrong answers: trace back to which note point you missed.

CYCLE 6 — SPACED REVIEW (ongoing)
  - Day 1: study (cycles 1-5)
  - Day 2: active recall test on Day 1 topics (5 min)
  - Day 4: spaced recall test on Day 1 + Day 2 topics (10 min)
  - Day 8: expand test to Day 1-4 topics (15 min)
  - Day 16: comprehensive test (30 min)
  - Exam eve: rapid skim of all notes (visual + mnemonics only)
```

### 12E — Bloom's Taxonomy as a Learning Accelerator

Use Bloom's levels hierarchically — never skip a level:

| Level               | Learning Goal                       | Technique                                   |
| ------------------- | ----------------------------------- | ------------------------------------------- |
| **L1 — Remember**   | Reproduce facts, terms, definitions | Flashcards, mnemonics, spaced repetition    |
| **L2 — Understand** | Explain in your own words           | Feynman Technique, paraphrase each point    |
| **L3 — Apply**      | Use concept in a new situation      | Solve a fresh problem, write a code snippet |
| **L4 — Analyze**    | Break down, compare, find patterns  | Comparison tables, "What if..." scenarios   |
| **L5 — Evaluate**   | Judge, justify, critique            | Debate both sides, write a justification    |
| **L6 — Create**     | Produce something original          | Design a system, compose a solution         |

**Accelerator Rule**: Never spend more than 20% of time on L1 (pure memorization). Spend 40% on
L2-L3 (understanding + application — highest exam ROI). Spend 30% on L4-L5 (analysis + evaluation —
differentiator for top grades). Spend 10% on L6 (creation — essential for design-heavy subjects).

### 12G — Forgetting Curve Defense

Ebbinghaus Forgetting Curve shows we forget ~50% within 1 hour and ~70% within 24 hours without
review. These notes include built-in defense:

```
Study Event                Retention After                        Action
───────────────            ─────────────────────                  ──────
Initial study (Day 1)      100% knowledge                         Full cycles 1-5
After 1 hour               ~50% retained                          Mental recall (2 min)
After 24 hours             ~30% retained                          Active recall test (5 min)
After 7 days               ~20% retained                          Spaced review + weak-spot focus (10 min)
After 30 days              ~15% retained                          Comprehensive review + exam simulation (30 min)
```

Each active recall session restores retention to ~95%. Each spaced repetition extends the retention
duration by ~3x.

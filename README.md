## 🛠️ How to Use with ChatGPT, Claude, or Gemini

If you are using the raw AI models, use the markdown prompt files provided in this repository.

### Workflow:
1. **Choose your tool:** Select the prompt file that matches your goal (e.g., `Exam_Answer_Generator.md`).
2. **Copy the prompt:** Copy the *entire contents* of the markdown file.
3. **Paste into the AI:** Paste it as the first message / system prompt.
4. **Provide Context:** Upload your **SPPU Syllabus PDF** and any **Previous Year Question (PYQ) Papers**.
5. **Start Generating:** Ask for specific answers, notes, or analysis!

## 📂 The Prompt Library

Here are the core system prompts available in this repository:

### 1. [Exam Answer Generator](Exam_Answer_Generator.md)
**Purpose:** Produces `EXAM-READY, FULL-MARKS THEORY ANSWERS`.
*   Matches SPPU checking behavior (ticks, keywords).
*   Follows strict structure: Definition → Numbered Points → Diagram (if needed) → Example (if needed) → Conclusion.
*   Includes exact marks-to-depth calibration (e.g., 6 marks = 6-7 points + example).
*   **Bonus:** Features built-in intelligence for all major Computer Engineering subjects.

### 2. [Notes Generator (Exam Ready)](Notes_Generator.md)
**Purpose:** Creates `100% syllabus-locked, exam-ready NOTES`.
*   Suppresses extra-syllabus depth; focuses purely on examinable content.
*   Uses a highly scannable, bullet-point format with bolded keywords.
*   Automatically generates ASCII diagrams for structural concepts.

### 3. [IMP Topics & Questions Generator](IMP_Generator.md)
**Purpose:** Generates a strategic preparation plan (`Must-Prepare`, `Selective`, `Skim`).
*   Analyzes PYQs to identify exact wording repetitions and high-probability topics.
*   Sorts questions by marks and Bloom's Taxonomy level.

### 4. [PYQ Analyzer](PYQ_Analyzer.md)
**Purpose:** Deep analysis of question papers to decode examiner psychology.
*   Understands the strict SPPU `OR` rule (compulsory choice blocks).
*   Identifies which Course Outcomes (COs) are frequently tested.

### 5. [Assignment Answer Writer](Assignment_Prompt.md)
**Purpose:** Generates academic assignment answers.
*   Designed for 5-7 mark university evaluation depth.
*   Resembles natural, handwritten student assignments (no robotic section headers).

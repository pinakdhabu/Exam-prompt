# Product Context — Exam-Prompt

## Why This Project Exists
Students spend hundreds of hours preparing for exams — reading textbooks, writing notes, practicing answers. Most study methods are passive (rereading, highlighting) and ineffective (~20% retention). AI coding agents have the capability to generate perfect exam answers, but they need domain-specific instructions to do so.

This project bridges that gap by providing **24 pre-built skill modules** that any AI agent can load and follow. Each skill contains expert-level instructions for a specific exam task — answer writing, notes generation, PYQ analysis, etc.

## Problem Solved
- **For students**: Instant access to an AI personal tutor that knows their university's exam pattern
- **For AI agents**: Pre-built, battle-tested instructions so they don't need to guess how to write exam answers
- **For contributors**: A structured system to add new subjects, skills, and sample papers

## Target Users
1. **University students** (primary) — Any department, any year, any university
2. **AI coding agents** (Claude Code, Cursor, Windsurf, Aider, Cline, Copilot, Codex, OpenCode)
3. **Educators** — Can use the exam paper generator to create practice papers

## Core Philosophy
- **100% free forever** — No paid tiers, no premium features
- **University-agnostic** — Works for SPPU, VTU, JNTU, Oxford, MIT, any
- **Agent-first** — Designed for AI agents to discover and load automatically
- **KISS** — Skills are just Markdown files. Simple, portable, composable

## What Makes This Different
- Not just a prompt — a full **skills architecture** with 24 modules
- Not just SPPU — **any university worldwide** via the adapter skill
- Not just answers — **full ecosystem**: notes, PYQ analysis, IMP topics, MCQs, flashcards, viva prep, cram plans, lab reports, formula sheets, mind maps, case studies, essay grading

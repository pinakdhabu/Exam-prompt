## 23A53101: Discrete Mathematics

**Credits:** 3 | **CIE:** 30 Marks | **SEE:** 70 Marks

### Course Objectives

- To introduce mathematical logic and proof techniques
- To understand set theory, relations, functions, and algebraic structures
- To study counting principles, graph theory, and trees
- To apply discrete mathematical concepts in computer science

### Course Outcomes

| CO  | Description                                                    |
| --- | -------------------------------------------------------------- |
| CO1 | Apply logical reasoning and mathematical proof techniques      |
| CO2 | Use set theory, relations, and functions for modeling problems |
| CO3 | Apply counting principles and combinatorial reasoning          |
| CO4 | Model problems using graph theory and trees                    |
| CO5 | Apply algebraic structures in computing contexts               |

### Course Contents

#### Unit I: Mathematical Logic and Proofs (10 Hours)

- Propositions, Logical Connectives, Truth Tables
- Tautologies, Contradictions, Logical Equivalences
- Predicates and Quantifiers
- Rules of Inference
- Proof Techniques: Direct, Indirect, Contradiction, Mathematical Induction

#### Unit II: Sets, Relations, and Functions (10 Hours)

- Set Operations, Venn Diagrams, Cartesian Products
- Relations: Properties, Matrix Representation, Digraphs
- Closure of Relations, Equivalence Relations, Partial Orders
- Hasse Diagrams, Lattices
- Functions: Injective, Surjective, Bijective, Composition, Inverse

#### Unit III: Counting Principles (10 Hours)

- Pigeonhole Principle
- Permutations and Combinations
- Binomial Theorem
- Inclusion-Exclusion Principle
- Recurrence Relations: Solving Linear Recurrences

#### Unit IV: Graph Theory (10 Hours)

- Basic Terminology, Types of Graphs
- Graph Representations: Adjacency Matrix, Incidence Matrix
- Graph Isomorphism, Connectivity
- Euler and Hamiltonian Paths
- Planar Graphs, Graph Coloring

#### Unit V: Trees and Algebraic Structures (10 Hours)

- Trees: Properties, Rooted Trees, Binary Trees
- Tree Traversals: Preorder, Inorder, Postorder
- Spanning Trees: Prim's and Kruskal's Algorithms
- Algebraic Structures: Groups, Semigroups, Monoids, Rings, Fields

### Learning Resources

#### Textbooks

1. Kenneth H. Rosen, "Discrete Mathematics and Its Applications", 8th Edition, McGraw Hill
2. Tremblay and Manohar, "Discrete Mathematical Structures with Applications to CS", McGraw Hill

#### Reference Books

1. Narsingh Deo, "Graph Theory with Applications to Engineering and CS", PHI
2. J.P. Tremblay, R. Manohar, "Discrete Mathematical Structures", McGraw Hill

## 23A53102: Data Structures

**Credits:** 3 | **CIE:** 30 Marks | **SEE:** 70 Marks

### Course Objectives

- To understand various data structures and their operations
- To analyze time and space complexity of algorithms
- To implement linear and non-linear data structures
- To apply appropriate data structures for problem solving

### Course Outcomes

| CO  | Description                                              |
| --- | -------------------------------------------------------- |
| CO1 | Analyze algorithms using asymptotic notations            |
| CO2 | Implement linear data structures: arrays, stacks, queues |
| CO3 | Implement linked lists and their variations              |
| CO4 | Implement trees, graphs, and hash tables                 |
| CO5 | Apply sorting and searching algorithms                   |

### Course Contents

#### Unit I: Introduction to Data Structures and Algorithms (10 Hours)

- Data Structures: Classification, ADT
- Algorithm Analysis: Space and Time Complexity
- Asymptotic Notations: Big-O, Omega, Theta
- Recursion: Types, Implementation, Tail Recursion
- Algorithm Design Strategies: Divide and Conquer

#### Unit II: Arrays, Searching and Sorting (10 Hours)

- Arrays: Representation, Operations, Sparse Matrix
- Searching: Linear, Binary, Fibonacci Search
- Sorting: Bubble, Selection, Insertion, Quick, Merge, Heap, Radix Sort
- Comparison of Sorting Algorithms

#### Unit III: Stacks and Queues (10 Hours)

- Stack: ADT, Array and Linked Implementation
- Applications: Expression Evaluation, Infix/Postfix/Prefix
- Queue: ADT, Array and Linked Implementation
- Circular Queue, Deque, Priority Queue

#### Unit IV: Linked Lists (10 Hours)

- Singly Linked List: Operations
- Doubly Linked List
- Circular Linked List
- Polynomial Representation using Linked Lists
- Generalized Linked Lists

#### Unit V: Trees, Graphs and Hashing (10 Hours)

- Trees: Binary Tree, BST, Tree Traversals
- AVL Trees, B-Trees
- Graphs: DFS, BFS, MST (Prim's, Kruskal's), Shortest Path (Dijkstra's)
- Hashing: Hash Functions, Collision Resolution

### Learning Resources

#### Textbooks

1. Horowitz and Sahani, "Fundamentals of Data Structures in C++", University Press
2. Mark A. Weiss, "Data Structures and Algorithm Analysis in C++", Pearson

#### Reference Books

1. Thomas H. Cormen et al., "Introduction to Algorithms", MIT Press
2. A.V. Aho, J.E. Hopcroft, J.D. Ullman, "Data Structures and Algorithms", Pearson

## 23A53103: Object Oriented Programming using Java

**Credits:** 3 | **CIE:** 30 Marks | **SEE:** 70 Marks

### Course Objectives

- Understand OOP concepts and Java programming
- Learn inheritance, polymorphism, and exception handling
- Study Java I/O, collections, and multithreading

### Course Outcomes

| CO  | Description                                                  |
| --- | ------------------------------------------------------------ |
| CO1 | Apply OOP concepts: encapsulation, inheritance, polymorphism |
| CO2 | Write Java programs using classes, objects, and interfaces   |
| CO3 | Implement exception handling and multithreading              |
| CO4 | Use Java I/O streams and collections framework               |
| CO5 | Develop GUI applications using Java Swing/JavaFX             |

### Course Contents

#### Unit I: OOP Fundamentals and Java Basics (10 Hours)

- OOP Principles: Encapsulation, Inheritance, Polymorphism, Abstraction
- Java: History, JVM Architecture, Data Types
- Operators, Control Statements, Arrays
- Class and Object: Definition, Constructors, this Keyword

#### Unit II: Inheritance, Packages, and Interfaces (10 Hours)

- Inheritance: Types, super Keyword, Method Overriding
- Abstract Classes and Methods
- Interfaces: Definition, Multiple Inheritance
- Packages: Creating, Importing, Access Protection

#### Unit III: Exception Handling and Multithreading (10 Hours)

- Exception Types: Checked, Unchecked
- try, catch, throw, throws, finally
- Custom Exceptions
- Multithreading: Thread Class, Runnable Interface
- Thread Synchronization, Inter-thread Communication

#### Unit IV: I/O Streams and Collections (10 Hours)

- Byte Streams: InputStream, OutputStream
- Character Streams: Reader, Writer
- Serialization
- Collections Framework: List, Set, Map, Queue
- Generics

#### Unit V: GUI Programming and Event Handling (10 Hours)

- AWT: Components, Containers, Layout Managers
- Swing: JFrame, JButton, JTextField
- Event Delegation Model
- Adapter Classes, Inner Classes
- Applet Basics

### Learning Resources

#### Textbooks

1. Herbert Schildt, "Java: The Complete Reference", 12th Edition, McGraw Hill
2. E. Balagurusamy, "Programming with Java: A Primer", 6th Edition, McGraw Hill

#### Reference Books

1. Cay S. Horstmann, "Core Java Volume I — Fundamentals", Pearson
2. Bruce Eckel, "Thinking in Java", 4th Edition, PHI

## CSC301: Engineering Mathematics III

**Credits:** 4 | **CIE:** 25 Marks | **SEE:** 75 Marks

### Course Objectives

- To study linear differential equations, Fourier transforms, and Z-transforms
- To understand probability, statistics, and numerical methods

### Course Outcomes

| CO  | Description                                                       |
| --- | ----------------------------------------------------------------- |
| CO1 | Solve linear differential equations using various methods         |
| CO2 | Apply Fourier and Z-transforms to continuous and discrete systems |
| CO3 | Apply statistical methods for data analysis and prediction        |
| CO4 | Solve algebraic and transcendental equations numerically          |
| CO5 | Perform numerical integration and solve ODEs numerically          |

### Course Contents

#### Unit I: Linear Differential Equations (08 Hours)

- LDE of nth order with constant coefficients
- Complementary function and Particular integral
- Method of variation of parameters
- Cauchy's and Legendre's differential equations
- Simultaneous differential equations

#### Unit II: Fourier and Z-Transforms (08 Hours)

- Fourier integral theorem
- Fourier sine and cosine transforms
- Z-transform: Definition, properties, standard sequences
- Inverse Z-transform
- Solution of difference equations using Z-transform

#### Unit III: Probability and Statistics (08 Hours)

- Measures of central tendency and dispersion
- Moments, skewness, kurtosis
- Correlation and regression
- Probability distributions: Binomial, Poisson, Normal
- Hypothesis testing: Chi-square test, t-test

#### Unit IV: Numerical Methods — Algebraic and Transcendental (08 Hours)

- Bisection method, Regula-Falsi, Newton-Raphson
- Gauss elimination, LU decomposition
- Gauss-Seidel and Jacobi methods
- Curve fitting: Least squares method

#### Unit V: Numerical Integration and ODEs (08 Hours)

- Finite differences: Newton's forward/backward interpolation
- Lagrange's interpolation
- Numerical integration: Trapezoidal, Simpson's 1/3, 3/8 rules
- Euler's method, Runge-Kutta 4th order method

### Learning Resources

#### Textbooks

1. B.V. Ramana, "Higher Engineering Mathematics", Tata McGraw Hill
2. B.S. Grewal, "Higher Engineering Mathematics", Khanna Publishers

#### Reference Books

1. Erwin Kreyszig, "Advanced Engineering Mathematics", Wiley
2. S.L. Ross, "Differential Equations", Wiley

## CSC302: Discrete Mathematics

**Credits:** 3 | **CIE:** 25 Marks | **SEE:** 75 Marks

### Course Objectives

- Introduce set theory, logic, and proof techniques
- Study relations, functions, algebraic structures, and graph theory
- Apply counting principles and combinatorial techniques

### Course Outcomes

| CO  | Description                                         |
| --- | --------------------------------------------------- |
| CO1 | Apply set theory and logic for problem solving      |
| CO2 | Model problems using relations and functions        |
| CO3 | Solve counting problems using combinatorial methods |
| CO4 | Apply graph theory for solving real-world problems  |
| CO5 | Apply algebraic structures in computing contexts    |

### Course Contents

#### Unit I: Set Theory and Logic (08 Hours)

- Sets, Operations, Cardinality
- Propositional Logic: Connectives, Truth Tables
- Logical Equivalences, Tautologies
- Predicates and Quantifiers
- Methods of Proof

#### Unit II: Relations and Functions (08 Hours)

- Relations: Properties, Closures
- Equivalence Relations, Partial Orders
- Hasse Diagrams, Lattices
- Functions: Injective, Surjective, Bijective
- Composition, Inverse, Recursive Functions

#### Unit III: Combinatorics (08 Hours)

- Basic Counting: Sum and Product Rules
- Permutations and Combinations
- Pigeonhole Principle
- Inclusion-Exclusion
- Recurrence Relations

#### Unit IV: Graph Theory (08 Hours)

- Graph Terminology, Types
- Graph Representations
- Euler and Hamiltonian Paths
- Trees: Properties, Spanning Trees
- MST: Prim's, Kruskal's

#### Unit V: Algebraic Structures (08 Hours)

- Groups: Definition, Properties, Subgroups
- Cyclic Groups, Cosets
- Rings, Integral Domains
- Fields
- Homomorphisms and Isomorphisms

### Learning Resources

#### Textbooks

1. Kenneth Rosen, "Discrete Mathematics and Its Applications", McGraw Hill
2. C.L. Liu, "Elements of Discrete Mathematics", McGraw Hill

## CSC303: Data Structures

**Credits:** 3 | **CIE:** 25 Marks | **SEE:** 75 Marks

### Course Objectives

- Understand various data structures and their operations
- Analyze algorithm complexity
- Select appropriate data structures for problem solving

### Course Outcomes

| CO  | Description                                             |
| --- | ------------------------------------------------------- |
| CO1 | Analyze algorithm complexity using asymptotic notations |
| CO2 | Implement stacks, queues, and linked lists              |
| CO3 | Implement trees and graph algorithms                    |
| CO4 | Apply searching and sorting techniques                  |
| CO5 | Implement hashing techniques                            |

### Course Contents

#### Unit I: Algorithm Analysis and Arrays (08 Hours)

- Data Structures: Classification, ADT
- Algorithm Complexity: Big-O, Omega, Theta
- Arrays: Representation, Operations
- Sparse Matrix
- Polynomial Operations

#### Unit II: Searching, Sorting, Stacks, and Queues (08 Hours)

- Searching: Linear, Binary
- Sorting: Bubble, Selection, Insertion, Quick, Merge
- Stack: ADT, Implementation, Applications
- Queue: ADT, Types (Circular, Priority, Deque)

#### Unit III: Linked Lists (08 Hours)

- Singly Linked List: Operations
- Doubly Linked List
- Circular Linked List
- Polynomial using Linked List
- Generalized Linked List

#### Unit IV: Trees and Graphs (08 Hours)

- Binary Tree: Representations, Traversals
- Binary Search Tree: Operations
- AVL Trees, B-Trees
- Graphs: BFS, DFS, MST, Shortest Path

#### Unit V: Hashing and File Structures (08 Hours)

- Hash Functions: Division, Folding, Mid-square
- Collision Resolution: Chaining, Open Addressing
- Hashing Applications
- File Organizations: Sequential, Indexed, Direct

### Learning Resources

#### Textbooks

1. Horowitz and Sahani, "Fundamentals of Data Structures in C++", University Press
2. Mark A Weiss, "Data Structures and Algorithm Analysis in C++", Pearson

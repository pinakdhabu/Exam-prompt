## BCS601: Machine Learning

**Teaching Scheme:** Theory: 03 Hours/Week | **Credits:** 03 | **Total Hours:** 40

**Examination:** CIE: 50 Marks, SEE: 50 Marks, Total: 100 Marks

**Examination Nature:** Theory (03 Hours)

### Course Objectives

- Provide an in-depth understanding of machine learning algorithms and techniques.
- Develop skills to implement supervised, unsupervised, and reinforcement learning algorithms.
- Understand model evaluation, selection, and improvement strategies.

### Course Outcomes

| CO  | Description                                                                             |
| --- | --------------------------------------------------------------------------------------- |
| CO1 | Explain the fundamentals of machine learning and various learning paradigms             |
| CO2 | Implement and analyze supervised learning algorithms for classification and regression  |
| CO3 | Apply unsupervised learning techniques for data clustering and dimensionality reduction |
| CO4 | Evaluate model performance using appropriate metrics and validation techniques          |
| CO5 | Understand reinforcement learning and ensemble methods                                  |

### Course Contents

#### Module 1: Introduction to Machine Learning (08 Hours)

- What is Machine Learning?
- Types of Learning: Supervised, Unsupervised, Semi-supervised, Reinforcement
- Key Terminology: Features, Labels, Training, Testing
- Applications of Machine Learning
- AI vs ML vs Deep Learning
- Python Libraries for ML: NumPy, Pandas, Scikit-learn
- Data Preprocessing: Handling Missing Values, Feature Scaling, Encoding

#### Module 2: Regression and Model Evaluation (08 Hours)

- Simple Linear Regression
- Multiple Linear Regression
- Polynomial Regression
- Ridge and Lasso Regression
- Bias-Variance Tradeoff
- Cross-Validation: k-fold, Leave-One-Out
- Performance Metrics: MSE, RMSE, MAE, R²

#### Module 3: Classification Algorithms (08 Hours)

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Trees: ID3, C4.5, CART
- Support Vector Machines (SVM)
- Naive Bayes Classifier
- Evaluation Metrics: Confusion Matrix, Precision, Recall, F1-Score, ROC AUC

#### Module 4: Clustering and Dimensionality Reduction (08 Hours)

- K-Means Clustering
- Hierarchical Clustering: Agglomerative, Divisive
- DBSCAN
- Principal Component Analysis (PCA)
- t-SNE for Visualization
- Evaluation: Elbow Method, Silhouette Score

#### Module 5: Ensemble Learning and Reinforcement Learning (08 Hours)

- Ensemble Methods: Bagging, Boosting, Stacking
- Random Forest
- AdaBoost, Gradient Boosting, XGBoost
- Introduction to Reinforcement Learning
- Markov Decision Process
- Q-Learning
- Exploration vs Exploitation

### Learning Resources

#### Textbooks

1. Tom Mitchell, "Machine Learning", McGraw-Hill, 1997
2. Christopher Bishop, "Pattern Recognition and Machine Learning", Springer, 2006
3. Ethem Alpaydin, "Introduction to Machine Learning", 4th Edition, MIT Press, 2020

#### Reference Books

1. Shai Shalev-Shwartz, Shai Ben-David, "Understanding Machine Learning", Cambridge University
   Press, 2014
2. Gareth James et al., "An Introduction to Statistical Learning", Springer, 2021

## BCS602: Full Stack Development (IPCC)

**Teaching Scheme:** Theory: 03 Hours/Week, Practical: 02 Hours/Week

**Credits:** 04 (Theory 3 + Practical 1)

**Examination:** CIE: 50 Marks, SEE: 50 Marks, Total: 100 Marks

**Examination Nature:** Theory/Practical (Integrated)

### Course Objectives

- Understand full stack web development architecture and technologies
- Build responsive front-end interfaces using modern frameworks
- Develop server-side applications and RESTful APIs
- Manage databases and deploy full stack applications

### Course Outcomes

| CO  | Description                                                                    |
| --- | ------------------------------------------------------------------------------ |
| CO1 | Design and develop responsive web interfaces using HTML5, CSS3, and JavaScript |
| CO2 | Build dynamic front-end applications using React.js                            |
| CO3 | Develop server-side logic and RESTful APIs using Node.js and Express           |
| CO4 | Design and manage databases for web applications                               |
| CO5 | Deploy and maintain full stack applications                                    |

### Course Contents

#### Module 1: Front-End Fundamentals (08 Hours)

- HTML5: Semantic Elements, Forms, Multimedia
- CSS3: Selectors, Box Model, Flexbox, Grid, Animations
- JavaScript: ES6+ Features, DOM Manipulation, Events
- AJAX, Fetch API, Promises, Async/Await
- Responsive Design: Media Queries, Bootstrap

#### Module 2: React.js (08 Hours)

- React Fundamentals: JSX, Components, Props, State
- Hooks: useState, useEffect, useContext, useReducer
- Component Lifecycle
- Event Handling, Conditional Rendering, Lists and Keys
- React Router: Navigation, Protected Routes
- State Management: Context API, Redux Basics

#### Module 3: Node.js and Express (08 Hours)

- Node.js: Event Loop, Modules, NPM
- Express.js: Routing, Middleware, Error Handling
- REST API Design: CRUD Operations
- Authentication: JWT, OAuth 2.0, Sessions
- File Upload, Email Services

#### Module 4: Databases (08 Hours)

- SQL Databases: PostgreSQL/MySQL, Schema Design, Queries
- NoSQL: MongoDB, Mongoose ODM
- ORM: Prisma, Sequelize
- Database Relationships: One-to-One, One-to-Many, Many-to-Many
- Caching with Redis

#### Module 5: DevOps and Deployment (08 Hours)

- Version Control: Git, GitHub, Branching Strategies
- Containers: Docker, Docker Compose
- CI/CD: GitHub Actions, Jenkins
- Cloud Deployment: AWS (EC2, S3), Vercel, Netlify, Heroku
- Monitoring, Logging, Performance Optimization

### Practical Component (IPCC)

1. Create a responsive portfolio website using HTML, CSS, Bootstrap
2. Build a calculator application using JavaScript
3. Develop a todo list application using React.js with hooks
4. Implement a REST API for a blog application using Node.js + Express
5. Connect the API to MongoDB and implement CRUD operations
6. Add JWT authentication to the application
7. Create a front-end dashboard with React and connect to the API
8. Containerize the application using Docker
9. Deploy the application to cloud platform
10. Mini-project: Full stack application (E-commerce, Social Media, Project Management)

## BCS603: Cloud Computing (IPCC)

**Teaching Scheme:** Theory: 03 Hours/Week, Practical: 02 Hours/Week

**Credits:** 04 (Theory 3 + Practical 1)

**Examination:** CIE: 50 Marks, SEE: 50 Marks, Total: 100 Marks

**Examination Nature:** Theory/Practical (Integrated)

### Course Objectives

- Understand cloud computing fundamentals and service models
- Learn virtualization concepts and cloud architecture
- Explore cloud storage, security, and deployment strategies

### Course Outcomes

| CO  | Description                                                         |
| --- | ------------------------------------------------------------------- |
| CO1 | Explain cloud computing models, services, and deployment strategies |
| CO2 | Analyze virtualization techniques and cloud architecture components |
| CO3 | Implement cloud storage solutions and data management techniques    |
| CO4 | Evaluate cloud security mechanisms and compliance requirements      |
| CO5 | Design and deploy applications on cloud platforms                   |

### Course Contents

#### Module 1: Cloud Computing Fundamentals (08 Hours)

- Definition, Evolution, and Characteristics
- Service Models: IaaS, PaaS, SaaS, FaaS, XaaS
- Deployment Models: Public, Private, Hybrid, Community
- Cloud Computing benefits and challenges
- NIST Cloud Computing Reference Architecture
- Cloud Enabling Technologies: Broadband Networks, Data Centers, Virtualization
- Cloud Economics and TCO

#### Module 2: Virtualization (08 Hours)

- Virtualization: Types (Server, Storage, Network, Desktop)
- Hypervisors: Type 1 (Bare-metal), Type 2 (Hosted)
- Virtual Machines: Creation, Migration, Snapshots
- Containerization: Docker, Kubernetes Basics
- Comparison: VMs vs Containers
- Software-Defined Networking (SDN)
- Virtual SAN

#### Module 3: Cloud Infrastructure and Services (08 Hours)

- AWS: EC2, S3, VPC, Lambda, RDS, DynamoDB, CloudFront
- Azure: Virtual Machines, Blob Storage, Functions, SQL Database
- Google Cloud: Compute Engine, Cloud Storage, Cloud Functions
- Load Balancing, Auto-scaling
- Content Delivery Networks (CDN)
- Serverless Computing: AWS Lambda, Azure Functions

#### Module 4: Cloud Storage and Data Management (08 Hours)

- Cloud Storage Types: Object, Block, File
- Amazon S3: Buckets, Objects, Versioning, Lifecycle Policies
- Databases in Cloud: RDS, DynamoDB, Cloud SQL, Firestore
- Data Backup and Disaster Recovery
- Big Data in Cloud: Hadoop, Spark on EMR
- Data Warehousing: Redshift, BigQuery

#### Module 5: Cloud Security and Migration (08 Hours)

**Cloud Security:**

- Shared Responsibility Model
- Identity and Access Management (IAM): Users, Groups, Roles, Policies
- Encryption: At Rest, In Transit, Key Management (KMS)
- Security Groups, Network ACLs, WAF

**Compliance:**

- GDPR, HIPAA, SOC, PCI DSS

**Cloud Migration:**

- Migration Strategies: Rehost, Replatform, Refactor, Retire, Retain
- Migration Phases: Assess, Mobilize, Migrate & Modernize
- AWS Migration Tools: AWS Migration Hub, DMS, SMS

### Practical Component (IPCC)

1. Create a virtual machine on AWS EC2 and configure security groups
2. Deploy a static website on AWS S3 with CloudFront CDN
3. Set up a relational database using AWS RDS
4. Create serverless functions using AWS Lambda
5. Build a scalable web application with load balancing and auto-scaling
6. Implement Docker containerization for a web application
7. Deploy a containerized app on AWS ECS/EKS
8. Configure IAM roles and policies
9. Implement a CI/CD pipeline using AWS CodePipeline
10. Mini-project: Deploy a full stack application on cloud

## BCS656A: Software Testing (Professional Elective)

**Teaching Scheme:** Theory: 03 Hours/Week | **Credits:** 03 | **Total Hours:** 40

**Examination:** CIE: 50 Marks, SEE: 50 Marks, Total: 100 Marks

### Course Objectives

- Understand software testing fundamentals and methodologies
- Learn test planning, design, and execution
- Explore automation testing tools and frameworks

### Course Outcomes

| CO  | Description                                               |
| --- | --------------------------------------------------------- |
| CO1 | Explain software testing principles and levels of testing |
| CO2 | Design effective test cases using various techniques      |
| CO3 | Apply automation testing tools for efficient testing      |
| CO4 | Evaluate software quality using appropriate metrics       |
| CO5 | Implement testing in agile and DevOps environments        |

### Course Contents

#### Module 1: Fundamentals of Software Testing (08 Hours)

- Testing: Definition, Goals, Principles
- Testing vs Debugging
- Verification and Validation
- Levels of Testing: Unit, Integration, System, Acceptance
- Static vs Dynamic Testing
- Test Planning and Documentation

#### Module 2: Test Case Design Techniques (08 Hours)

- White Box Testing: Statement, Branch, Path, Condition Coverage
- Black Box Testing: BVA, Equivalence Partitioning, State Transition
- Experience-Based Testing: Error Guessing, Exploratory Testing
- Use Case Testing

#### Module 3: Test Management and Automation (08 Hours)

- Test Organization, Test Planning
- Test Estimation: Metrics-based, Expert-based
- Test Execution, Defect Management
- Introduction to Automation Testing
- Selenium: IDE, WebDriver, Grid
- TestNG, JUnit

#### Module 4: Advanced Testing (08 Hours)

- Performance Testing: Load, Stress, Spike, Endurance
- Security Testing
- API Testing: Postman, REST Assured
- Mobile Testing
- Database Testing

#### Module 5: Testing in Agile and DevOps (08 Hours)

- Agile Testing: Test-driven Development (TDD), Behavior-driven Development (BDD)
- Cucumber, Gherkin
- Continuous Testing in CI/CD Pipelines
- Shift-Left Testing
- AI in Software Testing

# Assessment Details (Common for All Courses)

## CIE and SEE Structure

- **CIE:** 50% weightage (25 marks assignment + 25 marks tests)
- **SEE:** 50% weightage (03 hours, 10 questions, answer 5, scaled to 50)
- Minimum passing: 40% overall (min 35% in SEE)

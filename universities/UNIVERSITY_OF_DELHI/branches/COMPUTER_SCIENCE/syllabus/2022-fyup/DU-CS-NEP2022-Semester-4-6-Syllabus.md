## DSC-10: Design & Analysis of Algorithms

**Credits:** 4 | **Theory:** 3 hrs/week | **Practical:** 2 hrs/week

### Course Objectives

- To analyze algorithm complexity using asymptotic notations
- To master algorithm design techniques (divide & conquer, greedy, DP, backtracking)
- To understand NP-completeness and approximation algorithms
- To develop efficient algorithms for computational problems
- To apply string matching and graph algorithms

### Course Outcomes

| CO  | Description                                                                 |
| --- | --------------------------------------------------------------------------- |
| CO1 | Analyze worst-case and average-case running times using asymptotic notation |
| CO2 | Apply divide-and-conquer and greedy strategies                              |
| CO3 | Design dynamic programming solutions                                        |
| CO4 | Apply backtracking and branch-and-bound techniques                          |
| CO5 | Classify P/NP problems and analyze string matching algorithms               |

### Course Contents

**Unit I: Algorithm Analysis and Sorting (12 Hours):** Asymptotic notations (O, Ω, Θ). Recurrence
relations: Substitution, recursion tree, Master theorem. Sorting: Heap sort, Quick sort
(randomized), Merge sort, Lower bounds. Order statistics (Quickselect, median of medians). Amortized
analysis

**Unit II: Divide and Conquer and Greedy Algorithms (12 Hours):** Divide and Conquer: Binary search,
Strassen's matrix multiplication, Maximum subarray, Closest pair of points. Greedy: Activity
selection, Huffman coding, Fractional knapsack, Job sequencing, MST (Prim's, Kruskal's), Dijkstra's
algorithm

**Unit III: Dynamic Programming (12 Hours):** DP principles (optimal substructure, overlapping
subproblems). 0/1 Knapsack, LCS, Matrix chain multiplication, OBST, Bellman-Ford, Floyd-Warshall,
Coin change, Longest increasing subsequence

**Unit IV: Backtracking and Branch-and-Bound (12 Hours):** Backtracking: N-Queens, Graph coloring,
Hamiltonian cycle, Sum of subsets, Sudoku. Branch-and-Bound: TSP, 0/1 knapsack (FIFO, LC), Job
assignment

**Unit V: NP-Completeness and String Matching (12 Hours):** P, NP, NP-Complete, NP-Hard. Reductions
(SAT, 3-SAT, Vertex cover, Clique, Hamiltonian Path). Approximation algorithms: Vertex cover
(2-approx), TSP (2-approx). String matching: Naive, Rabin-Karp, KMP algorithm

### Learning Resources

**Textbooks:**

1. T.H. Cormen, C.E. Leiserson, R.L. Rivest, C. Stein, "Introduction to Algorithms", 4th Edition,
   MIT Press
2. E. Horowitz, S. Sahni, S. Rajasekaran, "Fundamentals of Computer Algorithms", 2nd Edition

**Reference Books:**

1. Jon Kleinberg, Eva Tardos, "Algorithm Design", Pearson
2. Steven S. Skiena, "The Algorithm Design Manual", 3rd Edition, Springer

## DSC-11: Software Engineering

**Credits:** 4 | **Theory:** 3 hrs/week | **Practical:** 2 hrs/week

### Course Contents

**Unit I: Software Processes (12 Hours):** Software engineering principles, Process models
(Waterfall, Incremental, Prototyping, Spiral, RAD). Agile: Scrum (sprints, backlog, ceremonies), XP
(practices), Kanban

**Unit II: Requirements Engineering (12 Hours):** Feasibility study, Elicitation (interviews,
surveys, workshops, prototyping). Functional vs non-functional requirements. Use cases. SRS (IEEE
830). Requirements validation

**Unit III: Software Design (12 Hours):** Design concepts: Modularity, cohesion, coupling.
Architectural styles. UML: Class, sequence, activity, state, component, deployment diagrams. Design
patterns: Singleton, Factory, Observer, Strategy

**Unit IV: Testing and Quality (12 Hours):** White-box testing (statement, branch, path, cyclomatic
complexity). Black-box testing (equivalence, BVA, decision table). Integration testing. Acceptance
testing. Automation: Selenium, JUnit

**Unit V: Project Management (12 Hours):** Estimation (LOC, FP, COCOMO II). Scheduling (WBS, PERT,
CPM, Gantt). Risk management. Quality assurance (ISO 9001, CMMI). Maintenance, Version control
(Git), Configuration management

### Learning Resources

**Textbooks:**

1. Roger S. Pressman, Bruce R. Maxim, "Software Engineering: A Practitioner's Approach", 9th
   Edition, McGraw Hill
2. Ian Sommerville, "Software Engineering", 10th Edition, Pearson

## DSC-12: Theory of Computation

**Credits:** 4 | **Theory:** 3 hrs/week | **Practical:** 2 hrs/week

### Course Contents

**Unit I: Finite Automata (12 Hours):** DFA, NFA, ε-NFA. Equivalence (subset construction). DFA
minimization. Moore and Mealy machines. Applications in lexical analysis

**Unit II: Regular Languages (12 Hours):** Regular expressions, Arden's theorem. RE to NFA
(Thompson's), NFA to RE. Pumping lemma for regular languages. Closure and decision properties.
Myhill-Nerode theorem

**Unit III: Context-Free Grammars and PDA (12 Hours):** CFG, derivation, parse trees, ambiguity.
Simplification, CNF, GNF. PDA: Design, acceptance (final state, empty stack). CFG ↔ PDA equivalence.
Pumping lemma for CFLs

**Unit IV: Turing Machines (12 Hours):** TM definition, design (aⁿbⁿcⁿ, ww, palindrome). Variants
(multi-tape, NTM). Universal TM. Recursive and recursively enumerable languages. Chomsky hierarchy

**Unit V: Undecidability (12 Hours):** Decidable vs undecidable problems. Halting problem
undecidability. Reducibility. PCP. Rice's theorem. Introduction to P vs NP

## DSC-13: Artificial Intelligence

**Credits:** 4 | **Theory:** 3 hrs/week | **Practical:** 2 hrs/week

### Course Contents

**Unit I: Intelligent Agents and Problem Solving (12 Hours):** AI history, Intelligent agents (PEAS,
types). Problem spaces: State space search, BFS, DFS, IDDFS. Problem formulation (8-puzzle, water
jug, missionaries-cannibals)

**Unit II: Informed Search and Game Playing (12 Hours):** Heuristic search: Greedy BFS, A\*
(admissibility, consistency, optimality). Local search: Hill climbing, simulated annealing, genetic
algorithms. Adversarial search: Minimax, alpha-beta pruning, games with chance

**Unit III: Knowledge Representation and Reasoning (12 Hours):** Propositional logic, FOL, Inference
(resolution, forward/backward chaining). Ontologies, Semantic networks, Frames, Scripts. Rule-based
systems, Expert systems

**Unit IV: Reasoning Under Uncertainty (12 Hours):** Probability, Bayes' theorem, Bayesian networks
(DAG, CPTs, inference). Hidden Markov Models. Dempster-Shafer theory. Fuzzy logic (sets, membership,
inference systems)

**Unit V: AI Applications (12 Hours):** NLP pipeline (tokenization, POS tagging, NER, parsing).
Computer vision basics (image classification, object detection concept). Robotics (configuration
space, path planning). AI ethics, bias, and fairness. Case studies

### Learning Resources

**Textbooks:**

1. Stuart Russell, Peter Norvig, "Artificial Intelligence: A Modern Approach", 4th Edition, Pearson
2. Elaine Rich, Kevin Knight, "Artificial Intelligence", 3rd Edition, McGraw Hill

## DSC-14: Machine Learning

**Credits:** 4 | **Theory:** 3 hrs/week | **Practical:** 2 hrs/week

### Course Contents

**Unit I: ML Fundamentals and Regression (12 Hours):** ML types (supervised, unsupervised,
reinforcement). Linear regression (simple, multiple), Gradient descent, Polynomial regression,
Regularization (Ridge, Lasso, Elastic Net). Evaluation: MSE, RMSE, MAE, R²

**Unit II: Classification (12 Hours):** Logistic regression, Decision trees (ID3, C4.5, CART,
pruning). SVM (linear, kernel trick (RBF, polynomial), soft margin). k-NN. Naive Bayes. Evaluation:
Confusion matrix, accuracy, precision, recall, F1, ROC-AUC. Cross-validation

**Unit III: Ensemble Methods (12 Hours):** Bagging (Random Forest), Boosting (AdaBoost, Gradient
Boosting, XGBoost, LightGBM). Bias-variance tradeoff. Hyperparameter tuning (GridSearch,
RandomizedSearch)

**Unit IV: Unsupervised Learning (12 Hours):** K-means (initialization, elbow, silhouette),
Hierarchical clustering (agglomerative, dendrograms), DBSCAN. Dimensionality reduction: PCA.
Association: Apriori. Anomaly detection (Isolation Forest, LOF)

**Unit V: Neural Networks (12 Hours):** Perceptron, MLP (backpropagation, activation functions), CNN
(convolution, pooling, LeNet concept), RNN/LSTM (concept). Frameworks: TensorFlow/Keras basics.
Transfer learning

## DSC-15: Compiler Design

**Credits:** 4 | **Theory:** 3 hrs/week | **Practical:** 2 hrs/week

**Unit I:** Phases of compiler, Lexical analysis (tokens, regular expressions, NFA/DFA, Lex tool)
**Unit II:** Parsing: Top-down (LL(1), FIRST/FOLLOW, recursive descent), Bottom-up (LR(0), SLR, CLR,
LALR, YACC) **Unit III:** Syntax-directed translation, Intermediate code (three-address, quadruples,
triples, AST) **Unit IV:** Symbol tables (linear, hash, tree). Runtime environments (activation
records, stack/heap allocation) **Unit V:** Code optimization (basic blocks, DAG, data-flow
analysis, loop optimization), Code generation (register allocation, instruction selection)

## DSC-16: Computer Graphics

**Credits:** 4 | **Theory:** 3 hrs/week | **Practical:** 2 hrs/week

**Unit I:** Graphics primitives, Scan conversion (DDA, Bresenham line/circle), Anti-aliasing **Unit
II:** 2D transformations (translation, rotation, scaling, reflection, shear, homogeneous
coordinates). 2D viewing, Clipping (Cohen-Sutherland, Sutherland-Hodgeman) **Unit III:** 3D
transformations, Projections (parallel, perspective). 3D viewing pipeline **Unit IV:** Hidden
surface removal (depth buffer, painters, scan-line), Shading (Gouraud, Phong), Illumination
(ambient, diffuse, specular), Color models (RGB, CMY, HSV) **Unit V:** Curves (Bezier, B-spline,
Hermite), Fractals (Koch, Mandelbrot), Animation techniques, OpenGL basics

### Learning Resources

**Textbooks:**

1. Donald Hearn, M. Pauline Baker, "Computer Graphics with OpenGL", 4th Edition, Pearson
2. J.D. Foley, A. van Dam, S.K. Feiner, J.F. Hughes, "Computer Graphics: Principles and Practice",
   3rd Edition, Addison-Wesley

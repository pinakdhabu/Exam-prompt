## DSC-301: Data Structures

**Credits:** 4 | **Theory:** 3 hrs/week | **Practical:** 2 hrs/week

### Course Objectives
- Understand fundamental data structures and their operations
- Analyze time and space complexity of algorithms
- Implement data structures in programming language
- Apply appropriate data structures for solving computational problems

### Course Outcomes

| CO | Description |
|----|-------------|
| CO1 | Analyze algorithms using asymptotic notations |
| CO2 | Implement linear data structures: arrays, stacks, queues, linked lists |
| CO3 | Implement non-linear data structures: trees, graphs |
| CO4 | Apply searching, sorting, and hashing techniques |
| CO5 | Select and use appropriate data structures for problem solving |

### Course Contents

#### Unit I: Introduction to Data Structures and Algorithm Analysis (12 Hours)
- Classification of Data Structures: Linear and Non-linear
- Abstract Data Types (ADTs)
- Algorithm Complexity: Space and Time
- Asymptotic Notations: Big-O, Omega, Theta
- Recursion: Design and Implementation

#### Unit II: Arrays, Searching and Sorting (12 Hours)
- Arrays: Memory Representation, Operations
- Sparse Matrix: Array and Linked Representations
- Searching: Linear, Binary, Indexed Sequential
- Sorting: Insertion, Bubble, Selection, Quick, Merge, Heap Sort

#### Unit III: Stacks, Queues and Linked Lists (12 Hours)
- Stack: ADT, Array/Linked Implementation, Applications
- Queue: ADT, Circular Queue, Priority Queue, Deque
- Singly Linked List: Operations
- Doubly and Circular Linked Lists
- Polynomial Representation

#### Unit IV: Trees and Graphs (12 Hours)
- Binary Tree: Properties, Representation, Traversals
- Binary Search Tree: Operations
- AVL Trees, B-Trees
- Graph: BFS, DFS, MST, Shortest Path

#### Unit V: Hashing and Advanced Data Structures (12 Hours)
- Hashing: Hash Functions, Collision Resolution
- Open Addressing: Linear, Quadratic, Double Hashing
- Chaining: Separate Chaining
- Heaps: Min-Heap, Max-Heap
- Tries, Skip Lists

### Learning Resources

#### Textbooks
1. Mark A. Weiss, "Data Structures and Algorithm Analysis in C++", 4th Edition, Pearson
2. Thomas H. Cormen et al., "Introduction to Algorithms", 3rd Edition, MIT Press

#### Reference Books
1. A.V. Aho, J.E. Hopcroft, J.D. Ullman, "Data Structures and Algorithms", Pearson
2. Horowitz and Sahani, "Fundamentals of Data Structures", University Press

## DSC-303: Operating Systems

**Credits:** 4 | **Theory:** 3 hrs/week | **Practical:** 2 hrs/week

### Course Objectives
- Understand OS structure, process management, and scheduling
- Study memory management, file systems, and I/O management
- Learn concurrency, synchronization, and deadlock handling

### Course Outcomes

| CO | Description |
|----|-------------|
| CO1 | Explain OS architecture and system calls |
| CO2 | Apply CPU scheduling algorithms for process management |
| CO3 | Implement process synchronization and deadlock handling |
| CO4 | Apply memory management techniques |
| CO5 | Understand file systems and I/O management |

### Course Contents

#### Unit I: Introduction to Operating Systems (12 Hours)
- OS: Functions, Types, Evolution
- System Calls: Process, File, Device
- OS Structures: Monolithic, Layered, Microkernel
- System Boot, System Programs

#### Unit II: Process and Thread Management (12 Hours)
- Process: States, PCB, Context Switch
- Threads: User-level, Kernel-level
- CPU Scheduling: FCFS, SJF, RR, Priority, Multilevel Queue
- Scheduling Evaluation

#### Unit III: Process Synchronization and Deadlocks (12 Hours)
- Race Conditions, Critical Section
- Semaphores, Mutexes, Monitors
- Classical Problems: Producer-Consumer, Reader-Writer, Dining Philosophers
- Deadlock: Conditions, Prevention, Avoidance, Detection, Recovery

#### Unit IV: Memory Management (12 Hours)
- Memory Hierarchy
- Contiguous Allocation: Fixed/Dynamic Partitions
- Paging: Page Table, TLB
- Segmentation
- Virtual Memory: Demand Paging, Page Replacement (FIFO, LRU, Optimal), Thrashing

#### Unit V: File Systems and I/O Management (12 Hours)
- File Concepts: Attributes, Operations
- Directory Structure: Single-level, Two-level, Tree, Acyclic Graph
- File Allocation: Contiguous, Linked, Indexed
- Disk Scheduling: FCFS, SSTF, SCAN, C-SCAN
- RAID Structure

### Learning Resources

#### Textbooks
1. Abraham Silberschatz, Peter B. Galvin, Greg Gagne, "Operating System Concepts", 10th Edition, Wiley
2. William Stallings, "Operating Systems: Internals and Design Principles", 9th Edition, Pearson

#### Reference Books
1. Andrew S. Tanenbaum, "Modern Operating Systems", 4th Edition, Pearson
2. Gary Nutt, "Operating Systems: A Modern Perspective", 3rd Edition, Pearson

# University of Delhi B.Sc. (Hons) Computer Science — Course Structure (NEP FYUP 2022)

> **University:** University of Delhi (DU) **Regulation:** NEP Undergraduate Curriculum Framework
> (UGCF) 2022 — Four Year Undergraduate Programme (FYUP) **Program:** B.Sc. (Hons) Computer Science
> **Duration:** 4 Years (8 Semesters) with multiple exit options

## Course Categories (NEP)

|   Code   | Category                     | Description                     |
| :------: | ---------------------------- | ------------------------------- |
| **DSC**  | Discipline Specific Core     | Compulsory CS courses           |
| **DSE**  | Discipline Specific Elective | Advanced CS electives           |
|  **GE**  | Generic Elective             | Courses from other disciplines  |
| **AEC**  | Ability Enhancement Course   | English/MIL communication       |
| **SEC**  | Skill Enhancement Course     | Practical skill courses         |
| **VAC**  | Value Addition Course        | Environmental Sci, Ethics, etc. |
| **DISS** | Dissertation/Project         | Research project in final year  |

## Examination Pattern

- **Internal Assessment:** 25 marks
- **End Semester Exam:** 75 marks
- **Total:** 100 marks per DSC/DSE
- **Min passing:** 40% combined

## Official Syllabus Links

- DU CS Department: https://cs.du.ac.in/

# Harvard University Computer Science — Course Reference

> Compiled from Harvard University Computer Science course catalog for reference.
>
> Harvard follows a semester system where students take courses across Fall and Spring semesters.
> A.B. and S.B. degree options are available.

---

## Core Courses

### CS 50: Introduction to Computer Science I

**Fall/Spring** | **Harvard College** | **Credits:** 4

**Topics:** Computational thinking, abstraction, algorithms, data structures, resource management.
Languages: C, Python, SQL, JavaScript, HTML/CSS.

**Problem Sets:** 8 assignments covering arrays, algorithms, memory, data structures, web
development. **Final Project:** Open-ended programming project.

### CS 51: Abstraction and Design in Computation

**Fall/Spring** | **Credits:** 4 | **Prerequisites:** CS 50 or equivalent

**Topics:** Object-oriented programming, functional programming, abstract data types, modules,
specifications, assertions, invariants. Language: OCaml, then transition to other languages.

### CS 61: Systems Programming and Machine Organization

**Fall/Spring** | **Credits:** 4 | **Prerequisites:** CS 50

**Topics:** C programming, memory management, assembly language, processor architecture, caching,
linking, processes, virtual memory, concurrency.

### CS 121: Introduction to Theoretical Computer Science

**Fall/Spring** | **Credits:** 4 | **Prerequisites:** CS 51, Math 22 or 23 or 25

**Topics:** Finite automata, regular expressions, Turing machines, computability, time complexity, P
vs NP, NP-completeness, space complexity.

### CS 124: Data Structures and Algorithms

**Fall/Spring** | **Credits:** 4 | **Prerequisites:** CS 50, CS 51, Math 21a/22a

**Topics:** Graph algorithms, hashing, heaps, balanced trees, dynamic programming, greedy
algorithms, network flow, linear programming, randomized algorithms.

## Advanced Elective Courses (Sample)

### Systems

- **CS 143:** Operating Systems — Processes, scheduling, memory, file systems, virtualization
- **CS 144:** Computer Networks — TCP/IP, routing, BGP, DNS, transport protocols, congestion control
- **CS 146:** Distributed Computing — Distributed algorithms, consensus, replication, fault
  tolerance
- **CS 148:** Computer Architecture — Pipelining, out-of-order execution, memory hierarchy, GPU

### AI/ML

- **CS 181:** Introduction to Machine Learning — Supervised/unsupervised learning, neural networks,
  SVMs, boosting
- **CS 182:** Deep Learning — CNNs, RNNs, GANs, transformers, reinforcement learning
- **CS 185:** Computer Vision — Image processing, object detection, 3D vision, deep learning for
  vision
- **CS 187:** Natural Language Processing — Parsing, semantics, machine translation, modern LLMs

### Theory

- **CS 120:** Cryptography — Symmetric/asymmetric encryption, authentication, zero-knowledge, secure
  computation
- **CS 125:** Algorithms and Complexity — Advanced algorithms, approximation, online algorithms
- **CS 127:** Quantum Computation — Qubits, quantum gates, quantum algorithms, error correction

### Applications

- **CS 171:** Visualization — Scientific/Information visualization, interaction, perception
- **CS 175:** Computer Graphics — Rendering, geometry, animation, real-time graphics
- **CS 179:** Introduction to Discrete Mathematics — Logic, counting, graph theory

### Programming Languages and Software Engineering

- **CS 152:** Programming Languages — Semantics, type systems, compilers, functional programming
- **CS 153:** Compilers — Lexing, parsing, optimization, code generation
- **CS 165:** Systems Security — Memory safety, web security, network security, cryptography

## Senior Year

### CS 91r: Senior Thesis Research

- Year-long independent research project supervised by faculty
- Culminates in a written thesis and oral presentation

### CS 189r: Capstone Project

- Team-based software development project
- Real-world clients from industry/non-profit

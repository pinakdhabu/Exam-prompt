## Programme Structure

### Foundational Courses
- CS50: Introduction to Computer Science
- CS20: Discrete Mathematics
- CS51: Abstraction and Design in Computation
- CS61: Systems Programming and Machine Organization
- Stat 110: Probability

### Core Courses (Areas)
- **Theory:** CS121 (Introduction to Theoretical Computer Science), CS124 (Algorithms)
- **Systems:** CS141 (Computing Hardware), CS143 (Compilers), CS144 (Operating Systems), CS145 (Networking), CS146 (Database Systems)
- **AI/ML:** CS181 (Machine Learning), CS182 (AI), CS184 (Neural Networks), CS189 (Computational Vision)

### Advanced Electives
- CS171: Visualization
- CS175: Computer Graphics
- CS179: Computational Photography
- CS205: Computing Foundations for Computational Science
- CS221: Cryptography
- CS224: Advanced Algorithms
- CS225: Pseudorandomness
- CS226: Distributed Algorithms
- CS227: Topics in Optimization
- CS228: Probabilistic Graphical Models
- CS229: Machine Learning (graduate)
- CS230: Deep Learning
- CS231n: CNNs for Visual Recognition
- CS246: Social Network Analysis

### Assessment
- **Grading:** Letter grades A-F on 4.0 GPA scale
- **Terms:** Fall (Sep-Dec), Spring (Jan-May)
- **System:** Standard US semester pattern with reading period before final exams

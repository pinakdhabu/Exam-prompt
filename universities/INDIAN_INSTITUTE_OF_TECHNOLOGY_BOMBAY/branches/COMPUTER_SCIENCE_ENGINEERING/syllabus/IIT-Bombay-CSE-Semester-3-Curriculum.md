# IIT Bombay CSE — Curriculum Overview

IIT Bombay follows a semester system with courses organized across 8 semesters.
Each course is assigned a certain number of credits based on L:T:P (Lecture:Tutorial:Practical) hours.

---

## Core Courses — Semester III

### CS 221: Data Structures and Algorithms

**Credits:** 3 | **L:T:P:** 3:0:0 | **Prerequisites:** CS 101, CS 111

#### Course Objectives
- Design and implement advanced data structures
- Analyze algorithm efficiency rigorously
- Apply algorithm design paradigms for problem solving

#### Course Outcomes

| CO | Description |
|----|-------------|
| CO1 | Analyze algorithm complexity using asymptotic methods |
| CO2 | Implement advanced tree structures (AVL, Red-Black, B-Trees) |
| CO3 | Apply graph algorithms for real-world problem solving |
| CO4 | Design algorithms using dynamic programming and greedy strategies |
| CO5 | Analyze NP-completeness and approximation algorithms |

#### Course Contents

**Unit 1:** Review of Basic Data Structures: Arrays, Linked Lists, Stacks, Queues

**Unit 2:** Trees: BST, AVL Trees, Red-Black Trees, B-Trees, Tries

**Unit 3:** Graphs: Representations, DFS, BFS, Topological Sort, Strongly Connected Components, MST (Prim, Kruskal), Shortest Paths (Dijkstra, Bellman-Ford, Floyd-Warshall)

**Unit 4:** Algorithm Design Paradigms: Divide and Conquer, Greedy, Dynamic Programming

**Unit 5:** Advanced Topics: String Matching (KMP, Rabin-Karp), Network Flow, NP-Completeness, Approximation Algorithms

#### Learning Resources

1. T.H. Cormen, C.E. Leiserson, R.L. Rivest, C. Stein, "Introduction to Algorithms", MIT Press
2. J. Kleinberg, E. Tardos, "Algorithm Design", Addison-Wesley

### CS 222: Logic and Discrete Mathematics

**Credits:** 3 | **L:T:P:** 3:0:0

#### Course Outcomes

| CO | Description |
|----|-------------|
| CO1 | Apply mathematical logic and proof techniques |
| CO2 | Use set theory, relations, and functions for modeling |
| CO3 | Apply combinatorial methods for counting |
| CO4 | Apply graph theory concepts for problem solving |
| CO5 | Understand algebraic structures in computing |

#### Course Contents

**Unit 1:** Propositional and Predicate Logic, Proof Techniques, Induction

**Unit 2:** Set Theory, Relations, Functions, Cardinality

**Unit 3:** Combinatorics: Permutations, Combinations, Pigeonhole Principle, Generating Functions

**Unit 4:** Graph Theory: Eulerian/Hamiltonian Graphs, Planarity, Coloring, Matching

**Unit 5:** Algebraic Structures: Groups, Rings, Fields, Applications in Coding Theory

### CS 223: Computer Organization and Architecture

**Credits:** 3 | **L:T:P:** 3:0:0

#### Course Outcomes

| CO | Description |
|----|-------------|
| CO1 | Explain CPU architecture and instruction execution |
| CO2 | Design combinational and sequential circuits |
| CO3 | Analyze memory hierarchy and cache performance |
| CO4 | Understand pipelining and parallelism concepts |
| CO5 | Evaluate I/O systems and storage architectures |

#### Course Contents

**Unit 1:** Digital Logic Fundamentals, Boolean Algebra, K-Maps, Combinational/Sequential Circuits

**Unit 2:** Processor Design: Datapath, Control Unit (Hardwired, Microprogrammed)

**Unit 3:** Memory Hierarchy: Cache, Main Memory, Virtual Memory

**Unit 4:** Pipelining: Hazards, Forwarding, Branch Prediction

**Unit 5:** Parallel Architectures: Superscalar, VLIW, Multi-core, GPU

### CS 224: Operating Systems

**Credits:** 3 | **L:T:P:** 3:0:0 | **Prerequisites:** CS 221

#### Course Outcomes

| CO | Description |
|----|-------------|
| CO1 | Understand OS structure and abstractions |
| CO2 | Implement process scheduling and synchronization |
| CO3 | Manage memory using paging and segmentation |
| CO4 | Design file systems and I/O subsystems |
| CO5 | Analyze performance of OS components |

#### Course Contents

**Unit 1:** OS Structures, System Calls, Boot Process

**Unit 2:** Processes: Scheduling (MLFQ, CFS), IPC, Synchronization (Locks, Semaphores)

**Unit 3:** Memory Management: Paging, TLB, Demand Paging, Page Replacement

**Unit 4:** File Systems: EXT4, NTFS, Journaling, RAID

**Unit 5:** I/O Management: Device Drivers, Interrupt Handling, DMA

### CS 225: Probability and Statistics for CS

**Credits:** 3 | **L:T:P:** 3:0:0

#### Course Outcomes

| CO | Description |
|----|-------------|
| CO1 | Apply probability theory to model uncertainty |
| CO2 | Understand random variables and distributions |
| CO3 | Perform statistical inference and hypothesis testing |
| CO4 | Apply probabilistic methods in CS (randomized algorithms, ML) |
| CO5 | Design and analyze experiments |

#### Course Contents

**Unit 1:** Probability: Axioms, Conditional, Bayes Theorem

**Unit 2:** Random Variables: Discrete (Binomial, Poisson), Continuous (Normal, Exponential)

**Unit 3:** Expectation, Variance, Moments, Law of Large Numbers, Central Limit Theorem

**Unit 4:** Statistics: Estimation, Hypothesis Testing, Confidence Intervals

**Unit 5:** Applications: Randomized Algorithms, Probabilistic Analysis, Introduction to ML

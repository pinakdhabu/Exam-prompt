## MA3354: Discrete Mathematics

**Credits:** 4 (L:3, T:1, P:0) | **CIE:** 25 Marks | **SEE:** 75 Marks

### Course Objectives
- To introduce propositional logic, predicates, and proof strategies
- To study set theory, relations, functions, and counting principles
- To understand graph theory and algebraic structures

### Course Outcomes

| CO | Description |
|----|-------------|
| CO1 | Apply propositional logic and predicate calculus in problem solving |
| CO2 | Use set theory, relations, and functions to model computing problems |
| CO3 | Apply counting techniques and combinatorial reasoning |
| CO4 | Model problems using graph theory and trees |
| CO5 | Apply algebraic structures in computing contexts |

### Course Contents

#### Unit I: Logic and Proofs (12 Hours)
- Propositional Logic: Connectives, Truth Tables
- Propositional Equivalences: DeMorgan's Laws, Tautologies
- Predicates and Quantifiers
- Nested Quantifiers
- Rules of Inference
- Proof Methods: Direct, Indirect, Contradiction, Induction

#### Unit II: Sets, Relations, and Functions (12 Hours)
- Set Theory: Operations, Cardinality, Power Set
- Relations: Properties, Representation, Closures
- Equivalence Relations and Partitions
- Partial Orders, Hasse Diagrams, Lattices
- Functions: Types, Composition, Inverse
- Pigeonhole Principle

#### Unit III: Counting Principles (12 Hours)
- Basics of Counting: Sum and Product Rules
- Permutations and Combinations
- Binomial Coefficients
- Inclusion-Exclusion Principle
- Recurrence Relations: Solving Linear Recurrences

#### Unit IV: Graph Theory (12 Hours)
- Graphs: Types, Basic Terminology
- Graph Representations: Adjacency Matrix, Adjacency List
- Graph Isomorphism, Connectivity
- Eulerian and Hamiltonian Graphs
- Planar Graphs, Graph Coloring
- Trees: Properties, Spanning Trees, MST

#### Unit V: Algebraic Structures (12 Hours)
- Groups: Definition, Properties, Subgroups, Cyclic Groups
- Permutation Groups, Cosets, Lagrange's Theorem
- Rings: Definition, Properties, Integral Domains
- Fields: Definition, Finite Fields
- Homomorphisms and Isomorphisms

### Learning Resources

#### Textbooks
1. Kenneth H. Rosen, "Discrete Mathematics and Its Applications", 8th Edition, McGraw Hill, 2021
2. Ralph P. Grimaldi, "Discrete and Combinatorial Mathematics", 5th Edition, Pearson, 2004

#### Reference Books
1. Bernard Kolman, Robert C. Busby, "Discrete Mathematical Structures", 6th Edition, Pearson
2. Narsingh Deo, "Graph Theory with Applications to Engineering and CS", PHI

## CS3351: Data Structures

**Credits:** 4.5 (L:3, P:3) | **CIE:** 25 Marks | **SEE:** 75 Marks

### Course Objectives
- To understand data structure concepts and ADT
- To implement linear and non-linear data structures
- To analyze algorithm efficiency
- To apply appropriate data structures for problem solving

### Course Outcomes

| CO | Description |
|----|-------------|
| CO1 | Analyze algorithms using asymptotic notations |
| CO2 | Implement linear data structures: stacks, queues |
| CO3 | Implement linked lists and their applications |
| CO4 | Implement tree and graph data structures |
| CO5 | Apply searching, sorting, and hashing techniques |

### Course Contents

#### Unit I: Introduction and Linear Structures (10 Hours)
- ADT, Data Structure Classification
- Algorithm Analysis: Asymptotic Notations
- Array: Representation, Operations
- Searching: Linear, Binary
- Sorting: Bubble, Insertion, Selection, Quick, Merge

#### Unit II: Stacks and Queues (10 Hours)
- Stack ADT: Array and Linked Implementation
- Applications: Expression Evaluation, Balancing Symbols
- Queue ADT: Array and Linked Implementation
- Circular Queue, Deque, Priority Queue

#### Unit III: Linked Lists (10 Hours)
- Singly Linked List: Traversal, Insertion, Deletion, Search
- Doubly Linked List
- Circular Linked List
- Polynomial Representation
- Sparse Matrix Representation

#### Unit IV: Trees and Graphs (10 Hours)
- Trees: Terminology, Binary Tree Representations
- Tree Traversals: Inorder, Preorder, Postorder
- Binary Search Tree: Operations
- AVL Trees: Rotations
- Graph: Representations, BFS, DFS, MST (Prim's, Kruskal's)

#### Unit V: Hashing and Advanced Topics (10 Hours)
- Hashing: Hash Functions, Collision Resolution (Chaining, Open Addressing)
- B-Trees: Insertion, Deletion
- Heap: Max Heap, Min Heap, Heap Sort
- Tries
- File Organizations: Sequential, Indexed, Direct

### Learning Resources

#### Textbooks
1. Mark A. Weiss, "Data Structures and Algorithm Analysis in C++", 4th Edition, Pearson, 2014
2. Reema Thareja, "Data Structures Using C", 2nd Edition, Oxford University Press, 2014

#### Reference Books
1. Thomas H. Cormen et al., "Introduction to Algorithms", 3rd Edition, MIT Press, 2009
2. A.V. Aho, J.E. Hopcroft, J.D. Ullman, "Data Structures and Algorithms", Pearson, 2002

## CS3352: Foundation of Data Science

**Credits:** 3 (L:3, P:0) | **CIE:** 25 Marks | **SEE:** 75 Marks

### Course Objectives
- Understand data science lifecycle and data analysis
- Learn statistical methods for data analysis
- Apply machine learning techniques for data-driven decisions

### Course Outcomes

| CO | Description |
|----|-------------|
| CO1 | Explain data science lifecycle and exploratory data analysis |
| CO2 | Apply statistical measures for data characterization |
| CO3 | Implement data preprocessing and visualization techniques |
| CO4 | Apply regression and classification techniques |
| CO5 | Use clustering for data segmentation |

### Course Contents

#### Unit I: Introduction to Data Science (10 Hours)
- Data Science: Definition, Scope, Applications
- Data Science Lifecycle: CRISP-DM
- Types of Data: Structured, Semi-Structured, Unstructured
- Data Sources, Data Exploration
- Introduction to Python for Data Science

#### Unit II: Descriptive and Inferential Statistics (10 Hours)
- Measures of Central Tendency: Mean, Median, Mode
- Measures of Dispersion: Range, Variance, Standard Deviation
- Correlation and Covariance
- Probability Distributions: Normal, Binomial, Poisson
- Hypothesis Testing: t-test, Chi-square test

#### Unit III: Data Preprocessing and Visualization (10 Hours)
- Data Cleaning: Missing Values, Outliers
- Data Transformation: Scaling, Normalization
- Feature Selection and Extraction
- Data Visualization: Histograms, Box Plots, Scatter Plots
- Visualization Libraries: Matplotlib, Seaborn

#### Unit IV: Regression and Classification (10 Hours)
- Linear Regression
- Logistic Regression
- Decision Trees
- Random Forest
- Model Evaluation: Cross-validation, Confusion Matrix, ROC

#### Unit V: Clustering and Dimensionality Reduction (10 Hours)
- K-Means Clustering
- Hierarchical Clustering
- DBSCAN
- Principal Component Analysis (PCA)
- Evaluating Clusters: Elbow Method, Silhouette Score

### Learning Resources

#### Textbooks
1. Jake VanderPlas, "Python Data Science Handbook", O'Reilly, 2016
2. Joel Grus, "Data Science from Scratch", 2nd Edition, O'Reilly, 2019

#### Reference Books
1. Gareth James et al., "An Introduction to Statistical Learning", Springer, 2021
2. Wes McKinney, "Python for Data Analysis", 2nd Edition, O'Reilly, 2017

## CS3353: Digital Principles and Computer Organization

**Credits:** 3 (L:3, P:0) | **CIE:** 25 Marks | **SEE:** 75 Marks

### Course Objectives
- Understand digital logic fundamentals and Boolean algebra
- Learn computer organization and architecture concepts
- Study CPU design, memory hierarchy, and I/O organization

### Course Outcomes

| CO | Description |
|----|-------------|
| CO1 | Simplify Boolean expressions using Boolean algebra and K-maps |
| CO2 | Design combinational and sequential circuits |
| CO3 | Explain computer architecture and CPU organization |
| CO4 | Analyze memory hierarchy and cache design |
| CO5 | Understand I/O organization and communication |

### Course Contents

#### Unit I: Boolean Algebra and Logic Gates (10 Hours)
- Number Systems: Binary, Octal, Hex
- Boolean Algebra: Axioms, Theorems, DeMorgan's Laws
- Logic Gates: AND, OR, NOT, NAND, NOR, XOR, XNOR
- K-Map: 2, 3, 4 Variable Simplification
- Don't Care Conditions

#### Unit II: Combinational Logic (10 Hours)
- Adders: Half, Full, Ripple Carry, Carry Lookahead
- Subtractors: Half, Full
- Multiplexers and Demultiplexers
- Encoders and Decoders
- Comparators, Code Converters

#### Unit III: Sequential Logic (10 Hours)
- Flip-Flops: SR, D, JK, T, Master-Slave
- Registers: SISO, SIPO, PISO, PIPO
- Counters: Ripple, Synchronous, Ring, Johnson
- Finite State Machines: Mealy, Moore
- State Diagrams and State Tables

#### Unit IV: Computer Organization (10 Hours)
- Basic Computer Architecture: Von Neumann, Harvard
- CPU: ALU, Control Unit (Hardwired, Micro-programmed)
- Instruction Set Architecture: RISC vs CISC
- Addressing Modes
- Pipelining: Stages, Hazards

#### Unit V: Memory and I/O Organization (10 Hours)
- Memory Hierarchy: Cache, Main Memory, Secondary Storage
- Cache Mapping: Direct, Associative, Set-Associative
- Virtual Memory: Paging, Segmentation
- I/O Organization: Programmed I/O, Interrupt-driven I/O, DMA
- Buses: System Bus, I/O Bus

### Learning Resources

#### Textbooks
1. M. Morris Mano, "Digital Logic and Computer Design", Pearson, 2017
2. William Stallings, "Computer Organization and Architecture", 11th Edition, Pearson, 2019

#### Reference Books
1. David A. Patterson, John L. Hennessy, "Computer Organization and Design", 5th Edition, Morgan Kaufmann
2. John P. Hayes, "Computer Architecture and Organization", 3rd Edition, McGraw Hill

## CS3391: Object Oriented Programming

**Credits:** 4.5 (L:3, P:3) | **CIE:** 25 Marks | **SEE:** 75 Marks

### Course Objectives
- Understand OOP concepts and principles
- Learn Java programming language
- Develop object-oriented applications

### Course Outcomes

| CO | Description |
|----|-------------|
| CO1 | Apply OOP concepts in Java programs |
| CO2 | Implement inheritance, polymorphism, and interfaces |
| CO3 | Handle exceptions and implement multithreading |
| CO4 | Use Java collections and I/O streams |
| CO5 | Develop GUI applications using JavaFX/Swing |

### Course Contents

#### Unit I: Introduction to OOP and Java (10 Hours)
- OOP Fundamentals: Encapsulation, Inheritance, Polymorphism
- Java: JVM, Bytecode, Data Types
- Operators and Expressions
- Control Statements
- Arrays, String Handling

#### Unit II: Classes, Objects, Inheritance (10 Hours)
- Defining Classes, Constructors
- Method Overloading, this Keyword
- Static Members, Final Keyword
- Inheritance: Types, super, Method Overriding
- Abstract Classes, Interfaces

#### Unit III: Packages, Exceptions, Multithreading (10 Hours)
- User-defined Packages
- Access Protection
- Exception Types: Checked, Unchecked
- try-catch-finally, throw, throws
- Thread: Creation, Lifecycle, Synchronization

#### Unit IV: I/O Streams and Collections (10 Hours)
- Byte and Character Streams
- File I/O, Serialization
- Collections: ArrayList, LinkedList, HashSet, TreeSet
- Map: HashMap, TreeMap
- Generics, Comparator, Comparable

#### Unit V: GUI Programming (10 Hours)
- AWT: Components, Layouts
- Swing: JFrames, Event Handling
- Adapter Classes, Inner Classes
- JDBC: Database Connectivity
- Applets

### Learning Resources

#### Textbooks

2. Cay S. Horstmann, "Core Java Volume I — Fundamentals", 11th Edition, Pearson, 2019

#### Reference Books

## KCS301: Discrete Structures and Theory of Logic

**Credits:** 4 | **CIE:** 50 Marks | **SEE:** 100 Marks

### Course Objectives
- Understand sets, relations, functions, and algebraic structures
- Study propositional logic and predicate calculus
- Learn graph theory, trees, and combinatorial methods

### Course Outcomes

| CO | Description |
|----|-------------|
| CO1 | Apply set theory, relations, and functions to model computing problems |
| CO2 | Use propositional and predicate logic for mathematical reasoning |
| CO3 | Solve combinatorial problems using counting principles |
| CO4 | Model real-world problems using graph theory and trees |
| CO5 | Apply algebraic structures in coding theory and computing |

### Course Contents

#### Unit I: Set Theory, Relations, and Functions (10 Hours)
- Sets: Operations, Venn Diagrams, Cartesian Product
- Relations: Binary Relations, Properties, Matrix Representation
- Closures: Reflexive, Symmetric, Transitive
- Equivalence Relations, Partial Orders, Hasse Diagrams
- Functions: Types, Composition, Inverse

#### Unit II: Propositional Logic (10 Hours)
- Propositions, Logical Connectives
- Truth Tables, Tautologies, Contradictions, Contingency
- Logical Equivalences: DeMorgan's Laws
- Normal Forms: CNF, DNF
- Predicate Logic: Quantifiers, Nested Quantifiers

#### Unit III: Combinatorics and Counting (10 Hours)
- Pigeonhole Principle
- Permutations and Combinations
- Binomial Theorem
- Inclusion-Exclusion Principle
- Recurrence Relations: Solving with Characteristic Equations

#### Unit IV: Graph Theory and Trees (10 Hours)
- Graphs: Directed, Undirected, Weighted
- Graph Representations: Adjacency Matrix, Incidence Matrix
- Graph Isomorphism, Connectivity
- Eulerian and Hamiltonian Paths and Circuits
- Trees: Binary Trees, Tree Traversals, Spanning Trees

#### Unit V: Algebraic Structures (10 Hours)
- Groups: Definition, Properties, Subgroups
- Cyclic Groups, Cosets, Lagrange's Theorem
- Normal Subgroups and Quotient Groups
- Rings: Integral Domains, Fields
- Homomorphisms and Isomorphisms

### Learning Resources

#### Textbooks
1. Kenneth H. Rosen, "Discrete Mathematics and Its Applications", McGraw Hill
2. J.P. Tremblay, R. Manohar, "Discrete Mathematical Structures", McGraw Hill

## KCS302: Data Structures and Applications

**Credits:** 4 | **CIE:** 50 Marks | **SEE:** 100 Marks

### Course Objectives
- Understand linear and non-linear data structures
- Analyze algorithm complexity
- Apply appropriate data structures for problem solving

### Course Outcomes

| CO | Description |
|----|-------------|
| CO1 | Analyze algorithm efficiency using asymptotic notation |
| CO2 | Implement linear data structures (arrays, stacks, queues, linked lists) |
| CO3 | Implement non-linear data structures (trees, graphs) |
| CO4 | Apply searching, sorting, and hashing techniques |
| CO5 | Select appropriate data structures for solving problems |

### Course Contents

#### Unit I: Introduction and Algorithm Analysis (10 Hours)
- Classification of Data Structures, ADT
- Algorithm: Space and Time Complexity
- Asymptotic Notations: O, Ω, Θ
- Recursion: Concept, Types, Implementation
- Divide and Conquer Strategy

#### Unit II: Arrays and Searching/Sorting (10 Hours)
- Array Operations: Insertion, Deletion, Traversal
- Sparse Matrix: Representation, Operations
- Searching: Linear, Binary
- Sorting: Bubble, Quick, Merge, Heap, Radix Sort

#### Unit III: Stacks, Queues, Linked Lists (10 Hours)
- Stack: Implementation, Infix/Postfix/Prefix, Evaluation
- Queue: Linear, Circular, Priority, Deque
- Singly, Doubly, Circular Linked Lists
- Polynomial Representation using Linked Lists

#### Unit IV: Trees and Graphs (10 Hours)
- Binary Tree: Representations, Traversals (Inorder, Preorder, Postorder)
- Binary Search Tree: Insert, Delete, Search
- AVL Trees, B-Trees
- Graph: BFS, DFS, MST (Prim's, Kruskal's)

#### Unit V: Hashing and File Structures (10 Hours)
- Hash Functions: Division, Folding, Mid-square
- Collision Resolution: Chaining, Open Addressing
- Hashing Applications: Symbol Table
- File Organization: Sequential, Random, Indexed Sequential
- Multiway Trees: B+ Trees, Tries

### Learning Resources

#### Textbooks
1. Horowitz, Sahani, "Fundamentals of Data Structures", University Press
2. Mark A. Weiss, "Data Structures and Algorithm Analysis in C++", Pearson

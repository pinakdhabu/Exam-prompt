## 410603: Industrial IoT and Smart Systems

**Teaching Scheme:** Theory: 03 Hours/Week | **Credits:** 03

### Course Contents

#### Unit I: Industry 4.0 and IIoT (07 Hours)

- Industry 4.0: Principles, Cyber-Physical Systems, Digital Twins
- IIoT vs Consumer IoT: Reliability, Latency, Determinism
- Industrial Communication: OPC-UA, Modbus, Profinet, EtherCAT
- SCADA Systems: Architecture, RTU, PLC, HMI
- MES and ERP Integration

#### Unit II: Smart Manufacturing (07 Hours)

- Digital Manufacturing: CAD/CAM, 3D Printing
- Predictive Quality: Statistical Process Control
- Supply Chain IoT: RFID, GPS Tracking
- Warehouse Automation: AGV, Robotics
- Human-Machine Collaboration: Cobots

#### Unit III: Smart Energy Systems (07 Hours)

- Smart Grid: AMI, DER, V2G
- Energy Monitoring: IoT-based, Real-time
- Renewable Integration: Solar, Wind
- Building Management Systems (BMS)
- Energy Optimization: ML-based

#### Unit IV: Smart Healthcare IoT (07 Hours)

- Remote Patient Monitoring: Wearables, Vital Signs
- IoMT: Connected Medical Devices
- Telemedicine Infrastructure
- HIPAA/GDPR Compliance in Healthcare IoT
- AI-assisted Diagnostics

#### Unit V: Smart City Infrastructure (07 Hours)

- Smart Transportation: Traffic Management, Autonomous Vehicles
- Smart Parking: Sensor-based, Payment Integration
- Smart Lighting: Adaptive, Energy-efficient
- Waste Management: Fill-level Monitoring, Route Optimization
- Smart Water Management: Leak Detection, Quality Monitoring

#### Unit VI: IIoT Security and Standards (07 Hours)

- Purdue Model for ICS Security
- ISA/IEC 62443 Standards
- OT Security: Air Gap, DMZ, Unidirectional Gateways
- IIoT Risk Assessment
- Future Trends: 5G, 6G, TSN

### Learning Resources

#### Textbooks

1. Alasdair Gilchrist, "Industry 4.0: The Industrial Internet of Things", Apress, 2016
2. Richard Brooks, "Industrial Internet of Things", CRC Press, 2019

## 410604: Industrial IoT Laboratory

**Teaching Scheme:** Practical: 02 Hours/Week | **Credits:** 01

### Laboratory Experiments

1. Implement Modbus communication between PLC and IoT gateway
2. Build a digital twin simulation using AWS IoT TwinMaker
3. Set up OPC-UA server and client communication
4. Implement SCADA monitoring dashboard using Grafana
5. Build smart energy monitoring system with ESP32
6. Implement predictive quality model for manufacturing
7. Build RFID-based asset tracking system
8. Implement smart parking system with occupancy detection
9. Build telemedicine IoT sensor monitoring system
10. Mini-project: End-to-end IIoT system

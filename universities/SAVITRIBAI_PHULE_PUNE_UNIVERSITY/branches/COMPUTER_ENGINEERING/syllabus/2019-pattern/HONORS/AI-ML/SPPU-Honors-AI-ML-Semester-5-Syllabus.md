## 310301: Computational Statistics

**Teaching Scheme:** Theory: 03 Hours/Week

**Credits:** 03

**Examination:** In-Semester Assessment: 30 Marks, End-Semester Assessment: 70 Marks

**Prerequisites:** Engineering Mathematics III, Probability and Statistics

### Course Objectives

- To understand the fundamental concepts of probability and statistical inference
- To learn various probability distributions and their applications
- To study sampling techniques and hypothesis testing methods
- To explore regression analysis and statistical modeling
- To apply computational statistical methods for machine learning

### Course Outcomes

| CO  | Description                                                                          |
| --- | ------------------------------------------------------------------------------------ |
| CO1 | Apply probability theory and understand various probability distributions            |
| CO2 | Perform statistical inference using sampling distributions and estimation techniques |
| CO3 | Apply hypothesis testing methods for decision making                                 |
| CO4 | Perform correlation and regression analysis for data modeling                        |
| CO5 | Apply ANOVA and design of experiments for statistical analysis                       |

### Course Contents

#### Unit I: Probability and Random Variables (07 Hours) → CO1

- Review of Probability: Axioms, Conditional Probability, Bayes' Theorem
- Random Variables: Discrete and Continuous
- Probability Mass Function (PMF) and Probability Density Function (PDF)
- Cumulative Distribution Function (CDF)
- Mathematical Expectation, Variance, Moments
- Moment Generating Functions

#### Unit II: Probability Distributions (07 Hours) → CO1

- Discrete Distributions: Binomial, Poisson, Geometric, Negative Binomial
- Continuous Distributions: Uniform, Exponential, Normal, Gamma, Beta
- Central Limit Theorem
- Joint Probability Distributions
- Covariance and Correlation

#### Unit III: Sampling Distributions and Estimation (07 Hours) → CO2

- Sampling Methods: Simple Random, Stratified, Cluster, Systematic
- Sampling Distributions: Sample Mean, Sample Proportion
- Central Limit Theorem and its Applications
- Point Estimation: Method of Moments, Maximum Likelihood Estimation
- Interval Estimation: Confidence Intervals for Mean, Proportion, Variance

#### Unit IV: Hypothesis Testing (07 Hours) → CO3

- Null and Alternative Hypotheses
- Type I and Type II Errors
- Test Statistic and Critical Region
- Parametric Tests: Z-test, t-test, F-test, Chi-Square Test
- p-value and its Interpretation
- Non-parametric Tests: Mann-Whitney, Wilcoxon Signed-Rank, Kruskal-Wallis

#### Unit V: Regression Analysis and ANOVA (07 Hours) → CO4, CO5

- Correlation Analysis: Pearson, Spearman
- Simple Linear Regression: Least Squares Method
- Multiple Linear Regression
- Model Diagnostics: Residual Analysis, R², Adjusted R²
- One-Way ANOVA: Fixed and Random Effects
- Two-Way ANOVA: Interaction Effects
- Design of Experiments: Factorial Designs

#### Unit VI: Computational Statistics (07 Hours) → CO5

- Monte Carlo Simulation Methods
- Bootstrap and Jackknife Resampling
- Markov Chain Monte Carlo (MCMC)
- Expectation-Maximization (EM) Algorithm
- Dimensionality Reduction: PCA from Statistical Perspective
- Statistical Learning Theory Basics: Bias-Variance Tradeoff

## 310302: Computational Statistics Laboratory

**Teaching Scheme:** Practical: 02 Hours/Week

**Credits:** 01

**Examination:** Term Work: 25 Marks, Practical: 25 Marks

### Course Outcomes

| CO  | Description                                                                     |
| --- | ------------------------------------------------------------------------------- |
| CO1 | Implement probability distributions and statistical computations using Python/R |
| CO2 | Perform hypothesis testing and statistical inference                            |
| CO3 | Build regression models and perform ANOVA                                       |
| CO4 | Implement resampling methods and Monte Carlo simulations                        |

### Suggested List of Assignments

**Group A (Any 4):**

1. Implement functions to compute PMF, PDF, CDF for various probability distributions
2. Generate random samples from different distributions and verify Central Limit Theorem
3. Implement point estimation using MLE and Method of Moments
4. Perform hypothesis testing (Z-test, t-test, Chi-Square) on sample datasets

**Group B (Any 4):** 5. Implement linear and multiple regression analysis on real-world datasets 6.
Perform ANOVA (one-way and two-way) on experimental data 7. Implement bootstrap resampling for
confidence interval estimation 8. Implement PCA for dimensionality reduction

**Group C (Any 2):** 9. Implement Monte Carlo simulation for estimating probabilities 10. Implement
Markov Chain Monte Carlo (MCMC) sampling 11. Mini-project: Complete statistical analysis pipeline on
a real dataset

### Learning Resources

- Python with NumPy, SciPy, Pandas, Statsmodels, Scikit-learn
- R programming with standard statistical packages
- Jupyter Notebooks for reproducible analysis

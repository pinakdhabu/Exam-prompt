## 310401: Information and Cyber Security

**Teaching Scheme:** Theory: 03 Hours/Week | **Credits:** 03 | **ISA:** 30, **ESA:** 70

**Prerequisites:** Computer Networks and Security

### Course Objectives

- Understand security fundamentals, threats, and risk management
- Learn cryptography, network security, and system hardening
- Master security assessment, auditing, and compliance

### Course Outcomes

| CO  | Description                                                                |
| --- | -------------------------------------------------------------------------- |
| CO1 | Identify security threats, vulnerabilities, and risk management approaches |
| CO2 | Apply cryptographic techniques for data protection                         |
| CO3 | Implement network security controls and monitoring                         |
| CO4 | Perform security assessment and ethical hacking                            |
| CO5 | Apply security compliance and governance frameworks                        |

### Course Contents

#### Unit I: Security Fundamentals (07 Hours)

- CIA Triad: Confidentiality, Integrity, Availability
- Security Threats: Malware, Phishing, DoS/DDoS, MITM, SQL Injection, XSS
- Vulnerabilities, Exploits, and Attack Vectors
- Security Risk Management: Risk Assessment, Treatment, Acceptance
- Security Policies: Types, Development, Implementation
- Security Standards: ISO 27001, NIST Cybersecurity Framework
- Cyber Laws and IT Act 2000: Provisions, Amendments

#### Unit II: Cryptography (07 Hours)

- Symmetric Cryptography: DES, 3DES, AES — Modes of Operation
- Asymmetric Cryptography: RSA, ElGamal, ECC
- Hash Functions: MD5, SHA-1, SHA-256, SHA-3
- Message Authentication: MAC, HMAC, CMAC
- Digital Signatures: DSA, ECDSA, RSA Signatures
- Public Key Infrastructure: CA, Certificates, CRL, OCSP
- Key Management: Generation, Distribution, Storage

#### Unit III: Network Security (07 Hours)

- Firewalls: Packet Filter, Stateful, Application Layer, NGFW
- Intrusion Detection and Prevention: Signature-based, Anomaly-based
- VPNs: Site-to-Site, Remote Access, IPSec, SSL VPN
- Network Segmentation: VLANs, DMZ, Micro-segmentation
- Wireless Security: WPA2, WPA3, 802.1X, EAP
- Web Security: HTTPS, SSL/TLS, HSTS, CSP
- Email Security: SPF, DKIM, DMARC, PGP, S/MIME

#### Unit IV: System Security and Hardening (07 Hours)

- OS Security: Windows, Linux — User Management, Permissions, Auditing
- Secure Configuration: CIS Benchmarks, Hardening Guides
- Patch Management: Vulnerability Scanning, Patch Testing, Deployment
- Application Security: Secure Coding Practices, OWASP Top 10
- Database Security: Authentication, Encryption, Auditing
- Endpoint Security: Antivirus, EDR, HIDS, Application Control
- Mobile Security: Android/iOS Security Models, MDM

#### Unit V: Ethical Hacking and Penetration Testing (07 Hours)

- Ethical Hacking Methodology: Reconnaissance, Scanning, Exploitation
- Reconnaissance: OSINT, Google Hacking, Social Engineering
- Scanning: Nmap, Netcat, Vulnerability Scanners (Nessus, OpenVAS)
- Exploitation: Metasploit Framework, Exploit Development Basics
- Web Application Testing: Burp Suite, SQLMap, OWASP ZAP
- Wireless Hacking: Aircrack-ng, Wireshark Analysis
- Reporting: Findings, Risk Rating, Remediation Recommendations

#### Unit VI: Security Governance and Compliance (07 Hours)

- Information Security Management System (ISMS)
- Security Policies: Access Control, Data Classification, Incident Response
- Business Continuity and Disaster Recovery: BCP, DRP
- Security Auditing: Internal, External, Compliance Audits
- Regulatory Compliance: GDPR, HIPAA, PCI DSS, SOX
- Security Awareness Training: Programs, Phishing Simulations
- Incident Response: Preparation, Detection, Containment, Recovery, Lessons Learned

## 310402: Information and Cyber Security Laboratory

**Teaching Scheme:** Practical: 02 Hours/Week | **Credits:** 01 | **TW:** 25, **PR:** 25

### Laboratory Experiments

1. Implement symmetric encryption (AES) and asymmetric encryption (RSA) in Python
2. Perform hash computation and verify message integrity using HMAC
3. Configure firewall rules using iptables/Windows Firewall
4. Network scanning and reconnaissance using Nmap
5. Vulnerability scanning using OpenVAS/Nessus
6. Web application security testing using Burp Suite/OWASP ZAP
7. Exploit a vulnerable machine using Metasploit
8. Configure VPN (IPSec/SSL) between two systems
9. Analyze network traffic using Wireshark
10. Mini-project: Security audit and penetration test report

## 410701: VR in Game Development

**Teaching Scheme:** Theory: 03 Hours/Week | **Credits:** 03

**Prerequisites:** Virtual Reality (310701), Augmented Reality (310703)

### Course Objectives
- Apply game design principles to VR environments
- Master VR interaction, physics, and animation
- Build optimized VR experiences for consumer hardware

### Course Contents

#### Unit I: Game Design for VR (07 Hours)
- VR Game Design Principles: Comfort, Agency, Immersion
- VR Game Genres: FPS, Puzzle, Simulation, Social
- Player Presence: Embodiment, Avatar, Self-representation
- Scale and Proportion: Realistic vs Stylized
- Motion Design: Locomotion, Comfort Modes (Snap Turn, Teleport)
- Pacing and Narrative in VR: Environmental Storytelling
- VR-specific Game Mechanics: Grabbing, Throwing, Climbing

#### Unit II: VR Physics and Interaction (07 Hours)
- Physics in VR: Rigidbody, Colliders, Joints, Constraints
- Object Physics: Weight, Momentum, Throw Prediction
- Grabbing Mechanics: Simple Grab, Physics Grab, Distance Grab
- Climbing Systems: Hand-based, Ladder, Free-form
- Weapon Systems: Aiming, Recoil, Reloading
- Vehicle Physics: Cockpit, Driving, Flight
- Destruction and Deformable Objects

#### Unit III: VR Animation and VFX (07 Hours)
- Realistic Character Animation: IK, FK, Avatar Masks
- Hand Animation: Gestures, Finger Tracking
- Facial Animation: Blend Shapes, Visemes
- Particle Systems: Fire, Smoke, Magic Effects
- Shader Effects: Transparency, Glow, Distortion for VR
- Post-processing: Anti-aliasing, Bloom, Depth of Field

#### Unit IV: VR Audio and UI (07 Hours)
- Spatial Audio: 3D Sound, Reverb Zones, Audio Occlusion
- Ambisonic Audio: 360° Soundscapes
- VR User Interface: Diegetic UI, Spatial UI, Gesture UI
- Input System: Action-based, Device-based
- Accessibility in VR: Subtitles, Color Blindness, One-handed Mode
- Localization for VR Games

#### Unit V: VR Multiplayer and Networking (07 Hours)
- Multiplayer VR: Shared Spaces, Synchronization
- Networking Models: Client-Server, P2P for VR
- Photon Unity Networking for VR: Rooms, RPCs, Ownership
- Avatar Synchronization: Position, Animation, Voice
- Latency Compensation: Prediction, Interpolation, Lag Compensation
- Voice Chat Integration: Vivox, Discord, Dissonance

#### Unit VI: VR Performance Optimization (07 Hours)
- Profiling VR: Frame Timing, Draw Calls, Memory
- Optimization Techniques: Occlusion Culling, LOD Groups, Batching
- Mobile VR Optimization: Quest-specific (Quest 2, 3)
- Fixed Foveated Rendering: Settings, Quality Trade-offs
- GPU Optimization: Shader Complexity, Overdraw
- Build Pipeline: Asset Bundles, Compression, Build Size

## 410702: VR Game Development Laboratory

**Teaching Scheme:** Practical: 02 Hours/Week | **Credits:** 01 | **TW:** 25, **PR:** 25

### Laboratory Experiments

1. Set up VR room-scale environment with boundaries
2. Implement object grabbing with physics and throw
3. Build VR locomotion system: teleport, smooth movement, snap turn
4. Implement climbing system in VR
5. Create spatial audio environment with reverb zones
6. Build VR weapon system with aiming and recoil
7. Implement VR UI: HUD, menus, tooltips
8. Create multiplayer VR experience with avatar sync and voice chat
9. Profile and optimize VR scene for target frame rate
10. Mini-project: Complete VR game with 2+ mechanics

## 310701: Virtual Reality

**Teaching Scheme:** Theory: 03 Hours/Week | **Credits:** 03 | **ISA:** 30, **ESA:** 70

**Prerequisites:** Computer Graphics, Object Oriented Programming

### Course Objectives

- Understand VR concepts, history, and applications
- Learn 3D graphics, rendering, and modeling for VR
- Master VR interaction design and system architecture

### Course Outcomes

| CO  | Description                                        |
| --- | -------------------------------------------------- |
| CO1 | Explain VR technology, taxonomy, and applications  |
| CO2 | Apply 3D graphics and rendering techniques for VR  |
| CO3 | Design immersive VR experiences with interaction   |
| CO4 | Implement VR applications using game engines       |
| CO5 | Evaluate VR system performance and user experience |

### Course Contents

#### Unit I: Introduction to Virtual Reality (07 Hours)

- History of VR: Sensorama, Sword of Damocles, CAVE, HMDs
- VR Definition: Immersion, Presence, Interactivity
- VR Taxonomy: Non-immersive, Semi-immersive, Fully Immersive
- Human Perception: Visual, Auditory, Haptic, Vestibular
- VR Applications: Gaming, Training, Education, Healthcare, Architecture
- VR Hardware: HMDs (Quest, Vive, Index), Trackers, Controllers

#### Unit II: 3D Computer Graphics for VR (07 Hours)

- 3D Coordinate Systems: World, View, Projection
- Geometric Transformations: Translation, Rotation, Scaling
- Viewing Pipeline: Modeling → Viewing → Projection → Viewport
- Lighting and Shading: Ambient, Diffuse, Specular, Phong Model
- Textures: Mapping, Filtering, Mipmapping
- Level of Detail (LOD): Mesh Simplification, Impostors
- Stereoscopic Rendering: Eye Separation, Convergence

#### Unit III: VR Interaction Design (07 Hours)

- Input Devices: Controllers, Gloves, Eye Trackers, Voice
- Interaction Techniques:
  - Selection: Raycasting, Pointing, Go-go
  - Manipulation: Grabbing, Scaling, Rotating
  - Navigation: Walking, Teleportation, Flying
  - Wayfinding: Maps, Signs, Landmarks
- Haptic Feedback: Vibrotactile, Force Feedback, Thermal
- Multimodal Interaction: Combining Visual, Audio, Haptic
- User Interface in VR: Diegetic, Non-diegetic, Spatial UI

#### Unit IV: VR System Architecture (07 Hours)

- VR Rendering Pipeline: Application, Geometry, Rasterization
- Real-time Rendering: Frame Rate, Latency Requirements
- Asynchronous Reprojection: Time Warp, Space Warp
- Foveated Rendering: Eye-tracking based Optimization
- Multi-view Rendering: Single Pass Stereo
- Audio in VR: Spatial Audio, HRTF, Ambisonics, Binaural
- Networking in VR: Synchronization, Prediction, Interpolation

#### Unit V: VR Development Platforms (07 Hours)

- Unity for VR: XR Interaction Toolkit, XR Plugin Framework
- Unreal Engine for VR: VR Template, Blueprints, C++
- WebXR: Browser-based VR, A-Frame, Three.js
- OpenXR: Cross-platform VR Standard
- VR Optimization: Draw Calls, Batching, GPU Profiling
- VR Testing: Playtesting, Simulator Sickness, Usability

#### Unit VI: 360° Video and Photogrammetry (07 Hours)

- 360° Video: Capture (Ricoh Theta, Insta360), Stitching
- Stereoscopic 360°: Over-under, Side-by-side
- Volumetric Video: Capture, Compression, Playback
- Photogrammetry: Structure from Motion, Mesh Generation
- Light Field Capture: Plenoptic Cameras, Light Field Rendering
- Real-world to VR Pipeline: Scanning → Processing → Import

## 310702: Virtual Reality Laboratory

**Teaching Scheme:** Practical: 02 Hours/Week | **Credits:** 01 | **TW:** 25, **PR:** 25

### Laboratory Experiments

1. Set up Unity VR development environment with XR Plugin
2. Create a 3D scene with lighting, textures, and shadows
3. Implement VR camera rig with stereoscopic rendering
4. Implement object selection using raycasting in VR
5. Implement VR locomotion: teleportation and continuous movement
6. Implement object manipulation: grab, scale, rotate
7. Create spatial audio environment in VR
8. Build VR UI system (menus, tooltips, sliders)
9. Optimize VR scene: draw calls, batching, LOD
10. Mini-project: Complete VR experience

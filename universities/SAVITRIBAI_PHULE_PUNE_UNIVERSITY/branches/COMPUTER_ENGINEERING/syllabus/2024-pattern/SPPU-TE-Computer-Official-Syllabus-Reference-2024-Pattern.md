## PCC301COM: Artificial Intelligence

**Teaching Scheme:** Theory: 03 Hours/Week **Credits:** 03 **Examination:** CCE: 30 Marks,
End-Semester: 70 Marks

**Prerequisite Courses:** Discrete Mathematics, Data Structures, Linear Algebra, Probability and
Statistics

### Course Objectives

1. To understand the fundamental concepts of AI and intelligent agents
2. To study various problem-solving techniques using search algorithms
3. To learn knowledge representation and reasoning methods
4. To explore machine learning and natural language processing basics
5. To understand ethical considerations in AI

### Course Outcomes

| CO  | Description                                                                 |
| --- | --------------------------------------------------------------------------- |
| CO1 | Explain AI fundamentals, intelligent agents, and problem-solving approaches |
| CO2 | Apply uninformed and informed search strategies to solve AI problems        |
| CO3 | Represent knowledge using logical and structured representation schemes     |
| CO4 | Apply machine learning, NLP, and computer vision techniques                 |
| CO5 | Analyze ethical implications and societal impact of AI systems              |

### Course Contents

#### Unit I: Introduction to Artificial Intelligence (09 Hours)

- AI: Definitions, History, Foundations, Applications
- Intelligent Agents: Structure, Types, Environments
- Problem Solving: Problem formulation, State space representation
- Search Strategies: Uninformed (BFS, DFS, Depth-limited, Iterative deepening)
- Informed Search: Best-first, A\*, Heuristic functions, Admissibility

#### Unit II: Knowledge Representation and Reasoning (09 Hours)

- Propositional Logic: Syntax, Semantics, Inference
- First-Order Logic: Syntax, Semantics, Quantifiers
- Inference in FOL: Unification, Forward/Backward chaining, Resolution
- Structured Knowledge: Frames, Semantic networks, Conceptual graphs
- Planning: STRIPS, Goal stack planning, Partial order planning

#### Unit III: Machine Learning and Probabilistic Reasoning (09 Hours)

- Probability basics, Bayes' theorem, Naive Bayes classifier
- Decision trees, Ensemble methods
- Support Vector Machines basics
- Hidden Markov Models
- Reinforcement learning: Q-learning basics

#### Unit IV: Natural Language Processing and Computer Vision (09 Hours)

- NLP: Syntax/Semantics, POS tagging, Parsing, NER
- Language models: N-grams, Word embeddings
- Computer Vision: Image representation, Feature extraction, Edge detection
- Object recognition basics, CNNs introduction

#### Unit V: AI Ethics and Advanced Topics (09 Hours)

- Ethical AI: Fairness, Accountability, Transparency, Bias
- AI and Society: Employment, Privacy, Security
- Expert Systems: Architecture, Rule-based systems
- Robotics: Configurations, Sensors, Actuators, Localization
- Generative AI: Introduction to LLMs, GANs

### Learning Resources

#### Text Books

2. Elaine Rich, Kevin Knight, "Artificial Intelligence", 3rd Edition, Tata McGraw Hill

#### Reference Books

## PCC302COM: Computer Networks

**Teaching Scheme:** Theory: 03 Hours/Week **Credits:** 03 **Examination:** CCE: 30 Marks,
End-Semester: 70 Marks

**Prerequisite Courses:** Data Structures, Operating Systems, Digital Electronics

### Course Objectives

1. To understand network architecture, OSI and TCP/IP models
2. To study physical layer transmission media and data link layer protocols
3. To learn network layer protocols, IP addressing, and routing algorithms
4. To explore transport layer protocols and congestion control
5. To understand application layer protocols and network security basics

### Course Outcomes

| CO  | Description                                                                      |
| --- | -------------------------------------------------------------------------------- |
| CO1 | Explain network architecture, reference models, and physical layer concepts      |
| CO2 | Analyze data link layer protocols, error detection/correction, and MAC protocols |
| CO3 | Apply IP addressing, subnetting, and routing algorithms for network design       |
| CO4 | Compare transport layer protocols and analyze congestion control mechanisms      |
| CO5 | Describe application layer protocols and basic network security mechanisms       |

### Course Contents

#### Unit I: Introduction and Physical Layer (09 Hours)

- Network Models: OSI, TCP/IP, Protocols, Services, Interfaces
- Physical Layer: Analog/Digital signals, Transmission media (Guided/Unguided)
- Multiplexing: FDM, TDM, WDM, CDM
- Switching: Circuit, Packet, Message switching
- Network Topologies: Star, Bus, Ring, Mesh, Hybrid

#### Unit II: Data Link Layer (09 Hours)

- DLL services: Framing, Flow control, Error control
- Error Detection/Correction: Parity, CRC, Hamming code
- Flow Control: Stop-and-Wait, Sliding Window, Go-Back-N, Selective Repeat
- MAC Sublayer: Random Access (ALOHA, CSMA, CSMA/CD), Controlled Access
- Ethernet: IEEE 802.3, Fast Ethernet, Gigabit Ethernet
- Wireless LAN: IEEE 802.11, Bluetooth

#### Unit III: Network Layer (09 Hours)

- Logical Addressing: IPv4, IPv6, Subnetting, CIDR, VLSM
- Routing Algorithms: Distance Vector (RIP), Link State (OSPF), Path Vector (BGP)
- Network Layer Protocols: ARP, RARP, ICMP, IGMP
- Network Devices: Routers, Switches, Bridges, Gateways
- Software Defined Networking (SDN) basics

#### Unit IV: Transport Layer (09 Hours)

- Transport Services: Connection-oriented/Connectionless
- UDP: Segment format, Checksum
- TCP: Segment format, Connection management, Flow control, Congestion control
- Congestion Control: Slow Start, Congestion Avoidance, Fast Recovery
- Quality of Service: Traffic shaping, Leaky bucket, Token bucket

#### Unit V: Application Layer and Security (09 Hours)

- Application Protocols: HTTP, FTP, SMTP, POP3, IMAP, DNS, DHCP
- Network Security: Cryptography basics, Symmetric/Asymmetric encryption
- Firewalls, VPNs, IDS/IPS
- Web Security: SSL/TLS, HTTPS, SET

### Learning Resources

#### Text Books

1. Andrew S. Tanenbaum, David J. Wetherall, "Computer Networks", 5th Edition, Pearson
2. Behrouz A. Forouzan, "Data Communications and Networking", 5th Edition, McGraw Hill

#### Reference Books

1. William Stallings, "Data and Computer Communications", 10th Edition, Pearson
2. James F. Kurose, Keith W. Ross, "Computer Networking: A Top-Down Approach", 8th Edition, Pearson

## PCC303COM: Theory of Computation

**Teaching Scheme:** Theory: 03 Hours/Week **Credits:** 03 **Examination:** CCE: 30 Marks,
End-Semester: 70 Marks

**Prerequisite Courses:** Discrete Mathematics, Data Structures

### Course Objectives

1. To understand formal languages, grammars, and automata theory
2. To study the equivalence of different automata and language classes
3. To learn about Turing machines and computability
4. To explore complexity theory and NP-completeness
5. To apply automata theory in practical applications

### Course Outcomes

| CO  | Description                                                                 |
| --- | --------------------------------------------------------------------------- |
| CO1 | Explain the hierarchy of formal languages and automata                      |
| CO2 | Design finite automata, regular expressions, and context-free grammars      |
| CO3 | Analyze the equivalence of pushdown automata and context-free grammars      |
| CO4 | Design Turing machines for decision problems and understand computability   |
| CO5 | Classify problems into complexity classes and identify NP-complete problems |

### Course Contents

#### Unit I: Finite Automata and Regular Languages (09 Hours)

- Deterministic Finite Automata (DFA): Definition, Design, Minimization
- Non-deterministic Finite Automata (NFA): Definition, NFA to DFA conversion
- Regular Expressions: Operations, Algebraic laws, Equivalence to FA
- Closure properties of regular languages
- Pumping Lemma for regular languages

#### Unit II: Context-Free Grammars and Languages (09 Hours)

- Context-Free Grammars: Definition, Derivation, Parse trees
- Ambiguity in CFGs: Removal of ambiguity
- Chomsky Normal Form (CNF), Greibach Normal Form (GNF)
- Pumping Lemma for CFL
- Closure properties of CFL

#### Unit III: Pushdown Automata (09 Hours)

- Pushdown Automata: Definition, Types (DPDA, NPDA)
- PDA Design: Acceptance by final state, empty stack
- Equivalence of PDA and CFG
- Deterministic vs Non-deterministic PDA
- Applications of PDA

#### Unit IV: Turing Machines and Computability (09 Hours)

- Turing Machine: Definition, Design, Variants
- TM as a computing device, TM as a language acceptor
- Recursive and Recursively Enumerable languages
- Undecidability: Halting problem, Post's Correspondence Problem
- Rice's Theorem

#### Unit V: Complexity Theory (09 Hours)

- Time Complexity: Big-O, Polynomial time
- P and NP classes: Definitions, Examples
- NP-Completeness: Reduction, Cook-Levin Theorem
- Classic NP-Complete problems: SAT, 3-SAT, Hamiltonian cycle, TSP
- Coping with NP-Completeness: Approximation, Heuristics

### Learning Resources

#### Text Books

1. John E. Hopcroft, Rajeev Motwani, Jeffrey D. Ullman, "Introduction to Automata Theory, Languages,
   and Computation", 3rd Edition, Pearson
2. Michael Sipser, "Introduction to the Theory of Computation", 3rd Edition, Cengage Learning

#### Reference Books

1. Peter Linz, "An Introduction to Formal Languages and Automata", 6th Edition, Jones & Bartlett
2. J. C. Martin, "Introduction to Languages and the Theory of Computation", McGraw Hill
3. Dexter C. Kozen, "Automata and Computability", Springer

#### MOOC / NPTEL Links

1. NPTEL: Theory of Computation — IIT Kharagpur
2. NPTEL: Automata Theory — IIT Kanpur

1. Understand robotics fundamentals and robot classifications

## PCC351COM: Machine Learning

**Teaching Scheme:** Theory: 03 Hours/Week **Credits:** 03 **Examination:** CCE: 30 Marks,
End-Semester: 70 Marks

**Prerequisite Courses:** Probability and Statistics, Data Science, Python Programming

### Course Objectives

1. Provide the fundamental concepts of Machine Learning
2. Develop an understanding of regression concepts, techniques, and evaluation metrics used for
   predictive modeling
3. Imbibe knowledge of classification models and algorithms for solving real-world classification
   problems
4. Familiarize students with clustering algorithms and ensemble learning techniques
5. Give insight into reinforcement learning concepts and their use in sequential decision-making
   problems

### Course Outcomes

| CO  | Description                                                                                                                     |
| --- | ------------------------------------------------------------------------------------------------------------------------------- |
| CO1 | Apply fundamental Machine Learning concepts in various learning paradigms and real-world engineering applications               |
| CO2 | Make use of various types of regression models for predictive modeling and data analysis                                        |
| CO3 | Identify different types of classification problems, including binary, multiclass, balanced, and imbalanced classification      |
| CO4 | Analyze clustering algorithms for grouping similar data points and ensemble learning techniques for improving model performance |
| CO5 | Distinguish reinforcement learning from supervised and unsupervised learning approaches                                         |

### Course Contents

#### Unit I: Fundamentals of Machine Learning (09 Hours)

- Introduction, scope, AI vs ML vs Data Science, traditional programming vs ML
- Real-world applications of ML
- Learning Types: Supervised, unsupervised, semi-supervised, reinforcement
- Models: Geometric, probabilistic, logical, grouping/grading
- Parametric vs non-parametric models
- Feature Engineering: Feature selection, extraction, scaling
- Dimensionality Reduction: PCA, LDA

**Case Study:** Machine Learning Based Student Performance Prediction and Feature Engineering
Analysis

#### Unit II: Supervised Learning — Regression (09 Hours)

- Regression vs correlation, Univariate/Multivariate regression
- Linear/Nonlinear regression
- Bias-Variance Tradeoff, Overfitting/Underfitting
- Regression Techniques: Simple/Multiple Linear, Polynomial
- Decision Tree Regression, Random Forest Regression
- Support Vector Regression (SVR)
- Regularization: Ridge (L2), Lasso (L1)
- Evaluation Metrics: MSE, MAE, RMSE, R-squared

**Case Study:** Comparative Study of Regression Techniques for House Price Prediction

#### Unit III: Supervised Learning — Classification (09 Hours)

- Binary vs Multiclass classification
- Balanced vs Imbalanced problems
- Decision boundary
- Evaluation Metrics: Confusion Matrix, Accuracy, Precision, Recall, F1-Score
- Multiclass strategies: One-vs-One, One-vs-All, Averaging Methods
- Algorithms: K-Nearest Neighbors (KNN), Linear SVM, Soft Margin SVM
- Kernels: RBF, Polynomial, Sigmoid

**Case Study:** Comparative Study of Classification Algorithms for Email Spam Detection

#### Unit IV: Unsupervised Learning and Ensemble Learning (09 Hours)

- **Clustering:** Hierarchical (Agglomerative/Divisive), K-Means, K-Medoids, DBSCAN, Gaussian
  Mixture Model
- **Ensemble Learning:** Homogeneous/Heterogeneous ensembles
- Voting: Max, Averaging, Weighted
- Bagging, Random Forest
- Boosting: AdaBoost, Gradient Boosting, Stacking

**Case Study:** Customer Segmentation and Sales Prediction

#### Unit V: Reinforcement Learning (09 Hours)

- Components: Agent, Environment, State, Action, Reward
- Markov Decision Process (MDP): Property, Elements, Tasks
- Framework: Policy, Value functions, Bellman equation
- Exploration vs Exploitation tradeoff
- ε-greedy algorithm
- Dynamic Programming
- Q-Learning algorithm

**Case Study:** Smart Traffic Signal Control using Q-Learning

### Learning Resources

#### Text Books

1. Ethem Alpaydin, "Introduction to Machine Learning", MIT Press
2. Andreas C. Müller, Sarah Guido, "Introduction to Machine Learning with Python", O'Reilly
3. Tom Mitchell, "Machine Learning", McGraw-Hill

#### Reference Books

1. Peter Flach, "Machine Learning: The Art and Science of Algorithms", Cambridge University Press
2. Kevin P. Murphy, "Machine Learning: A Probabilistic Perspective", MIT Press
3. Shai Shalev-Shwartz, Shai Ben-David, "Understanding Machine Learning", Cambridge University Press

#### MOOC / NPTEL Links
